# None-Curve

An experimental web app for turning font curves into editable polygon shapes. Explore different levels of detail, inspect a glyph’s original points, and reshape its outline into a crisp geometric or expressive form. Export your results as SVG or a font file.

## 中文

一个用于把字体曲线转换成可编辑多边形的实验性网页工具。你可以调整轮廓的细节与锚点数量，查看字形原有的锚点和控制点，并将字体改造成利落的几何形态或更自由的风格。作品可导出为 SVG 或字体文件。
