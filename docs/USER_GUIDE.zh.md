# None-Curve 用户指南

[English](USER_GUIDE.md) · **中文**

本指南面向设计师和所有感兴趣的人，不需要任何编程知识。它会说明屏幕上每个区域的作用、每个控制项会带来什么变化，以及如何保存作品。

> 网页界面是英文的。本指南提到按钮和选项时，会写出界面上的英文名称，并在旁边附上中文解释，方便对照。

---

## 1. None-Curve 能做什么

字体里的字母是用平滑曲线画出来的。None-Curve 会把这些曲线**改用直线重建**，让字母变成多边形——效果可以从“几乎和原字一样”，一直调到“棱角分明的折面”“方形”“对齐网格”，或“粗糙、像刻出来的”。

你可以：

- 从电脑或 Google Fonts 载入字体。
- 输入任意文字，拖动滑块时实时看到它被重建。
- 放大查看单个字母，以及它原本的曲线控制点。
- 把一个字母或整段文字保存为 **SVG** 图像，或把改造后的字母生成新的**字体文件**（`.otf`）。

所有操作都在你的浏览器里完成，字体文件不会被上传到任何地方。

---

## 2. 你需要准备什么

- 电脑上的新版浏览器（Chrome、Edge、Firefox 或 Safari）。手机也能用，但大屏幕会舒服得多。
- 电脑里的字体文件（`.ttf`、`.otf`、`.woff` 或 `.woff2`），**或者**能上网，以便从 Google Fonts 载入字体。
- 网页地址，例如 `https://m1ingx1xx1.github.io/None-Curve/`，也可以向搭建项目的人索取。

## 3. 认识屏幕

屏幕分成上下两行、五个区域：

```text
┌────────────────────────╥──────────────────────────────────────┐
│ ① 功能区                ║ ② 结果画布                           │
│   Import font 导入字体   ║   你输入的文字，实时重建               │
│   字体信息               ║                                      │
│   造型控制项             ║                                      │
╞════════════════════════╩══════════════════════════════════════╡
│ ③ Glyphs 字形列表        ║ ④ Text 文字   ║ ⑤ Preview 预览         │
│   点击插入字符           ║   在这里打字   ║   ② 的缩小版，可模糊/反色 │
└────────────────────────╨──────────────╨───────────────────────┘
```

1. **功能区（左上）**——**Import font**（导入字体）按钮、已载入字体的信息，以及所有造型控制项。滚动这一栏可以看到全部控制项。
2. **结果画布（右上）**——最大的预览区，始终显示你输入的文字，并按当前设置重建。
3. **Glyphs 字形列表（左下）**——字体里的每个字母、数字和符号。点击一个就会把它打进文字输入框，适合输入 `©`、`→`、带重音的字母这类不好打的符号。
4. **Text 文字输入（右下左侧）**——输入想在画布上看到的文字。
5. **Preview 预览（右下右侧）**——结果画布的缩小版，显示你输入的全部文字，并带有自己的 **Blur**（模糊）滑块和 **Invert**（反色）按钮。拖动 ④ 和 ⑤ 之间的细线可以调整两者的宽度分配。

页面最上方有 **Export…**（导出）按钮；最下方的状态栏会说明当前显示的内容和启用了哪些设置。

**调整各区域的大小。** 图中的双线是可以拖动的细线：

- **上下两行之间**——上下拖动，让画布或下面一行更高；
- **功能区和画布之间**——左右拖动；
- **字形列表和文字输入之间**——左右拖动；
- **文字输入和预览之间**——左右拖动。

一边变大多少，另一边就变小多少，所以整个界面始终正好放进窗口里，页面不需要滚动。每个区域都有最小尺寸。双击细线可以让它回到原来的位置。下次打开时程序会记住你的设置。

> 在手机上，这些区域会从上到下排列：功能区、画布、文字输入、预览、字形列表。造型控制项默认收起，点画布工具栏里的 **Parameters** 展开。

## 4. 五分钟快速上手

1. 点左上的 **Import font** → **Google Fonts** → 选择 **Inter** → **Load font**。
2. 在文字输入框里输入一个词，比如 `Hello`。
3. 在功能区找到 **Curve flattening**（曲线展平），选择 **Fixed segments**（固定线段数），把 **Segments per curve**（每条曲线的线段数）设为 `2`。
4. 打开 **Merge joined curves**（合并相连曲线），字母会出现明显的折面效果。
5. 点顶部的 **Export…** → **SVG — specimen text** → **Download SVG**。

这就是完整的流程。本指南接下来会逐步详细说明。

## 5. 载入字体

点功能区最上方的 **Import font**，会出现两个选项。

### 从电脑载入

- 选择 **Local file**（本地文件）并挑一个字体文件，**或者**直接把字体文件拖到大画布上。
- 支持 `.ttf`、`.otf`、`.woff`、`.woff2`。不支持字体集合（`.ttc`）。
- 文件始终留在你的电脑上，只由浏览器读取。

### 从 Google Fonts 载入

选择 **Google Fonts**。在 **Family**（字体名称）框里，你可以：

- **从列表中选**——列出了 25 款常用字体。
- **输入字体名称**——任何 Google 字体都可以，但拼写要和 fonts.google.com 上完全一致（大小写也要一致：写 `Open Sans`，不要写 `open sans`），然后点 **Use "…"**。
- **粘贴链接**——在 fonts.google.com 上复制某款字体页面的地址，例如 `https://fonts.google.com/specimen/Plaster`，粘贴进来即可。带有字重或斜体信息的链接（例如 `…css2?family=Roboto:ital,wght@1,700`）也能识别。

选定字体后再设置：

- **Weight**（字重）——字有多粗（400 为常规，700 为粗体）。有些字体是“可变字体”，会以默认字重载入，此时字重菜单不可选。
- **Italic**（斜体）——如果这款字体有斜体。
- **Character subset**（字符子集）——Google 按语言拆分字体文件（如 `latin`、`latin-ext`、`cyrillic`）。一次只载入一个子集，所以其他语言的字符可能缺失。

点 **Load font**。下载完成后，字体名称会出现在功能区。

### 出问题时

功能区会显示发生了什么，并提供 **Retry**（重试）：

| 提示 | 含义 | 怎么办 |
|---|---|---|
| Empty file / Unsupported format | 文件不是字体，或者是空的。 | 换成 `.ttf`、`.otf`、`.woff` 或 `.woff2` 文件。 |
| Font parsing failed | 文件已损坏。 | 换一份这款字体的文件。 |
| Google Fonts API error | Google 不认识这个名字。 | 检查拼写和大小写。 |
| Network / CORS error | 没有网络，或浏览器插件拦截了请求。 | 检查网络或广告拦截插件，然后点 **Retry**。 |
| Only fonts.google.com … URLs are accepted | 粘贴的不是 Google Fonts 链接。 | 粘贴来自 fonts.google.com 的链接。 |

新字体载入失败时，屏幕上会继续保留之前的字体。

## 6. 输入文字

- 在 **Text** 输入框（右下）里打字，按回车换行。
- **Sample…** 提供现成的示例文字：全字母句（Pangram）、圆形字母（Round letters，适合测试方形化）和字距组合（Spacing）。
- **Clear** 清空输入框。
- 输入框下方会显示字符数，以及是否应用了字体自带的**字偶距**（像 “AV” 这类字母组合之间的细微间距调整）。
- 如果某个字符在字体里不存在，画布上会显示一个**红色虚线框**，并在输入框下方列出；这一行的其余部分照常显示。
- 最多显示 1000 个字符。
- 不好直接打出来的符号，可以在左下的 **Glyphs** 列表里点一下。它会插入到输入框里光标所在的位置（如果你还没点过输入框，就加在末尾）；如果你选中了一段文字，符号会替换掉它。
- 把 Glyphs 列表拖窄时，它只显示字符本身、不显示编码，这样能放下更多字符；拖宽就会重新显示编码（鼠标停在字符上也能看到）。
- **Glyphs** 列表上方的**搜索框**可以按字符本身（`A`）、编码（`U+0041`）或名称的一部分（`arrow`、`dieresis`）查找字符。

## 7. 查看结果

### 画布工具栏

**轮廓视图**——画出哪种形状：

- **Original**（原始）——字体原本的样子，带曲线，用来对比。
- **Flattened**（展平后）——套用你全部设置后的结果（默认）。
- **Compare**（对比）——灰色的结果上叠加蓝色虚线表示的原始曲线。

**图层**——可以开关的附加信息：

- **Fill**（填充）——实心字母。关闭后只显示轮廓线。
- **Skeleton**（骨架）——决定原始曲线的点：蓝色方块在曲线上；空心橙色圆是牵引曲线的“控制点”；细线把它们连起来。
- **Vertices**（顶点）——新直线形状每个拐角处的绿色圆点。
- **Metrics**（度量线）——几条水平参考线：ascender（上伸线，“h” 这类高字母的顶部）、cap height（大写字母顶部）、x-height（“x” 的顶部）、baseline（基线，字母坐落的线）、descender（下伸线，“p”“g” 的底部）。

> 字母足够大时才会显示骨架点和顶点。如果画布提示 “Zoom in to see skeleton points and vertices”，请放大。

**缩放**——`−` 和 `+` 缩小、放大，**Fit** 重新显示全部文字。也可以在画布上滚动鼠标滚轮缩放，按住拖动来移动视图。

### 查看单个字母

- 点画布上的某个字母即可选中它，它在文字中出现的每一处都会高亮。从 Glyphs 列表插入字符时，也会选中该字符。
- 造型控制项里的统计数字（顶点数、曲线数等）针对的是当前选中的字母。
- 想看细节，就在画布上放大。

### 预览：模糊、反色和宽度

右下角的 **Preview** 是画布的缩小版，始终一次显示你输入的全部文字。它跟随画布的 Original / Flattened / Compare 和图层按钮，但不跟随画布的缩放。

- **Blur** 让预览变模糊，就像从远处看或眯着眼看。这样能抛开细节，只看字母整体的形状和节奏——可以快速检查粗糙或折面风格的文字是否仍然好认。
- **Invert**（反色）交换预览里字母和背景的颜色——浅底深字变成深底浅字，再点一次换回来。适合检查文字在两种配色下的效果，比如做招牌或深色海报时。
- Blur 和 Invert 只改变这个小视图，不会改变画布上的字母，也不会影响导出。
- **想让输入框或预览更宽：** 拖动两者之间的细线（见第 3 节“调整各区域的大小”）。

## 8. 造型控制项

控制项按固定顺序从上到下依次生效，后面的步骤处理的是前面步骤的结果：

**Curve flattening 曲线展平 → Squaring 方形化 → Anchors 锚点 → Grid & angles 网格与角度 → Distortion 扰动**

所有尺寸都以**字体单位**计算。字体是在一个看不见的正方形（称为 **em**）上设计的，通常宽 1000 或 2048 个单位（字体信息里的 “Units/em”）。所以在 1000 单位的字体里，“20 u” 相当于字高的 2%。缩放画布不会改变这些设置的效果。

每个控制项都有简短说明。为了让面板保持清爽，说明默认是收起的：点控制项名称旁边的小 **ⓘ** 就能展开阅读，再点一次收起。想一次看到全部说明（第一次使用时很有用），勾选面板顶部的 **Show all explanations**。黄色警告和统计数字始终显示。如果某个设置会破坏形状（例如让字母自己交叉），字母的那一部分会保持上一步的样子，并出现一条黄色提示说明原因。

### Curve flattening（曲线展平）——曲线如何变成直线

先选一种 **Mode**（模式）：

- **Adaptive**（自适应）——尽量贴近原形。**Tolerance**（容差）是直线允许偏离曲线的距离。数值小（0.1–2）时几乎和原字一样；数值大（20–500）时明显有棱角。单独使用 Adaptive 时，大约到 100 就不会再变粗犷了——打开 **Merge joined curves** 才能更进一步。
- **Fixed segments**（固定线段数）——每条曲线都换成同样数量的直线。**Segments per curve** 设置这个数量（1–32），线越少越粗犷、折面感越强。

**Merge joined curves**（合并相连曲线，两种模式都可用）——获得强烈折面效果的关键。你眼中的一条弧，在字体里通常由好几小段曲线拼成。不合并时，设置作用于每一小段，字母看起来仍然平滑；合并后，整条看得见的弧才算一条曲线：

- 在 **Fixed segments** 下，把 **Segments per curve** 依次设为 4、3、2，从含蓄过渡到强烈；
- 在 **Adaptive** 下，调大 **Tolerance**（试试 50、150、500）：每条弧会在容差允许的范围内尽量拉直，最多变成一条直线。

下面的合并设置两种模式共用，切换模式时会保留。

- **Break merged curves at**（在哪里断开合并的曲线）——一条合并曲线在哪里结束、下一条从哪里开始：
  - **Corners & extremes**（尖角和极值点，默认）——在尖角处，以及每个圆形最左、最右、最上、最下的点断开。圆形的 “O” 会分成四段四分之一弧，折面均衡对称。
  - **Corners only**（只在尖角）——只在尖角处断开。像 “O” 这样整圈平滑的形状会变成一条曲线，可能得到三角形或非常简化的形状。
- **Merge through straight lines**（穿过直线合并）——把平滑流进曲线的直线部分也一起合并，比如 n、m、u 的竖笔流进弧线的地方。它们会和曲线一起被重新塑形，得到粗犷得多的“低分辨率”效果。竖笔的端点可能被削掉，所以默认关闭。
- **Corner angle**（尖角阈值）——拐弯要多急才算尖角（默认 15°），比它平缓的拐弯会被合并。单独调它几乎看不到变化，因为字体内部的曲线几乎总是平滑相接的。**打开 Merge through straight lines 后它才真正起作用：** 把角度调大（试试 45° 和 90°），每个字母会有越来越多的部分合并成几笔大的折线。

### Squaring（方形化）——让圆形字母变方

把圆形推向矩形。设为 **100%**（“Square”）时，圆形的 **O** 和它中间的洞都会变成正方形，笔画粗细保持不变。

- **Amount**（强度）——0% 为关闭，**Soft** 为一半，**Square** 为完全方形；中间的值用滑块调。
- **Applies to**（作用范围）：
  - **Round contours**（只作用于圆形轮廓，推荐）——只改变接近圆或椭圆的形状，如 O、o、0，以及 b、d、g、p、q 的圆腔。A、E、S 这类直线或尖角形状保持原样。
  - **All contours**（所有轮廓）——每个形状都推向矩形。效果强得多，有些字母可能会显得奇怪。

小技巧：方形化之后，加一点 **Anchor reduction**（锚点简化，例如 2），直边会更干净。

### Anchors（锚点）——轮廓上有多少个点

- **Anchor spacing**（锚点间距）——在直线边上加点，使每段都不超过这个长度。形状不变，但后面的步骤（比如扰动）会有更多点可以处理。0 为关闭。
- **Anchor reduction**（锚点简化）——去掉对形状影响很小的点。数值越大去掉的点越多、字母越简化；数值过大可能抹掉小细节。0 为关闭。
- 两者同时开启会互相抵消（简化会删掉刚加上的点），界面会提示。
- **Reset anchors** 同时关闭两者。

### Grid & angles（网格与角度）——构成感、几何感的造型

- **Snap to grid**（网格吸附）+ **Grid size**（网格大小）——把每个点移到一张看不见的网格上，就像在方格纸上画字。网格越大，字母越像像素块。开启时，画布上会淡淡地画出网格。
- **Angle lock**（角度锁定）+ **Allowed directions**（允许的方向）——把每条边拉直到固定的几个方向：
  - **90°**——只有水平和垂直线。
  - **45°**——再加上对角线。
  - **30°** / **15°**——更细的角度间隔。
- 两者同时开启时先吸附网格，所以角度锁定可能会让部分点稍微离开网格。
- **Reset grid & angles** 同时关闭两者。

### Distortion（扰动）——粗糙、手工或石刻般的边缘

以可控、可重复的方式移动轮廓上的点。

- **Noise amplitude**（噪声幅度）——点最多移动多远。0 为关闭。小数值（5–20）带来轻微的手工切割感；大数值像被磨损或侵蚀。
- **Noise frequency**（噪声频率）——边缘起伏的密度。低：缓慢、温和的波浪；高：急促、细碎的粗糙感。
- **Normal bias**（法线偏向）——点移动的方向。0% 让点沿着边滑动；100% 让边向内外凹凸。
- **Seed**（种子）——选择某一种随机图案的数字。同样的种子永远得到完全相同的结果，所以可以随时找回喜欢的版本。**Next variant** 换成下一种图案。
- **Reset distortion** 关闭扰动。

扰动可能会降低文字的可读性，请适度使用。

### Random anchors（随机锚点，实验性）——每次都不一样，但可以复现

位于工具面板的最底部。平时程序会在曲线上按规则的间距放点（即 Curve flattening 曲线展平）。打开 **Use random anchors** 后，点改为放在字母原始轮廓上的随机位置——点始终落在真实的字母上，随机的只是“放在哪里”。后面的控制项（Squaring、Anchors、Grid & angles、Distortion）照常叠加。

随机锚点开启期间，**Curve flattening** 的控件会变灰并附上说明，因为随机锚点取代了它们——调了也不会有变化。关掉随机锚点即可恢复使用。

- **Density**（密度）——每 1000 字体单位轮廓大约放多少个点。数值小（2–6）字母会变得粗糙、块状；数值大则接近原字形。
- **Randomness**（随机程度）——0% 时点均匀分布；100% 时每个点可以在自己的一小段范围内随意移动。点与点之间不会互换位置，所以字母不会缠在一起。
- **Keep sharp corners**（保留尖角）——保留字母真正的尖角（例如竖笔末端和衬线），让它们保持干净利落。关掉后效果更松散。
- **Seed**（种子）——决定某一个随机结果的数字。
  - **Shuffle** 随机换一个新种子，并显示在输入框里。
  - **Copy** 复制种子，方便贴到你的笔记里。
  - **Previous** 列出你这次打开页面后试过的种子，点一下就能回到那个结果。
  - 想以后重现某个结果：载入同一个字体，使用相同的设置，把种子输入到框里即可。
  - **Randomness** 为 0% 时点是均匀分布的，种子不起作用，会变灰。
- **Reset random anchors** 关闭随机锚点并恢复其他设置，但保留你的种子。

种子也会显示在底部的状态栏和导出对话框里，所以导出时它会被一起记录下来。

## 9. 常用配方

**粗犷的折面字（类似“每条曲线 4 / 3 / 2 条线”）**
Curve flattening → **Fixed segments**，打开 **Merge joined curves**，**Break merged curves at** 选 Corners & extremes，**Segments per curve** 设为 4（含蓄）、3 或 2（强烈）。

**用 Adaptive 模式做折面字形**
Curve flattening → **Adaptive**，打开 **Merge joined curves**，**Tolerance** 设为 50（含蓄）、150 或 500（非常粗犷）。

**极端的低分辨率字形**
在上面任一配方的基础上，打开 **Merge through straight lines**，把 **Corner angle** 调到 45°–90°。想要最简化的形状，可以把 **Break merged curves at** 改成 Corners only。

**方形的 O 和其他圆形字母**
Squaring → **Square**，Applies to 选 **Round contours**，再到 Anchors → **Anchor reduction** 设为 2。输入 “OO oo 00”（或 Sample… → Round letters）检查效果。

**像素 / 网格风格**
Grid & angles → 打开 **Snap to grid**，**Grid size** 约为字体 Units/em 的 5%（例如 1000 单位的字体设为 50）。再打开 **Angle lock** 并选 **90°**，就只剩水平和垂直的边。

**石刻或风化的质感**
固定线段数 3 并开启合并，然后 Distortion → **Noise amplitude** 10–30、**Noise frequency** 8–15、**Normal bias** 70%。不断点 **Next variant**，直到找到喜欢的图案。

**随机的手工切割感**
Random anchors → 打开 **Use random anchors**，**Density** 3–5，**Randomness** 100%，打开 **Keep sharp corners**。不断点 **Shuffle** 直到满意，然后点 **Copy** 记下种子。

**回到原样**
把 Curve flattening 设为 **Adaptive** 并用较小的 **Tolerance**，再关闭 Squaring、Anchors、Grid & angles 和 Distortion（每组都有复位按钮）。或者直接在画布工具栏选 **Original** 查看未经改动的字体。

## 10. 保存作品（导出）

点右上角的 **Export…**。只有点下载按钮时才会下载。

### 保存为图像（SVG）

1. 选择 **SVG — current glyph**（当前选中的字母）或 **SVG — specimen text**（你输入的全部文字）。
2. **Coordinate precision**（坐标精度）——文件里的数字保留几位小数，默认 2 即可。如果提示这个精度会破坏形状，就选更高的精度。
3. 点 **Download SVG**。

SVG 文件可以用 Illustrator、Figma、Inkscape 或浏览器打开，里面的形状全部由直线构成。

### 保存为字体（OTF）

1. 选择 **Font file — OpenType (.otf)**。
2. **Glyphs to include**（包含哪些字形）：**Current glyph**（当前字形）、**Specimen characters**（只包含你输入文字里的字符）或 **All mapped characters**（字体里的所有字母）。
3. 填写 **Family name**（字体族名）和 **Style name**（样式名），请用英文字母。起一个新名字可以避免和原字体混淆。
4. 点 **Build & verify**（生成并校验）。应用会生成字体并做全面检查；大字体可能需要几秒钟，点 **Cancel** 可以中止。
5. 显示 “Verified” 后点 **Download .otf**，然后像安装普通字体一样安装它。

需要了解：

- 生成之后如果又改了设置，需要重新生成再下载。
- 新字体**不包含字偶距**、连字或原字体的其他高级排版功能，只有改造后的字母和它们的宽度。
- 少数特殊字符如果形状无法安全保存会被略去，应用会列出它们。
- 可变字体会按屏幕上看到的版本保存。
- **版权提醒：**修改后的字体仍然基于别人的设计。分享前请查看原字体的授权——许多开源字体要求修改版使用新的名字。

## 11. 常见问题

**线段已经很少了，字母看起来还是很平滑。**
在 Fixed segments 模式下打开 **Merge joined curves**。不开启时，曲线的每一小段都会各自分到线段。

**调整 Corner angle 没有任何变化。**
打开 **Merge through straight lines**（在 Merge joined curves 下面）。不开启时，Corner angle 只影响两段曲线之间的连接点，而这些连接点几乎都已经是平滑的。

**我喜欢某个随机锚点的结果，怎么找回来？**
记下（或 **Copy**）它的种子。以后载入同一个字体，把 Random anchors 设成相同的设置，再把种子输入到 **Seed** 框里。同一次打开页面时，也可以直接在 **Previous** 里点它。

**为什么看不到骨架点或绿色顶点？**
字母足够大时才会显示。放大画布即可。

**有些控件是灰色的，拖不动。**
它们此刻不会产生任何效果，上方的说明会解释原因——例如随机锚点开启时曲线展平整组变灰；Randomness 为 0% 时随机种子变灰。

**在 Glyphs 里点的字符插错了位置。**
字符会插到文字输入框里光标最后所在的位置。先在输入框里点一下想插入的位置，再点字符。

**黄色提示说有些轮廓“kept their previous shape”（保持了之前的形状）。**
那个设置会让字母的一部分塌陷或自己交叉，所以应用为那一部分保留了上一个正常的结果。试试温和一点的数值。

**某个字母显示成红色虚线框。**
字体里没有这个字符，或者（Google Fonts 的情况下）它在另一个字符子集里。换一个子集或字体。

**有些 Google 字体的字重菜单是灰色的。**
那是一款可变字体，会以默认字重载入。

**刷新页面后结果会变吗？**
设置不会在两次访问之间保存。在同一次使用中，相同的设置和种子总会得到相同的结果。想保留的作品请导出。

**会上传什么东西吗？**
不会。本地字体始终留在你的电脑上；Google 字体从 Google 下载，不会发送到其他任何地方。

## 12. 术语表

| 术语 | 含义 |
|---|---|
| **Glyph 字形** | 字体中画出的一个图形——字母、数字或符号。 |
| **Contour 轮廓** | 一条闭合的外形线。“O” 有两条：外圈和中间的洞。 |
| **Counter 字腔** | 字母内部被包围的空白，如 “o”“a”“B” 中的洞。 |
| **Curve / segment 曲线 / 曲线段** | 两点之间的一段轮廓。字体用 Bézier 曲线来存储。 |
| **Anchor 锚点（曲线上的点）** | 位于轮廓线上的点。 |
| **Control point 控制点（曲线外的点）** | 牵引曲线、但本身不在曲线上的点。 |
| **Vertex 顶点** | 新的直线形状的拐角。 |
| **Polygon 多边形** | 只由直线组成的形状。 |
| **Em / Units per em** | 字体看不见的设计方格，以及它的字体单位大小（常见 1000 或 2048）。 |
| **Font unit 字体单位（u）** | 字体内部的度量单位，控制项里的所有尺寸都用它。 |
| **Baseline 基线** | 字母坐落的那条线。 |
| **x-height / cap height** | 小写 “x” 的高度 / 大写字母的高度。 |
| **Ascender / descender 上伸 / 下伸** | 高出 x 高度的部分（h、d）/ 低于基线的部分（p、g）。 |
| **Advance width 字宽** | 排一个字母后文字向前推进的距离，包括它两侧的留白。 |
| **Kerning 字偶距** | 特定字母组合之间的细微间距调整，如 “AV”。 |
| **Variable font 可变字体** | 一个文件里包含一系列字重或宽度的字体。 |
| **SVG** | 矢量图像格式，任何尺寸下都保持清晰。 |
| **OTF（OpenType）** | 可以安装到电脑上的标准字体文件格式。 |
