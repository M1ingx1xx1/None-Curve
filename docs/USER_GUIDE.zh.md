# None-Curve 用户指南

[English](USER_GUIDE.md) · **中文**

本指南面向设计师和所有感兴趣的人，不需要任何编程知识。它会说明屏幕上每个区域的作用、每个控制项会带来什么变化，以及如何保存作品。

> 网页界面是英文的。本指南提到按钮和选项时，会写出界面上的英文名称，并在旁边附上中文解释，方便对照。

---

## 1. None-Curve 能做什么

字体里的字母是用平滑曲线画出来的。None-Curve 会把这些曲线**改用直线重建**，让字母变成多边形——效果可以从“几乎和原字一样”，一直调到“棱角分明的折面”“方形”“对齐网格”，或“粗糙、像刻出来的”。

你可以：

- 从电脑或 Google Fonts 载入字体。
- 输入任意文字，拖动滑块时实时看到它被重建。
- 放大查看单个字母，以及它原本的曲线控制点。
- 把一个字母或整段文字保存为 **SVG** 图像，或把改造后的字母生成新的**字体文件**（`.otf`）。
- 播放音频文件或使用麦克风，让声音实时移动字母——比如音乐变响时轮廓变得粗糙，低音响起时花瓣张开，或者每个节拍上点都跳到新的位置。
- 把正在移动的字母录成**视频**（MP4 或 WebM），连同声音一起。

所有操作都在你的浏览器里完成，字体和音频文件不会被上传到任何地方。

---

## 2. 你需要准备什么

- 一台装有新版浏览器（Chrome、Edge、Firefox 或 Safari）的电脑。不支持手机和平板：这个工具是为大屏幕设计的。
- 电脑里的字体文件（`.ttf`、`.otf`、`.woff`、`.woff2`，或 `.ttc` / `.otc` 字体集合），**或者**能上网，以便从 Google Fonts 载入字体。
- 可选，供 **Sound** 标签页使用：一个音频文件（比如 MP3）或一个麦克风。
- 网页地址，例如 `https://m1ingx1xx1.github.io/None-Curve/`，也可以向搭建项目的人索取。

## 3. 认识屏幕

屏幕分成上下两行、五个区域：

```text
┌────────────────────────╥─────────────────────────────────────────────────────┐
│ ① 功能区               ║ ② 结果画布                                          │
│   Import 导入          ║   你输入的文字，实时重建                            │
│   字体信息             ║                                                     │
│   造型控制项           ║                                                     │
╞════════════════════════╩═╦══════════════════════════╦════════════════════════╡
│ ③ 排版、字形、颜色       ║ ④ Text 文字              ║ ⑤ Preview 预览         │
│   三个标签页             ║   在这里打字             ║   ② 的缩小版，         │
│                          ║                          ║   可模糊/反色          │
└──────────────────────────╨──────────────────────────╨────────────────────────┘
```

1. **功能区（左上）**——**Import**（导入）按钮、已载入字体的信息，以及三个标签页：**Geometry**（几何）和 **Experimental**（实验）里是决定字母形状的控制项，**Sound**（声音）用来聆听音频文件或麦克风，并能让字母随声音而动。向下滚动可以看到全部控制项。
2. **结果画布（右上）**——最大的预览区，显示一张固定尺寸的画布（类似一页纸），上面是你输入的文字，并按当前设置重建。要导出的那一页放在中间，带着柔和的阴影，像是稍稍浮在背景上。页面周围的背景稍暗一些，铺着浅浅的网格，所以页面本身保持干净，和导出效果完全一样。拖动文字时，或放大到 200% 以上时，网格也会出现在页面上，方便对齐。改动设置后，字母会在后台陆续更新——这期间应用照常可用，画布角落的标签会显示 “Updating…”，直到全部更新完。底部的 **Canvas size** 栏可以打开画布尺寸设置。
3. **排版、字形与颜色（左下）**——三个标签页。**Typography**（排版）设置文字的字号、间距、倾斜、对齐和位置。**Glyphs**（字形）列出字体里的每个字母、数字和符号：点击一个就会把它打进文字输入框，适合输入 `©`、`→`、带重音的字母这类不好打的符号。**Color**（颜色）设置文字和背景的颜色。
4. **Text 文字输入**——输入想在画布上看到的文字。
5. **Preview 预览**——一张小图，显示 SVG 导出会保存的样子：画布上的全部文字（实心字母，或在 **Fill** 关闭时只显示轮廓），并带有自己的 **Blur**（模糊）滑块和 **Invert**（反色）按钮。

页面最上方有一个 **Export…**（导出）按钮。录制视频时，它旁边会出现一个红灯、已录制的时间（例如 “Recording 0:12”）和一个方形的停止按钮（见[录制视频](#录制视频)）。撤销和重做没有按钮，用键盘操作（见下文[撤销与重做](#撤销与重做)）。最下方的状态栏会说明当前显示的内容和启用了哪些设置。

**亮色或暗色界面。** 状态栏最右端有两个小按钮——太阳和月亮——用来在亮色和暗色界面之间切换。每次打开时，程序都会跟随你电脑的亮色 / 暗色模式；你在这里的选择只在关闭页面前有效，不会被记住。画布不受影响：它的颜色来自 **Color** 标签页。

**一键从头开始。** 太阳和月亮左边有一个画着回转箭头的按钮（鼠标指着它会显示 **Reset all**，即全部重置），它会让程序回到刚打开时的样子：

- 字体关闭，所以也没有选中的字母；程序还会忘掉这个字体，下次打开页面时不会再出现（正在载入的字体会被放弃）；
- 文字变回示例文字（Lorem ipsum）；
- 每项设置恢复为初始值：Geometry、Experimental、Typography 和 Color 标签页，以及画布尺寸；
- 画布视图从头开始：**Flattened**，图层里只有 **Fill** 打开，整个画布都在视野内；
- Sound 标签页里的映射全部移除，**Response** 组的六个滑块恢复初始值，**Drive letters** 重新打开（如果你的电脑设置了“减少动态效果”，则是关闭）；正在播放的声音文件暂停，麦克风停止收音，但已载入的声音文件仍然保留；
- 预览的 **Blur** 和 **Invert** 关掉，**Coordinate precision**（坐标精度）恢复为 2，关于载入的配置文件或上次访问的提示也会消失。

保持不变的：亮色或暗色外观、各区域的大小，以及你打开的标签页。**它不能撤销**，也不会先询问你：重置之后没有可以撤销或重做的内容。如果之后可能还想找回现在的作品，请先导出，或者保存一个[配置文件](#保存为配置文件只含设置)。没有可以重置的内容时，这个按钮是灰色的（鼠标指着它会显示 “Everything is as the editor first opens”，即一切都和程序刚打开时一样）。

**调整各区域的大小。** 图中的双线就是各区域之间那些细细的灰线，可以拖动：

- **上下两行之间**——上下拖动，让画布或下面一行更高；
- **功能区和画布之间**——左右拖动；
- **排版 / 字形 / 颜色标签页和文字输入之间**——左右拖动；
- **文字输入和预览之间**——左右拖动。

一边变大多少，另一边就变小多少，所以整个界面始终正好放进窗口里，页面不需要滚动。每个区域都有最小尺寸。双击细线可以让它回到原来的位置。下次打开时程序会记住你的设置。

### 撤销与重做

撤销会撤回你最近的一次改动，重做再把它恢复。它们没有按钮，要用键盘：Mac 上 ⌘Z 撤销、⇧⌘Z 重做；Windows 和 Linux 上 Ctrl+Z 撤销、Ctrl+Shift+Z 或 Ctrl+Y 重做。程序最多保留 100 步。

- **可以撤销的：** Geometry、Experimental、Typography 和 Color 标签页里的每项设置、画布尺寸、文字，以及 Sound 标签页里的映射和 **Response** 组的六个滑块（Sensitivity、Strength、Motion contrast、Release、Pitch reactive 和 Melody tracking）。各个设置组的重置按钮也算在内，所以重置之后（包括 **Reset sound**）可以撤销，找回被清掉的设置。**Reset all** 是例外：它不能撤销（见[认识屏幕](#3-认识屏幕)里的“一键从头开始”）。
- **一步有多大：** 拖动一次滑块算一步，不管拖了多远。连续打字算一步，停顿片刻后再打就是新的一步。**Clear**、选一段示例文字、从 **Glyphs** 插入一个字符，各算一步。有些一次改动好几处的操作也只算一步：载入 Sound 预设、**Freeze**、载入配置文件，以及选择映射目标连同它顺带打开的设置。
- **不会撤销的：** 画布视图（Original / Flattened / Compare、图层按钮、缩放和移动）、选中的是哪个字母、预览的 Blur 和 Invert、导出设置、载入字体、Sound 标签页的 **Drive letters** 和声音来源，以及视频选项（**Format**、**Length**、**Include audio** 和 **Use the preview look**）。声音带动字母的变化也从不记录：只记录你自己的改动。
- **在输入框里时**——文字输入框，或者用来输入数字、颜色代码、名称的小框——快捷键只撤销你在这个框里打的字，和普通文本框一样。想按整步撤销，先点一下输入框外面（面板上的空白处）。打开着对话框（比如 **Export…**）时，快捷键不起作用。
- 关闭页面后这些步骤就没有了，所以下次打开时没有可以撤销的内容；按下 **Reset all** 时它们也会被清空。

### 下次打开时

程序会自动把你的作品保存在这个浏览器里（每次改动后稍等片刻就保存），下次在同一台电脑、同一个浏览器里打开时会恢复。

- **会保存的：** 文字；Geometry、Experimental、Typography 和 Color 标签页里的每项设置；画布尺寸；画布视图按钮（Original / Flattened / Compare 和各图层，但不包括缩放和移动到的位置）；预览的 Blur 和 Invert；导出的 **Coordinate precision**（坐标精度）；Sound 标签页的映射和 **Response** 组的六个滑块（Sensitivity、Strength、Motion contrast、Release、Pitch reactive 和 Melody tracking）；选中的字母（再次打开同一款字体时）；以及字体本身。
- **字体：** Google 字体会在页面打开时自动重新下载（需要联网）。来自你电脑的字体程序无法替你重新打开：画布上会显示 “Last font: *文件名*. Import it again to continue.”（上次的字体：……，请重新导入以继续）。导入同一个文件就能接着做——你的设置都还在。
- **不会保存的：** Sound 标签页的 **Drive letters** 和声音来源（文件或麦克风）；视频选项（**Format**、**Length**、**Include audio** 和 **Use the preview look**），它们只保留到关闭页面为止；打开着的对话框；亮色或暗色界面；以及撤销步骤。（和以前一样，程序也会记住各区域的大小、你打开的标签页、**Canvas size** 设置是否展开，以及 **Show all explanations**。）
- **旧版程序保存的作品：** Thorn 的 **Reach** 以前按 em（字母的设计正方形）的比例计算，现在改为按画布的比例计算（见 Experimental 标签页里的 Thorn）。以前保存的作品会按它保存时的字号和画布尺寸，换算成让刺保持同样长度的比例，所以刺会和原来一样。原来有刺的仍然有刺：刺再短，恢复后也至少是滑块第一档的长度。Sound 里作用在 Reach 上的映射行保留各自的 **Depth**。同一个 **Seed** 下，刺也可能长在和以前不同的点上，因为程序现在用一种更稳定的方式挑选它们（见 Experimental 标签页里的 Thorn）；多按几次 **Next variant**，直到你再次满意为止。Crumple 不再有 **Detail** 滑块：保存的 Detail 数值会被忽略，Sound 里作用在 **Crumple · Detail** 上的映射行会被去掉；Crumple 恢复了它改名前（还叫 Noise 时）的揉皱方式，所以同一个 **Seed** 得到的折痕和带 Detail 的版本不同。
- **如果页面在绘制你的设置时关闭了**——比如某个特别重的设置让浏览器撑不住了——下次打开时所有设置都会回到初始值，免得再次卡住，画布上会显示 “The last visit closed while drawing, so its settings were not restored.”（上次访问在绘制时关闭，所以没有恢复它的设置）。你的文字、字体、映射和 **Response** 滑块仍会恢复。
- **从头开始：** 大多数设置组都有重置按钮（**Reset anchors**、**Reset grid & angles**、**Reset distortion**、**Reset random anchors**、**Reset experimental**、**Reset typography**），Color 标签页里的 **Charcoal** 就是初始配色。状态栏最右端的箭头按钮（**Reset all**）关闭字体，并把文字和每项设置恢复成程序刚打开时的样子；它不能撤销（见[认识屏幕](#3-认识屏幕)里的“一键从头开始”）。如果还想忘掉各区域的大小和打开的标签页，就在浏览器设置里清除这个网站的数据（Cookie 和网站数据），然后刷新页面。
- **需要知道的：** 每个浏览器各存一份。如果在两个标签页里同时打开程序，以你最后改动的那个为准。Safari 可能会清除 7 天没有打开过的网站所保存的内容。想确保留住某个结果，请把它导出；想保留设置本身，或把它带到另一个浏览器，请保存一个[配置文件](#保存为配置文件只含设置)。

## 4. 五分钟快速上手

1. 点左上的 **Import** → **Google Fonts** → 选择 **Inter** → **Load font**。
2. 在文字输入框里输入一个词，比如 `Hello`。
3. 在功能区找到 **Curve flattening**（曲线展平），选择 **Fixed segments**（固定线段数），把 **Segments per curve**（每条曲线的线段数）设为 `2`。
4. 打开 **Merge joined curves**（合并相连曲线），字母会出现明显的折面效果。
5. 点顶部的 **Export…** → **SVG — main view** → **Download SVG**。

这就是完整的流程。本指南接下来会逐步详细说明。

## 5. 载入字体

点功能区最上方的 **Import**，会出现三个选项：电脑上的字体、Google Fonts 的字体，或者保存了设置的 **Config file**（配置文件，见[保存为配置文件](#保存为配置文件只含设置)）。

### 从电脑载入

- 选择 **Local file**（本地文件）并挑一个字体文件，**或者**直接把字体文件拖到大画布上。
- 支持 `.ttf`、`.otf`、`.woff`、`.woff2` 和字体“集合”（`.ttc`、`.otc`），最大 50 MB。
- **字体集合**把几种字体样式放在一个文件里——比如 Mac 上的 Helvetica Neue、Avenir Next 和 Futura。程序会打开最接近 Regular（常规）的那个样式，字体信息里的样式名会变成一个菜单，列出文件里的全部样式：在那里选另一个即可。这样切换样式时，你的文字、选中的字母（如果新样式里有它）和缩放都会保留。macOS 自用的几个隐藏样式（名称以点开头）不会列出。打包成 `.woff` 或 `.woff2` 的字体集合无法打开。
- 载入其他任何字体时，画布视图会重新开始：缩放到适合大小，并选中一个默认字母。
- 文件始终留在你的电脑上，只由浏览器读取。下次打开程序时，它会写出文件名并请你重新导入（见[下次打开时](#下次打开时)）。

### 从 Google Fonts 载入

选择 **Google Fonts**。在 **Family**（字体名称）框里，你可以：

- **从列表中选**——列出了 15 款字体，按无衬线、衬线、粗衬线和等宽分组（例如 Google Sans、Inter、EB Garamond、Bodoni Moda、Arvo、JetBrains Mono）。
- **输入字体名称**——任何 Google 字体都可以，但拼写要和 fonts.google.com 上完全一致（大小写也要一致：写 `Open Sans`，不要写 `open sans`），然后点 **Use "…"**。
- **粘贴链接**——在 fonts.google.com 上复制某款字体页面的地址，例如 `https://fonts.google.com/specimen/Plaster`，粘贴进来即可。带有字重或斜体信息的链接（例如 `…css2?family=Roboto:ital,wght@1,700`）也能识别。

选定字体后再设置：

- **Weight**（字重）——字有多粗（400 为常规，700 为粗体）。所有字体都可以选，包括把所有字重放在一个文件里的“可变字体”。
- **Italic**（斜体）——如果这款字体有斜体。
- **Character subset**（字符子集）——Google 按语言拆分字体文件（如 `latin`、`latin-ext`、`cyrillic`）。一次只载入一个子集，所以其他语言的字符可能缺失。

点 **Load font**。下载完成后，字体名称会出现在功能区。下次打开程序时，会自动重新下载同一款字体。

### 出问题时

功能区会显示发生了什么，并提供 **Retry**（重试）：

| 提示 | 含义 | 怎么办 |
|---|---|---|
| Empty file / Unsupported format | 文件不是字体，或者是空的。 | 换成 `.ttf`、`.otf`、`.woff`、`.woff2`、`.ttc` 或 `.otc` 文件。 |
| Font parsing failed | 文件已损坏。 | 换一份这款字体的文件。 |
| Google Fonts API error | Google 不认识这个名字。 | 检查拼写和大小写。 |
| Network / CORS error | 没有网络，或浏览器插件拦截了请求。 | 检查网络或广告拦截插件，然后点 **Retry**。 |
| Only fonts.google.com … URLs are accepted | 粘贴的不是 Google Fonts 链接。 | 粘贴来自 fonts.google.com 的链接。 |

新字体载入失败时，屏幕上会继续保留之前的字体。

## 6. 输入文字

- 在 **Text** 输入框（右下）里打字，按回车换行。
- **Clear** 旁边的示例菜单提供现成的示例文字：**Lorem ipsum**（假字填充）、**Pangrams**（包含所有字母的句子）、**Spacing**（如 “Hamburgefontsiv” 这类经典字距测试词）和 **Alphabet**（全部大写、小写、数字和常用标点，每组一行）。第一次打开程序时显示 Lorem ipsum；之后每次打开，都会显示你上次的文字。你改动文字后，菜单会显示上一个示例并标注 “(edited)”；再选一次它就能恢复原文。
- **Clear** 清空输入框。改主意了？撤销一下（Mac 上是 ⌘Z，其他系统是 Ctrl+Z）就能把文字找回来。
- **Text** 标题右边的 **AA**（全大写）、**Aa**（每个单词首字母大写）和 **aa**（全小写）会改变字母在画布和导出中的样子，你输入的文字本身不会变。再点一次高亮的按钮即恢复原样。（鼠标悬停在按钮上可以看到它的名称。）
- 输入框下方会显示字符数，以及是否应用了字体自带的**字偶距**（像 “AV” 这类字母组合之间的细微间距调整）。
- 如果某个字符在字体里不存在，画布上会显示一个**红色虚线框**，并在输入框下方列出；这一行的其余部分照常显示。
- 最多显示 1000 个字符。
- 不好直接打出来的符号，可以在左下的 **Glyphs** 标签页里点一下。它会插入到输入框里光标所在的位置（如果你还没点过输入框，就加在末尾）；如果你选中了一段文字，符号会替换掉它。
- 把 Glyphs 列表拖窄时，它只显示字符本身、不显示编码，这样能放下更多字符；拖宽就会重新显示编码（鼠标停在字符上也能看到）。
- **Glyphs** 列表上方的**搜索框**可以按字符本身（`A`）、编码（`U+0041`）或名称的一部分（`arrow`、`dieresis`）查找字符。

## 7. 查看结果

### 画布工具栏

**轮廓视图**——画出哪种形状：

- **Original**（原始）——字体原本的样子，带曲线，用来对比。
- **Flattened**（展平后）——套用你全部设置后的结果（默认）。
- **Compare**（对比）——灰色的结果上叠加蓝色虚线表示的原始曲线。

**图层**——可以开关的附加信息（一开始只开着 **Fill**）：

- **Fill**（填充）——实心字母。关闭后只显示轮廓线。它也会改变导出的内容：Fill 关闭时，预览、SVG、PNG 和视频里的字母都只画细细的轮廓线，里面是空的。字体文件里的字母始终是实心的。
- **Skeleton**（骨架）——决定原始曲线的点：蓝色方块在曲线上；空心橙色圆是牵引曲线的“控制点”；细线把它们连起来。
- **Vertices**（顶点）——新直线形状每个拐角处的绿色圆点。
- **Metrics**（度量线）——几条水平参考线：ascender（上伸线，“h” 这类高字母的顶部）、cap height（大写字母顶部）、x-height（“x” 的顶部）、baseline（基线，字母坐落的线）、descender（下伸线，“p”“g” 的底部）。

> 字母足够大时才会显示骨架点和顶点。如果画布提示 “Zoom in to see skeleton points and vertices”，请放大。

**缩放**——`−` 和 `+` 缩小、放大，**Fit** 重新显示全部文字。也可以在画布上滚动鼠标滚轮缩放，按住拖动来移动视图。

### 查看单个字母

- 点画布上的某个字母即可选中它（点在这个字母所占的位置里就行）。它在文字中出现的每一处都会换成高亮色。这个颜色根据你的文字颜色和背景颜色算出来，既醒目又容易看清——比如米色纸上的黑字会高亮成朱红色。鼠标指着某个字母时，它也会这样变色。从 Glyphs 列表插入字符时，也会选中该字符。
- 刺（见 Experimental 标签页里的 Thorn）不算字母所占的位置：点在刺伸出字母的那一段上，等于点它后面的东西，比如另一个字母，最常见的是画布的空白处。请点字母本身。开启 Thorn 时，字母靠它所占的位置和字体里原来的形状来点选，所以效果把字母画到远处的其他部分（比如 Slipstream 的拖尾）也选不中它。
- 点画布上的空白处，或按 Esc，即可取消高亮。拖动画布不会取消高亮。
- 造型控制项里的统计数字（顶点数、曲线数等）针对的是当前选中的字母；取消高亮后，针对的是你最后选中的那个字母。每个标签页顶部的 **Statistics** 一行始终写明是哪个字母，例如 “Statistics: l U+006C”。
- 预览从不显示高亮，因为它显示的正是导出后的样子。
- 想看细节，就在画布上放大。

### 预览：模糊、反色和宽度

右下角的 **Preview** 按 SVG 导出会保存的样子显示整张画布——画布以外的部分会被裁掉。

- 它始终只显示最终的字母：实心，或在 **Fill** 关闭时只显示轮廓，和导出的一样。除了 Fill，它不跟随大画布的 Original / Flattened / Compare 和图层按钮、缩放、吸附网格，也不显示缺失字符的虚线框：这些只在大画布上帮你查看，从不导出。
- 它的轮廓和 SVG 文件一样经过取整（见[保存作品](#10-保存作品导出)里的 **Coordinate precision**），所以这里看到的就是导出得到的。
- 打开 **Transparent background**（Color 标签页）时，空白背景显示为棋盘格。
- 如果把文字保存为 SVG 会失败，预览会改为显示 “Export would fail: …”（导出会失败）以及原因。
- Sound 标签页带动字母时，预览会跟着一起动。SVG、PNG 和字体导出仍然使用你的滑块（见 **Freeze**）；视频则录下正在移动的字母（见[录制视频](#录制视频)）。

- **Blur** 让预览变模糊，就像从远处看或眯着眼看。这样能抛开细节，只看字母整体的形状和节奏——可以快速检查粗糙或折面风格的文字是否仍然好认。
- **Invert**（反色）交换预览里文字和背景的颜色——浅底深字变成深底浅字，再点一次换回来。适合检查文字在两种配色下的效果，比如做招牌或深色海报时。
- Blur 和 Invert 只改变这个小视图。想把它们保存进文件，导出时勾选 **Export the preview look**。
- **想让预览更宽：** 拖动它左边的细线（见第 3 节“调整各区域的大小”）。

### 画布尺寸

文字排在一张固定像素尺寸的**画布**上，类似一页纸或一个画板。点大画布下方的 **Canvas size** 栏可以打开或收起它的设置：

- **W** 和 **H**——宽和高（像素）。拖动滑块或直接输入数字（按回车或点别处后生效）。
- **1:1、4:3、16:9、4:5、3:2、3:4**——常见画幅比例。宽度不变，高度随之调整。**Swap** 把横向画布变成竖向，或反过来。
- **1×、2×、3×、4×**——PNG 导出放大几倍。排版不变，倍数越高图片越大越清晰（下方会显示尺寸，例如 2400 × 1600 像素）。视频也用同样的尺寸，除非它超过 4K（见[录制视频](#录制视频)）。

如果文字太大放不进画布，大画布上会出现一条红色提示（“The text runs past the canvas edge and will be cut off in the preview and in exports. Try Typography → Fit text.”，文字超出了画布边缘，预览和导出时会被裁掉）；预览和导出会在画布边缘把文字裁掉。用 **Typography → Fit text** 可以让文字刚好放下。

刺（见 Experimental 标签页里的 Thorn）不算在内：它们可以远远伸出画布边缘，而不会出现红色提示。在大画布上，你能看到它们一直伸进画布四周颜色较深的区域；预览以及 SVG 和 PNG 导出则在画布边缘把它们裁掉。

Sound 标签页让字母动起来时，文字停在你的滑块所决定的位置，红色提示也按你的滑块做出的字母来判断。如果声音把某个字母扭得比你的滑块更远，这个字母可能伸出画布边缘而不出现红色提示：大画布上完整显示，但预览和视频会在边缘把它裁掉。

## 8. 造型控制项

这些控制项在左上的工具面板里，分为两个标签页。（第三个标签页 **Sound** 本身不改变字母的形状：它让字母随声音而动，就像在移动这两个标签页里的滑块和种子一样（它们本身停在你放的位置；每个滑块上的一条细线，或每个种子旁边的一个小数字，显示声音把它带到了哪里），见下文 [Sound 标签页](#sound声音标签页让字母随声音而动)。）**Geometry** 标签页按固定顺序从上到下依次生效，后面的步骤处理的是前面步骤的结果；**Experimental** 标签页在它全部完成之后生效：

**Curve flattening 曲线展平 → Squaring 方形化 → Anchors 锚点 → Grid & angles 网格与角度 → Distortion 扰动 → Experimental 实验效果**

所有尺寸都以**字体单位**计算。字体是在一个看不见的正方形（称为 **em**）上设计的，通常宽 1000 或 2048 个单位（字体信息里的 “Units/em”）。所以在 1000 单位的字体里，“20 u” 相当于字高的 2%。缩放画布不会改变这些设置的效果。

每个滑块名称旁边都有一个小数字框，显示它的值（单位是 %、°、u 等）。拖动滑块可以快速试效果；要设成一个精确的值，点一下数字框，输入数字，按回车（或点别的地方）即可。超出滑块范围的数字会被设成最近的那一端，按 Escape 恢复原来的值。滑块的每一档都很小——大多数是 1%，角度是 1°——点选滑块后，每按一次方向键就移动一档。

名称不够直观的控制项都有简短说明。为了让面板保持清爽，说明默认是收起的：点控制项名称旁边的小 **ⓘ** 就能展开阅读，再点一次收起。想一次看到全部说明（第一次使用时很有用），勾选工具面板顶部、标签页下方的 **Show all explanations**（排版和颜色标签页里的说明也会一起展开）。黄色警告和统计数字始终显示。如果某个设置会破坏形状（例如让字母自己交叉，或者把 **A**、**B**、**e** 中间的空洞推到字母外面、显示成一块实心），程序会先为字母的那一部分尝试一个温和一些的版本——少一点方形化、稍微简化的轮廓、角度锁定改用阶梯、或者小一点的扰动——并用一条灰色提示说明。只有都行不通时，那一部分才会保持上一步的样子，并出现一条黄色提示说明原因。

### Curve flattening（曲线展平）——曲线如何变成直线

先选一种 **Mode**（模式）：

- **Adaptive**（自适应）——尽量贴近原形。**Tolerance**（容差）是直线允许偏离曲线的距离。数值小（0.1–2）时几乎和原字一样；数值大（20–500）时明显有棱角。单独使用 Adaptive 时，大约到 100 就不会再变粗犷了——打开 **Merge joined curves** 才能更进一步。
- **Fixed segments**（固定线段数）——每条曲线都换成同样数量的直线。**Segments per curve** 设置这个数量（1–32），线越少越粗犷、折面感越强。

**Merge joined curves**（合并相连曲线，两种模式都可用）——获得强烈折面效果的关键。你眼中的一条弧，在字体里通常由好几小段曲线拼成。不合并时，设置作用于每一小段，字母看起来仍然平滑；合并后，整条看得见的弧才算一条曲线：

- 在 **Fixed segments** 下，把 **Segments per curve** 依次设为 4、3、2，从含蓄过渡到强烈；
- 在 **Adaptive** 下，调大 **Tolerance**（试试 50、150、500）：每条弧会在容差允许的范围内尽量拉直，最多变成一条直线。

下面的合并设置两种模式共用，切换模式时会保留。

- **Break merged curves at**（在哪里断开合并的曲线）——一条合并曲线在哪里结束、下一条从哪里开始：
  - **Corners & extremes**（尖角和极值点，默认）——在尖角处，以及每个圆形最左、最右、最上、最下的点断开。圆形的 “O” 会分成四段四分之一弧，折面均衡对称。
  - **Corners only**（只在尖角）——只在尖角处断开。像 “O” 这样整圈平滑的形状会变成一条曲线，可能得到三角形或非常简化的形状。
- **Merge through straight lines**（穿过直线合并）——把平滑流进曲线的直线部分也一起合并，比如 n、m、u 的竖笔流进弧线的地方。它们会和曲线一起被重新塑形，得到粗犷得多的“低分辨率”效果。竖笔的端点可能被削掉，所以默认关闭。
- **Corner angle**（尖角阈值）——拐弯要多急才算尖角（默认 15°），比它平缓的拐弯会被合并。单独调它几乎看不到变化，因为字体内部的曲线几乎总是平滑相接的。**打开 Merge through straight lines 后它才真正起作用：** 把角度调大（试试 45° 和 90°），每个字母会有越来越多的部分合并成几笔大的折线。

### Squaring（方形化）——让圆形字母变方

把圆形推向矩形。设为 **100%**（“Square”）时，圆形的 **O** 和它中间的洞都会变成正方形，笔画粗细保持不变。

- **Amount**（强度）——0% 为关闭，**Soft** 为一半，**Square** 为完全方形；中间的值用滑块调。
- **Applies to**（作用范围）：
  - **Round contours**（只作用于圆形轮廓，推荐）——只改变接近圆或椭圆的形状，如 O、o、0，以及 b、d、g、p、q 的圆腔。A、E、S 这类直线或尖角形状保持原样。
  - **All contours**（所有轮廓）——每个形状都推向矩形。效果强得多，有些字母可能会显得奇怪。

小技巧：方形化之后，加一点 **Anchor reduction**（锚点简化，例如 2），直边会更干净。

### Anchors（锚点）——轮廓上有多少个点

- **Anchor spacing**（锚点间距）——在直线边上加点，使每段都不超过这个长度。形状不变，但后面的步骤（比如扰动）会有更多点可以处理。0 为关闭。
- **Anchor reduction**（锚点简化）——去掉对形状影响很小的点。数值越大去掉的点越多、字母越简化；数值过大可能抹掉小细节。0 为关闭。
- 两者同时开启会互相抵消（简化会删掉刚加上的点），界面会提示。
- **Reset anchors** 同时关闭两者。

### Grid & angles（网格与角度）——构成感、几何感的造型

- **Snap to grid**（网格吸附）+ **Grid size**（网格大小）——把每个点移到一张看不见的网格上，就像在方格纸上画字。网格越大，字母越像像素块。开启时，画布上会淡淡地画出网格。
- **Angle lock**（角度锁定）+ **Allowed directions**（允许的方向）——把每条边拉直到固定的几个方向：
  - **90°**——只有水平和垂直线。
  - **45°**——再加上对角线。
  - **30°** / **15°**——更细的角度间隔。
- 如果拉直会让字母的某部分移动太远，那一部分会改成小阶梯，字母不会跑出原来的位置。
- 两者同时开启时先吸附网格，所以角度锁定可能会让部分点稍微离开网格。
- **Reset grid & angles** 同时关闭两者。

### Distortion（扰动）——粗糙、手工或石刻般的边缘

以可控、可重复的方式移动轮廓上的点。

- **Noise amplitude**（噪声幅度）——点最多移动多远。0 为关闭。小数值（5–20）带来轻微的手工切割感；大数值像被磨损或侵蚀。
- **Noise frequency**（噪声频率）——边缘起伏的密度。低：缓慢、温和的波浪；高：急促、细碎的粗糙感。
- **Normal bias**（法线偏向）——点移动的方向。0% 让点沿着边滑动；100% 让边向内外凹凸。
- **Seed**（种子）——选择某一种随机图案的数字。同样的种子永远得到完全相同的结果，所以可以随时找回喜欢的版本。**Next variant** 换成下一种图案。
- **Reset distortion** 关闭扰动，但保留你的种子。

**载入 Flicker 之后可能看到的说明。** Sound 标签页的 **Flicker** 预设会把 Distortion 切换到一种特殊模式：每个字母只有少数几个点移动——最多五个——拐角和最外侧的点保持不动，所以字形得以保持。每个移动的点都跳得很明显，换一个种子就换另外几个点。这个模式没有开关，所以面板上会显示 “Only a few anchors move (set by the Flicker preset in the Sound tab). Reset distortion moves every anchor again.”（只有少数锚点移动，由 Sound 标签页的 Flicker 预设设置；按 Reset distortion 让所有锚点重新移动），并多出一个数字 **Anchors moved**（移动的锚点数），统计移动了的点。想回到普通的扰动，按 **Reset distortion**（它也会把 Noise amplitude 设回 0，所以要再把它调高），或者载入另一个预设。

扰动可能会降低文字的可读性，请适度使用。

### Random anchors（随机锚点）——每次都不一样，但可以复现

位于 Geometry 标签页的最底部。平时程序会在曲线上按规则的间距放点（即 Curve flattening 曲线展平）。打开 **Use random anchors** 后，点改为放在字母原始轮廓上的随机位置——点始终落在真实的字母上，随机的只是“放在哪里”。后面的控制项（Squaring、Anchors、Grid & angles、Distortion）照常叠加。

随机锚点开启期间，**Curve flattening** 的控件会变灰并附上说明，因为随机锚点取代了它们——调了也不会有变化。关掉随机锚点即可恢复使用。

- **Density**（密度）——每 1000 字体单位轮廓大约放多少个点。数值小（2–6）字母会变得粗糙、块状；数值大则接近原字形。
- **Randomness**（随机程度）——0% 时点均匀分布；100% 时每个点可以在自己的一小段范围内随意移动。点与点之间不会互换位置，所以字母不会缠在一起。
- **Keep sharp corners**（保留尖角）——保留字母真正的尖角（例如竖笔末端和衬线），让它们保持干净利落。关掉后效果更松散。
- **Seed**（种子）——决定某一个随机结果的数字。
  - **Shuffle** 随机换一个新种子，并显示在输入框里。
  - **Copy** 复制种子，方便贴到你的笔记里。
  - **Previous** 列出你这次打开页面后试过的种子（关闭页面后这个列表不会保留），点一下就能回到那个结果。
  - 想以后重现某个结果：载入同一个字体，使用相同的设置，把种子输入到框里即可。
  - **Randomness** 为 0% 时点是均匀分布的，种子不起作用，会变灰。
- **Reset random anchors** 关闭随机锚点并恢复其他设置，但保留你的种子。

种子也会显示在底部的状态栏和导出对话框里，所以导出时它会被一起记录下来。

### Experimental（实验）标签页——可以叠加的效果

在工具面板顶部、**Geometry** 标签页的旁边。这里的效果作用在 Geometry 标签页的最终结果上，可以同时打开任意多个。**Crumple**、**Ripple**、**Whorl** 和 **Slipstream** 都沿**笔直的折痕**弯折字母：只会增加棱角，不会产生曲线。在 100% 以内，它们的任何组合都不会让字母自己交叉，也不会把 **A**、**B**、**e** 中间的空洞推到字母外面。另有几样东西是直接画到字母上的，同样只用直线：**Slipstream** 的切口和拖尾，以及 **Thorn** 的刺，刺可能穿过字母（见下文）。这些效果始终按同一顺序运行：先 **Crumple**，再 **Ripple**，然后 **Whorl**，接着 **Slipstream**，最后 **Thorn**。（早先的版本把它们叫作 Noise、Ripple、Curl、Wind 和 Spikes。）

**超过 100%——翻折。** Crumple、Ripple、Whorl 以及 Slipstream 的 Gustiness 都可以超过 100%（Whorl 正反两个方向都可以）。超过之后，字母会像被压扁的纸一样折到自己身上：笔画叠到别的笔画上，空洞被填上或被撕开，字母不再认得出来。凡是重叠的地方都会合并成一个干净的形状，仍然只由直线组成，所以字体照样可以导出。有效果超过 100%、打开了 **Thorn**，或者 **Slipstream** 在字母上切了口时，标签页顶部会显示合并了多少处（**Crossings merged**），以及略去了多少小到看不见的碎屑（**Slivers dropped**）。

**设置太重时。** 每一道翻折、折痕、切口和刺都会给字母增加拐角，几个密集的效果叠在一起，可能增加几十万个——多到既画不快，也存不下。所以每个字母都有一个上限：这些效果最多给它增加大约 6,000 个拐角。单独一个效果和 Sound 的预设都不会超出。组合超出上限时，字母会被简化：一步步略去最小的细节，直到放得下为止。画布、预览和所有导出里得到的都是同一个简化后的字母，并可能出现这些黄色提示（前三条在标签页顶部，最后一条在该效果自己的设置组里）：

- “Simplified: these settings make too many vertices or crossings, so the outline was reduced (tolerance N u).”（已简化：这些设置产生的顶点或交叉太多，轮廓已被精简）——小于大约 N 个字体单位的细节被略去了。如果这是选中的字母，状态栏里它的顶点数后面也会加上 **(simplified)**。
- “Too complex to merge; lower the settings.”（太复杂，无法合并；请调低设置）——即使简化之后，重叠的部分仍然多到无法合并，所以字母以简化但未合并的样子显示。它看起来仍然是实心的，但调低设置会得到更干净的结果。
- “Overlaps could not be merged; the outline is left as it is.”（重叠部分无法合并；轮廓保持原样）——很少见：这个字母的合并出了问题，或者它的刺伸得太远、无法合并，所以重叠的部分保持未合并，而不是被弄坏。
- “This glyph is left without *效果名*: too complex.”（这个字形太复杂，没有套用该效果；Thorn 的提示是 “…without roots or refraction…”）——这一个效果会在这个字母里产生多得离谱的拐角，所以这个字母不套用它。

几个滑块同时推到极端时，字母会变成几块粗糙的宽板。这是正常的：已经没有余地容纳细节了。把其中一两个效果调低，细节就会回来。

**Crumple——揉皱的纸**

- **Use crumple**——打开该效果。
- **Amount**（强度）——字母被揉皱的程度，最高 500%。数值小时像轻轻手折过；100% 时折痕锐利明显；再往上折痕会互相翻过去，接近 500% 时字母碎成一堆互相叠压的碎片。
- **Facet size**（刻面大小）——折痕的大小，按 em（字体的设计正方形）的比例计算。刻面小，折痕多而细；刻面大，折痕少而大，能让整个笔画弯折。最小值也会让折痕之间保持足够距离，看起来仍是棱角。
- **Turn**（转向）——折痕往哪边走。调大 **Amount** 时，每条折痕都沿同一个方向越推越远；Turn 让它们换一个方向，而折痕的位置不变。180° 时就是反方向揉。（Seed 下面的 **Next variant** 则是换一张全新的纸。）
- 统计数字显示轮廓最多移动了多远（**Max move**），以及折痕增加了多少个角（**Creases**）。

**Ripple——多边形波纹**

- **Use ripple**——打开该效果。
- **Amount**（强度）——波纹把轮廓推出、拉回的程度。50% 左右字母仍然好认；100% 时，波纹圈之间的笔画会被挤成细片，字母被撕成尖锐、破碎的形状；再往上（最高 400%），各圈互相穿过，字母折成尖刺状、星形般的形状。
- **Reverse**（反向）——把外和内对调：原来被推出去的圈改为被拉回来，反之亦然。打开 **Petals** 时，花瓣尖从各个角移到每条边的中点，各个角则被往里拉。初始为不勾选。
- **Wavelength**（波长）——相邻两道波之间的距离，按 em 的比例计算（最高 200%）。波长短，锯齿多而细；波长长，整个笔画都会弯折，甚至整个字母都会胀大。
- **Sides**（边数）——波纹圈的形状：3 是三角形，4 是正方形，8 是八边形，最多 12。波纹圈总是平放在一条边上。
- **Center X / Center Y**（中心 X / Y）——波纹从哪里开始，按每个字母的宽度和高度的比例计算（50% / 50% 是字母正中）。小于 0% 或大于 100% 时中心在字母外面，波纹会从一侧扫过字母。
- **Fade**（衰减）——离中心越远波纹减弱得越多。100% 时到字母最远的边缘就完全消失。
- **Petals**（花瓣）——把波纹圈变成一朵由直边花瓣组成的花，每条边一片，所以花瓣数由 **Sides** 决定（3 是三叶形）。数值小时，**o**、**e** 这类圆形字母里会出现一朵多面的小花；100% 及以上（最高 300%）时整个字母变成一朵大花，花瓣之间的凹口会把笔画掐成发丝线。只开 Petals 永远不会让字母翻折；配合超过 100% 的 **Amount**，可以得到翻折、混乱的花朵。

**Whorl——漩涡**

- **Use whorl**——打开该效果。
- **Amount**（强度）——字母绕自己中心旋转的程度，范围 −400% 到 400%。低于 0% 时改为顺时针转。60% 左右字母有明显的扭转；100% 时，在每个字母都保持原有形状的前提下转得最远。能转多远取决于 **Sides** 和 **Rings**：3 条边时约十二分之一圈，12 条边、圈数多时超过一整圈。正反方向超过 100% 时，各圈互相转过头，字母折到自己身上。
- **Pin top and bottom**（固定上下）——勾选（默认）：每个字母的顶和底留在原处，中间被拧转。不勾选：中间留在原处，改为外侧转动，所以顶和底也被甩过去，整个字母都转起来。
- **Rings**（圈数）——漩涡由多少圈组成，从字母中心一直到它的顶和底（2–12）。圈数少，刻面大而粗犷；圈数多，漩涡由许多小直线段拼成，更细密。
- **Sides**（边数）——圈的形状：3 是三角形，4 是正方形，8 是八边形，最多 12。边数越多，字母翻折之前漩涡能转得越远。

**Slipstream——被气流卷住的字母**

字母被一股急流卷住：每个字母的细切片彼此错开滑动，气流把字母拉长，细细的切口切进字母，后面还拖出缕缕拖尾。

- **Use slipstream**——打开该效果。
- **Direction**（方向）——气流流向哪里：0° 向右，90° 向上，180° 向左，270° 向下。
- **Strength**（强度）——字母被拉长多少（初始为 15%）。面向气流的一侧保持不动；字母的某一部分离这一侧越远，就被拉得越远。100% 时，每一部分被拉出的距离等于它离迎流侧的距离，800% 时是八倍（但最多 4 em），所以字母会远远伸进相邻的字母。
- **Slip**（错位）——切片彼此错开多远，按 em 的比例计算（初始为 15%，最高 60%）。字母被横着气流切成一片片，顺着气流滑开，就像把一叠扑克牌往旁边一推：几个大的错位，中间夹着小的。无论错开多远，都不会让字母翻折。
- **Gust size**（阵风大小）——切片的宽度，也是阵风拉动的条带宽度，按 em 的比例计算。气流水平（0° 或 180°）时，同一行的所有字母共用同样的条带，所以错位和尾迹会笔直地贯穿整行文字。
- **Gustiness**（阵风度）——拉长字母时各条带之间的差别。0% 时每条带被拉得一样多，字母只是被拉长；100% 时有的条带几乎不动，有的被拖得很远，留下参差、直边的尾迹；超过 100%（最高 200%）时部分阵风反向吹，把字母撕开。
- **Cuts**（切口）——顺着气流在每个字母上切出几道细长的楔形缝（初始为 2，最多 8）。每道切口在切入处最宽，然后收窄成一个尖，停在笔画里面；大约四道里有一道整个穿过字母。
- **Trails**（拖尾）——每个字母顺着气流拖出几条细细的拖尾（初始为 2，最多 8）。它们从字母背向气流那一侧的外边缘长出来，**Strength** 越大拖尾越长。拖尾永远不会撞上字母或另一条拖尾，所以地方不够时，字母得到的拖尾会少一些。
- 统计数字显示轮廓最多移动了多远、增加了多少个角；有切口或拖尾时，还显示选中的字母得到了几道切口和几条拖尾（**Cuts**、**Trails**）。

**Thorn——向外刺出的刺**

每个字母外侧轮廓上的几个点（锚点）会径直跳出字母、伸进画布，变成又长又直的刺，并把字母一起拉动：笔画倾斜、变细，空洞朝刺的方向弯。只有字母的外轮廓会长刺：**o**、**e**、**B** 这类字母里的空洞永远不会（不过它们可能会弯）。Thorn 最后运行，作用在其他效果处理完的字母上，但它是在这些效果和 **Distortion** 之前的字母上挑选点的（见下面的“**其他设置变动时，刺留在原处**”）。

- **Use thorn**——打开该效果。
- **Anchors**（锚点数）——每个字母有几个点跳出去，1 到 12（初始为 3）。
- **Reach**（伸出距离）——点跳出多远，按画布的比例计算（初始为 10%；数字框显示为例如 “10”，后面跟着 “% canvas”）。100% 是画布的对角线，即从一个角到对面那个角的距离，所以 100% 时一根刺可以横穿整张画布。每个点跳的距离各不相同，在 Reach 的大约三分之一到全部之间，所以刺长短不一。0% 时没有点跳出。
  - 这个滑块左边细、右边粗，所以短刺很容易调得精确：轨道正中间只是 12.5%，右半段才覆盖其余直到 100% 的部分。在最左端，每一档（或每按一次方向键）增加 0.01%，所以哪怕第一档也会长出小小的刺；只有 0 不长刺。数字框显示的距离精确到两位小数，也可以直接在框里输入精确值，例如 0.35。
  - 因为 Reach 按画布计算，改变文字的 **Size**（字号）或画布尺寸（**W** 和 **H**）时，刺在画布上所占的比例保持不变：文字越小或画布越大，刺相对字母就伸得越远。Thorn 打开时，这样的改动会让程序重新计算字母。PNG 的放大倍数（1×–4×）不影响它。
  - Reach 旁边的 **ⓘ** 会告诉你，在当前字号和画布下 100% 相当于多少个 em：初始画布（1200 × 800 像素、48 像素的文字）上大约是 30 em。无论文字多小，它都不会超过 256 em。
  - 变长的只有刺尖：**Root**、**Width** 和 **Flute width** 仍按字母本身计算，所以不随画布改变。
  - 底部的状态栏和导出对话框会连同它的 em 长度一起显示，例如 “reach 10% canvas (about 3.0 em)”。
- **Reverse**（反向）——刺不再向外刺出，而是射进字母里：从相同的点、以相同的角度出发，并走完全部长度。刺穿过笔画的地方会刻出一道细细的白缝；穿过空洞、或从字母另一侧穿出的地方，则显示为墨色的尖刺。**Back thorn** 和 **Dent** 照样起作用：凹陷仍然陷进笔画，每根反刺从笔画的另一侧出发，反向穿过笔画，在白缝旁边穿出，成为一根墨色的尖刺。初始为不勾选。
- **Root**（根部）——每根刺把它周围的字母带动多少（初始为 50%）。刺从一个宽阔的底部长出，收窄成尖锐的刺尖，附近的笔画和空洞都朝它倾斜、弯曲。0% 时刺只是贴上去的，周围的字母保持原样。
- **Spread**（散开）——点往哪个方向跳（初始为 50%）。0% 时每个点都垂直于轮廓笔直向外跳；Spread 越大，每个点越可能偏向左右两侧，100% 时最多偏 90°，刺朝各个方向散开。
- **Width**（宽度）——每根刺的刺尖离开底部的地方有多宽（初始为 30%）。0% 时是一根细针；100% 时刺尖和底部开始收窄处一样宽。
- **Back thorn**（反刺）——让每根刺看起来像把笔画整个贯穿了（初始为 0%，即关闭）。在刺背后笔画结束的地方，另一根更短的刺朝相反方向射出：射进 **o** 这类字母的空洞，或从字母另一侧穿出。100% 时它有刺长的一半。偏向一侧太多的刺、背后的笔画弯走了的刺（第二根刺会沿着笔画在别处穿出，而不是正好在它背后），或者反刺会紧挨着另一根刺的，就不长反刺。
- **Dent**（凹陷）——让每根刺两侧的轮廓陷进笔画，紧挨着刺的地方最深，沿轮廓走一小段后逐渐消失（初始为 0%，即关闭）。100% 时大约陷进笔画厚度的一半，笔画细或弯曲的地方陷得更浅。它永远不会穿到笔画的另一侧，也不会把字母切断，遇到下一根刺或轮廓拐角时就停下。因为偏得太多或背后笔画弯走而不长反刺的刺，也没有凹陷。
- **Refraction**（折射）——让字母看起来像隔着一块竖条纹（凹槽）玻璃（初始为 0%，即关闭）。字母被切成一条条竖条，每条稍微放大，并上下移动一点，所以笔画和刺看起来是断开、错位的。玻璃只盖住字母本身的宽度，再加两侧各一条竖条：刺向左或向右伸出这个范围的那一段，保持尖锐笔直。朝上或朝下的刺则整根都在玻璃后面。
- **Flute width**（条纹宽度）——玻璃每一条竖条有多宽，按 em 的比例计算（初始为 10%）。**Refraction** 为 0% 时它是灰色的。
- 统计数字显示有多少个点跳了出去（**Thorns**）、长出了多少根反刺（**Back thorns**，Back thorn 大于 0% 时显示）、有多少个点带动了字母（**Roots**），以及跳得最远的那个有多远，单位是字体单位（**Longest**）。
- **由种子决定位置。** 哪些点跳、往哪边偏、各跳多远，以及玻璃竖条怎么移动，都由这个标签页的 **Seed**（见下文）决定：种子相同，刺就相同；**Next variant** 让它们跳到别的地方。用 Sound 标签页驱动这个 Seed 时（例如 **Beat** → **Seed**，或者 **Flare** 预设），它们会随着节拍跳到新的地方，每次只有少数几个字母（见 Sound 标签页里的“**刺轮流变化**”）。
- **其他设置变动时，刺留在原处。** Thorn 在 Geometry 标签页于 **Distortion** 之前做出的字母上挑选点，以及每根刺指向哪里，然后在 Distortion 和这个标签页的其他效果弯曲字母时一路跟着每个点。所以稍微调动 **Distortion** 的滑块或 **Crumple**、**Ripple** 的 **Amount**，或者换一个 Distortion 种子时，几乎每根刺都留在原来的点上、指向不变，字母在它周围弯曲。Crumple 和 Ripple 的其他滑块，以及 **Whorl** 和 **Slipstream** 的滑块，会改变这些效果弯曲字母的方式，所以仍可能移动或转动刺。这个标签页的 **Seed** 会挑选新的点；改动 Distortion 之前的几何设置（例如 **Curve flattening**、**Squaring**、Anchor spacing 或 **Grid & angles**）也可能如此，因为它们改变了点本身。Thorn 自己的 **Anchors** 滑块只增加或减少刺，其余的刺留在原处。也因为这样，同一个种子得到的刺和旧版程序不同。
- **刺可以交叉。** 刺可能横穿自己所在的字母，或者穿过另一根刺。交叉的地方会合并成一个干净的轮廓，和上面的翻折一样，所以字体照样可以导出。每根刺都只由直线组成。
- **刺不会移动文字。** 文字放在哪里（Typography 标签页的 **Position** 和 **Free**）、**Fit text**，以及文字超出画布边缘时的红色提示，都只看去掉刺之后的字母，和关闭 Thorn 时完全一样，用了 **Slant**（倾斜）也是如此。所以刺可以伸出画布：在大画布上，它们一直伸进画布四周颜色较深的区域；预览以及 SVG 和 PNG 导出则在画布边缘把它们裁掉。要选中一个字母，或者用 **Free** 拖动文字，请点或拖字母本身，而不是刺。
- **字体文件里很长的刺。** 字体文件把每个字母存放在一个大小有限的正方形里（每 em 2048 单位的字体是 16 em 宽，每 em 1000 单位的是 32.8 em；见[保存为字体（OTF）](#保存为字体otf)）。伸得更远的刺尖在导出的字体里会在正方形边缘被切掉；画布、SVG 和 PNG 不受影响。
- **试一试：** 勾选 **Use thorn**，把 **Anchors** 设为 1、**Reach** 设为 20%，然后多按几次 Seed 下面的 **Next variant**：每按一次，每个字母都有一个点刺向别的地方，并把字母一起拖动。调高 **Back thorn** 和 **Dent**，就能看到每根刺像把笔画贯穿了一样。再调高 **Refraction**，就能看到字母像隔着竖条纹玻璃。

**Seed**（种子）——这个标签页上所有效果共用一个数字：它决定 Crumple 的折痕；Slipstream 的阵风、错位、切口和拖尾；以及 Thorn 移动哪些点、玻璃竖条怎么移动（Ripple 和 Whorl 没有随机性）。种子和设置相同，字母就相同；**Next variant** 换下一个。**Reset experimental** 关闭所有效果并恢复其设置，但保留你的种子。

同一个字母的每次出现折痕、切口、拖尾和刺都一样，所以导出的字体与画布上看到的完全相同，只有很长的刺会被字体文件切短（见上面的 Thorn）。

### Sound（声音）标签页——让字母随声音而动

第三个标签页，在 **Experimental** 旁边。它播放一个音频文件，或者通过麦克风收音，并边听边测量声音：有多响、低音 / 中音 / 高音各有多少、听起来有多亮、正在响的是哪个音、节拍落在哪里、声音有多热闹，以及声音偏左还是偏右。它还能让字母随声音而动：把一个读数（比如响度）连到一个滑块（比如 Distortion 的 **Noise amplitude**）上，音乐播放时，声音变响字母就变得粗糙，声音变轻字母又平静下来。你也可以把读数连到一个**种子**上，让字母上的点在每个节拍上跳到新的位置（见下文的 **Mappings** 和**种子**）。**Response**（响应）组的滑块决定字母回应得有多强，**Record**（录制）可以把移动的字母存成视频（见[录制视频](#录制视频)）。

声音只会移动滑块和种子，而且只在它们自己的范围内移动，所以你看到的每个字母，都是你自己拖滑块、填种子也能做出来的——和程序里其他结果一样，全部由直线构成。（开启 **Motion contrast** 或 **Pitch reactive** 时，同一时刻不同的字母可以有不同的反应幅度；开启 Thorn 时，字母的刺轮流变化，所以两个字母可能处在不同的滑块数值上；但每一个仍然是滑块能做出来的形状。）

你的音频始终留在浏览器里：文件只在你的电脑上读取，从不上传；麦克风只在收音期间使用。

**Source**（来源）——声音从哪里来：

- **File**（文件）——电脑里的音频文件。标签页一开始就是这个选项。
  - **Choose file**（选择文件）——挑选文件。常见格式基本都可以（MP3、WAV、AAC、OGG 或 FLAC，取决于你的浏览器），最大 512 MB。按钮旁会显示文件名和时长（分:秒）；文件名太长时会被截短，鼠标指着它可以看到全名。
  - **Play** / **Pause**（播放 / 暂停）——通过扬声器或耳机播放文件。选好文件之前，**Play** 和 **Position** 是灰色的。
  - **Loop**（循环）——文件播完后从头再放。默认是勾选的。
  - **Position**（进度）——拖动可以跳到文件的其他位置。旁边的数字显示当前位置和总时长，例如 “0:42 / 3:15”。
- **Microphone**（麦克风）——你周围的声音，比如房间里放的音乐、你的说话声或拍手声。
  - 选中 **Microphone** 会暂停文件，并出现 **Start listening** 按钮，点它才会打开麦克风。第一次使用时，浏览器会询问是否允许这个页面使用麦克风：点 **Allow**（允许）。
  - **Stop listening**（停止收音）关闭麦克风；**Start listening**（开始收音）重新打开。
  - 收音期间，按钮旁显示 **Listening**（正在收音），底部状态栏显示 **Microphone on**（麦克风已开启），所以在任何标签页都能看到。
  - 如果麦克风自己停了（被拔掉，或者浏览器的权限被收回），收音会结束，标签页会显示 **The microphone stopped.**（麦克风已停止），状态栏会显示 **No microphone**（没有麦克风）。如果开始收音时找不到麦克风，状态栏也会这样显示。
  - 麦克风的声音只被测量，从不回放，所以不会通过扬声器产生啸叫。
  - 点 **Stop listening**、切回 **File**，以及关闭页面，都会关闭麦克风。
- 没有“关闭”这个选项：想停下来，就按 **Pause**（文件）或 **Stop listening**（麦克风）。切回 **File** 时，之前选的文件还在，处于暂停状态。
- 如果文件正在播放或麦克风正在收音，却连续 3 秒听不到声音，标签页会显示 **No sound detected.**（没有检测到声音）。检查一下音量、麦克风是否静音，或者调高下面的 **Sensitivity**。

**Levels**（电平）——此刻的声音是什么样的：11 个读数，分成五组，每个读数占一行：名称、条形表和数字。点组名旁边的 **ⓘ** 可以看到简短说明。没有播放或收音时，条形表是空的，数字显示 “—”。大多数数字是百分比：满格就是 100%。

- **Loudness**（音量）
  - **Level**（响度）——声音整体有多响。数字的单位是分贝（dB）：−60 dB 时条形表是空的，0 dB 时是满的，0 dB 是录音能达到的最大响度。没有声音时显示 “—”。
  - **Swell**（缓变响度）——放慢了的 Level：上升大约要三分之一秒，回落要好几秒，所以它跟随的是音乐的大轮廓——安静的主歌、响亮的副歌——而不是每一下鼓点。适合大幅、平稳的变化。
- **Bands**（频段）——**Bass**、**Mids**、**Treble**（低频、中频、高频）：低音（250 Hz 以下：底鼓、贝斯）、中音（250–2000 Hz：人声和大多数乐器）和高音（2000 Hz 以上：镲片、嘶嘶声、“s” 这类声音）各有多少。每一个都和它自己在最近几秒里最响的时刻比较，所以条形表会随音乐自动调整：满格的意思是“和这部分声音最近最强的时候一样强”，而不是“非常响”。
- **Tone**（音色）
  - **Brightness**（亮度）——能量集中在哪里：沉闷、低音重的声音读数低；嘶嘶声和镲片读数高。
  - **Pitch**（音高）——正在演奏或演唱的音。它针对的是一次只有一个音的声音，比如人声或旋律。数字的单位是赫兹（Hz）：数字越大，音越高（440 Hz 就是乐队调音用的那个 A）。55 Hz（贝斯最低的那个 A）时条形表是空的，1760 Hz（高五个八度）时是满的；每个八度占条形表的五分之一。两个音之间（比如一下鼓点的时候）它保持上一个音；静音时它会回落，并显示 “—”。
  - **Melody**（旋律）——每当曲调换到一个新的音，它就跳起，然后按下面 **Release** 设定的速度回落。换到的音离原来越远、音越清晰，它跳得越高。和 Pitch 一样，它针对的是一次只有一个音的声音，比如人声或旋律。持续的长音不算；停顿之后滑进第一个音、歌手声音里的轻微颤动（颤音）也不算。新的音要持续一小会儿才算，所以很快的一串音里可能漏掉几个，很强的颤动偶尔也会被当成一个新的音。
- **Rhythm**（节奏）
  - **Beat**（节拍）——立即跳到满格、然后回落的条形表，回落的快慢由下面的 **Release** 决定。它在每个突然开始的新声音上跳起：一下鼓点、一次拍手、拨一下琴弦。它还会单独留意底鼓，所以大多数舞曲和流行音乐里那种低沉的 “咚”，即使被其他声音盖住，也会让它跳起。持续不变的声音不算，哪怕是嗡嗡作响、持续不断的低音：只有某个音区的声音突然变响时，Beat 才会跳起。因此，如果同时有一个很响的低音，比它轻很多的底鼓可能会被漏掉。如果你在电脑设置里开启了“减少动态效果”，它照常工作。
  - **Activity**（活跃度）——声音此刻有多热闹。每次突然的变化——鼓点、新的音——它都会跳起；节拍来得快时它一直保持在高处：每秒 8 拍是满格，每秒 4 拍是半格。持续的声音（比如一个长音、嗡嗡声或持续的沙沙声）接近 0%。
- **Stereo**（立体声）——声音在左右两个扬声器之间的位置。这需要立体声的来源，所以主要用于文件：只录一个声道（单声道）的麦克风总是显示 “C”。
  - **Pan**（声像）——声音偏向哪一边：居中时显示 “C”，偏左 40% 时显示 “L 40”，偏右 40% 时显示 “R 40”（“L 100” 表示只有左边的扬声器在响）。它的条形表从中间向那一侧伸长。它是唯一可以往两个方向走的读数。
- 非常小的声音算作静音：读数回落到空（Swell 和 Activity 慢一些），Pan 回到中间，Beat 也不会跳起，所以背景噪声不会让它乱跳。

**Mappings**（映射）——声音移动哪些滑块和种子、怎么移动。每个映射把一个读数连到一个滑块或种子上。

- **Drive letters**（驱动字母）——总开关。只有它打开，**并且**文件正在播放或麦克风正在收音时，声音才会移动字母（还要已经载入字体：没有字体时，电平表照常工作，但什么都不会动）。把它关掉后，你仍然可以看电平表，字母则保持不动。如果你的电脑设置了“减少动态效果”，它一开始是关着的，标签页会显示 “Off because your system asks for reduced motion.”（因为系统要求减少动态效果，所以关闭）；如果你仍然想让字母动起来，把它打开即可。页面打开期间才开启“减少动态效果”时，它会自动关掉。如果 **Strength**（强度，在下文的 **Response** 里）是 0%，字母同样不会动，开关下方会显示 “Strength is 0%: the letters hold still.”（Strength 为 0%：字母保持不动）。
- **Preset**（预设）和 **Load**（载入）——一次设好字母并填好现成的几行；见下文的**预设**。
- **Add mapping**（添加映射）——添加一行。第一行把 **Level** 连到 **Distortion · Noise amplitude**，Depth 为 **+50%**，适合先试一试；之后添加的行会选一个还没有任何一行使用的目标——如果有已经起作用的，就选它。最多可以有 8 行；满了以后按钮会变灰，标签页显示 “Up to 8 mappings.”（最多 8 个映射）。
- 每一行包括：
  - **Feature**（特征）——驱动它的读数：上面 11 个读数中的任意一个，按同样的五组列出。
  - **Target**（目标）——它移动的东西。滑块的名称是“分组 · 标签”，例如 “Ripple · Petals”。另外还有三个种子：“Distortion · Seed”、“Random anchors · Seed”，以及 Experimental 标签页的种子，名称就是 “Seed”。列表分为 **Geometry** 和 **Experimental** 两部分，顺序与两个标签页相同。
  - **Depth**（深度）——对滑块而言：它移动多远，从 −100% 到 +100%。+100% 时，最强的声音会把滑块带过整条轨道；+50% 时走一半。负值让它往反方向移动，所以声音越响，数值越小。0% 时不起作用。**Pan** 可以往两个方向走：Depth 为正时，声音偏右让数值变大，偏左让数值变小。
  - **Rate**（速率）——对种子而言，同一个滑块改为显示 **Rate**，从 0% 到 100%：种子跳动得有多频繁（见下文的**种子**）。0% 时不起作用。
  - 一个勾选框，用来打开或关闭这一行而不删除它；以及一个 **×** 按钮，用来删除这一行。
- **滑块移动多远：** 从你放下它的位置开始。如果滑块停在四分之一处，Depth 是 +50%，那么声音最强时它会到四分之三处；没有声音时它停在原处。它不会超出轨道的两端，并且和滑块本身一样按档移动。同一个滑块上的两行会相加。
- 有些滑块越往一端数值变化越快，比如 **Tolerance** 和 Thorn 的 **Reach**。声音仍然带着它们沿轨道均匀移动，就像你用手拖一样。
- **替你打开的设置。** 很多目标只有在另一个设置打开时才起作用：Ripple 的滑块需要 **Use ripple**，**Grid size** 需要 **Snap to grid**，等等。当你选中这样的目标（或者 **Add mapping** 添加了这样的目标）时，程序会替你打开那个设置，并在该行下方用一条提示说明改了什么，例如 “Turned on Ripple.”（已打开 Ripple）或 “Set Noise amplitude to 40.”（已把 Noise amplitude 设为 40）：
  - Crumple、Ripple、Whorl、Slipstream 或 Thorn 的滑块会打开各自的效果；**Flute width** 还会在 **Refraction** 为 0% 时把它设为 50%（有一定的折射，玻璃竖条才看得出来）；
  - Experimental 的 **Seed** 在 Crumple、Slipstream 或 Thorn 打开时起作用（Ripple 和 Whorl 没有随机性）；三个都没打开时，它会打开 Crumple；
  - **Grid size** 会打开 **Snap to grid**；
  - Distortion 的 **Noise frequency**、**Normal bias** 和 **Seed** 在 **Noise amplitude** 为 0 时会把它设为 40（为 0 时扰动是关闭的）；
  - Random anchors 的 **Density**、**Randomness** 和 **Seed** 会打开 **Use random anchors**；Seed 还会在 **Randomness** 为 0% 时把它设为 100%；
  - Curve flattening 的滑块会关闭随机锚点（随机锚点取代了曲线展平），并设好自己需要的设置：**Tolerance** 把 **Mode** 设为 Adaptive，**Segments per curve** 把它设为 Fixed segments，**Corner angle** 会打开 **Merge joined curves**——例如 “Turned off Random anchors. Set Mode to Adaptive.”（已关闭随机锚点。已把 Mode 设为 Adaptive）。（Corner angle 单独使用时变化不大，见 Curve flattening 一节。）
- 把某一行换成别的目标，或者删除这一行，都不会再把任何设置关掉。这条提示会一直保留，直到你再次更换这一行的目标或删除这一行。如果你用方向键在 **Target** 列表里逐个浏览，只有你最后停下的那个目标才会打开设置：在你按回车或转到其他控件时生效；用鼠标选择则立即生效。
- 如果之后那个设置又被关掉了——你自己关掉了它，或者另一行需要不同的 Mode（Tolerance 需要 Adaptive，Segments per curve 需要 Fixed segments）——该行下方会有一条灰色提示说明原因，例如 “Turn on Ripple to hear this.”（打开 Ripple 才能听到效果），旁边的 **Enable**（启用）按钮可以把它重新打开。
- **可以驱动的：** **Geometry** 和 **Experimental** 两个标签页里的每个滑块——Tolerance、Segments per curve 和 Corner angle；Squaring 的 Amount；Anchor spacing 和 Anchor reduction；Grid size；Noise amplitude、Noise frequency 和 Normal bias；Random anchors 的 Density 和 Randomness；以及 Crumple、Ripple、Whorl、Slipstream、Thorn 的全部滑块——以及三个种子，一共 42 个。开关和选项（比如 **Mode** 或 **Allowed directions**）不能驱动。
- 映射会和你的其他设置一起保存，下次打开程序时会恢复（见[下次打开时](#下次打开时)）；**Drive letters** 不会保存。添加、修改或删除一行，都可以像其他改动一样撤销。

**种子**——跳到新位置的点。种子决定一种随机图案（见 Distortion、Random anchors 和 Experimental 标签页）。声音驱动一个种子时，每跳一次，它就往前走一个数——1234 变成 1235——而每个种子都是一种完全不同的图案，所以轮廓上的每个点会一下子落到新的位置（载入 **Flicker** 之后，每个字母只有少数几个点移动，每次换不同的几个；开启 Thorn 时，Experimental **Seed** 和 Random anchors 的种子每次只送到少数几个字母，见下文的“**刺轮流变化**”）。到 999 999 之后，它从 0 重新开始。

- **Rate**（速率）——种子跳动得有多频繁：
  - 配合 **Beat** 时，它按次数计算：100% 时每一下都跳，50% 时每两下跳一次，25% 时每四下跳一次；
  - 配合其他读数时，读数越高跳得越频繁：100% 且条形表满格时最多每秒大约 5 次，条形表半格时减半。对 Pan 来说，偏左偏右都算。
  - **Rate** 旁边的 **ⓘ** 也有这些说明。
- **不会太快：** 种子的跳动和声音带动的滑块共用一个上限，所以字母不会闪烁（见下文的**不会闪烁**）。同一时刻一起跳的种子只算一次。单独的种子每秒最多可以跳大约 5 次；被带动的滑块也在来回摆动时，种子就会跳得少一些。鼓点很快时，有些拍子就会被跳过；它们不会被攒到之后再跳。
- **你的种子留在输入框里。** 被驱动的种子输入框旁边，有一个和实时细线同色的小数字，显示字母此刻使用的种子（实时种子）。Distortion 和 Random anchors 统计里的 **Seed**，以及底部的状态栏，也显示实时种子。当声音不再带动字母——你暂停、文件播完、关掉 **Drive letters** 或取消勾选这一行——字母会回到输入框里的种子，下次按 **Play** 也从它重新开始。想留住喜欢的种子，就按 **Freeze**：它会把实时种子写进输入框。
- **试一试——随节拍跳动的锚点：**
  1. 选择 **File** → **Choose file**，挑一首鼓点清晰的歌，然后按 **Play**。
  2. 点 **Add mapping**。
  3. 把 **Feature** 设为 **Beat**，**Target** 设为 **Distortion · Seed**。如果 **Noise amplitude** 原来是 0，该行下方会出现提示 “Set Noise amplitude to 40.”（已把 Noise amplitude 设为 40）：现在轮廓变粗糙了，才有东西可以动。
  4. 这一行的滑块现在显示 **Rate**：把它设为 100%。粗糙的轮廓会在每个节拍上换成新的形状。想跳得平缓一些，就调低 Rate。

**预设**——现成的起点，最快的入门方式：

1. 选择 **File** → **Choose file**，挑一首歌（或者选择 **Microphone**）。
2. 在 **Mappings** 下面的 **Preset** 列表里选一个预设。选择只是选中它：此时什么都不会变。
3. 按 **Load**。
4. 按 **Play**（或 **Start listening**）。

- **Load 让字母从头开始。** 它先把 **Geometry** 和 **Experimental** 标签页里的每个设置都恢复成初始值——你的三个种子会保留——然后设好预设起始用的几个滑块，再用预设的各行替换你的映射。所以无论你之前设了什么，同一个预设看起来总是一样的。你的文字、排版、颜色、画布、声音来源，以及 **Response** 组的六个滑块都不会被改动。
- **Preset 下方的说明会告诉你 Load 做了什么**，例如 “Loaded Bloom. Turned off Crumple. Other Geometry and Experimental settings back to defaults (seeds kept).”（已载入 Bloom。已关闭 Crumple。其他 Geometry 和 Experimental 设置已恢复默认，种子保留）。它会列出关掉了哪些效果，让你知道少了什么。再次载入或选择另一个预设时，这条说明就会消失。
- Load 不会先询问，但它只算一步撤销：载入后马上撤销（Mac 上是 ⌘Z，其他系统是 Ctrl+Z），就能找回之前的设置和映射行。**Preset** 下方的提示随之消失。像上文那样自己选择目标时，不会把任何设置恢复成默认值：只会打开该目标需要的设置。
- 载入之后，可以像平常一样修改、添加或删除行，或者移动任何滑块。**Preset** 旁边的 **ⓘ** 也列出了所有预设。
- 各个预设：
  - **Flicker**——每个节拍上，每个字母有几个点跳动，其余的点撑住字形；声音越响、每个节拍，它们都跳得更远。它用的是 Distortion 的一种特殊模式（见 Distortion）。
  - **Scatter**——每隔一个节拍重新放置字母上的点：安静时又密又均匀，越响越稀疏、越不均匀。载入它会打开随机锚点。
  - **Pixel**——字母吸附到网格上，低音让网格变粗；嘶嘶声和镲片让点变少。
  - **Low poly**——响亮的段落把曲线压成更少、更长的边；明亮的声音让点变少。
  - **Block**——音乐渐强时圆形笔画变方，每个节拍再方一点。
  - **Jitter**——嘶嘶声和镲片让轮廓颤动；声音越亮，颤动越细碎。
  - **Facet**——越响、每个节拍时，曲线碎成几条直边；音越高，又变得平滑。
  - **Bloom**——波纹穿过字母，每个节拍时涌起；低音把波纹弯成花瓣。载入它会打开 Ripple。
  - **Flare**——安静时没有刺；越响，每个字母就有几个点射出刺；它们随着节拍跳到新的地方，并短暂变多，每次只有少数几个字母（见下文的“**刺轮流变化**”）。载入它会打开 Thorn，并把 **Reach** 设为 0%；响度（**Level**）以 +50% 的 Depth 驱动 Reach，所以最响时刺最多伸出画布的八分之一（初始画布上约 4 em）。
  - **Gale**——响亮的声音让字母的切片彼此错开；节拍顺着气流切出细缝，热闹的段落拖出拖尾。安静时什么都不动。载入它会打开 Slipstream。

**声音移动字母的时候：**

- **你的滑块停在你放的位置。** 每个被驱动的滑块上，有一条细细的彩色竖线沿轨道移动，显示声音此刻把它带到了哪里（被驱动的种子则在输入框旁边显示实时种子，见上文的**种子**）。暂停、文件播完、停止收音或关掉 **Drive letters** 时，字母会完全回到你的滑块设置和种子，竖线和实时种子也随之消失。
- **文字停在原处。** 文字在画布上的位置是按你的滑块算出来的，而不是按移动中的字母，所以无论效果、种子、预设或 **Response** 设置如何，声音都不会推着文字跑。声音播放时如果你改了滑块、文字或排版，文字可能会在你停手片刻之后移动一次，移到这些新设置决定的位置。**Freeze** 会把移动中的数值复制进滑块，所以那时文字也可能移动一次。声音把某个字母扭得比你的滑块更远时，它可能伸出画布边缘：大画布上完整显示，但预览和视频会在那里把它裁掉（见[画布尺寸](#画布尺寸)）。
- **字母可以有不同的反应幅度。** 当 **Motion contrast**（动态对比）或 **Pitch reactive**（音高响应）（在下文的 **Response** 里）高于 0% 时，有些字母比别的动得少，有些动得多，所以同一个字母在文字里的两处可能长得不一样。滑块上的细线显示的是共同值：按通常幅度反应的那些字母被声音带到了哪里。种子对每个字母都按同样的方式跳动（开启 Thorn 时，Experimental 种子和 Random anchors 的种子改为轮流变化；见下一条）。两者都为 0%（初始值）时，所有字母一起动。开启 Thorn 时，这两项不改变轮流变化的那些设置（见下一条）：同一组的每个字母这些设置都相同。它们仍然改变其他设置，比如 Distortion 以及 Crumple 和 Ripple 的 **Amount**。
- **刺轮流变化。** 开启 Thorn 时，刺不再同时全部变化。字母被分成五组，每组都散布在整段文字里，各组依次换上声音最新的设置，两次之间至少相隔四分之一秒。所以同一时间最多约五分之一字母的刺在变，每个字母的刺最多大约每 1¼ 秒变一次，与文字长短无关。所以 **Seed** 或 Thorn 的 **Anchors** 上的一拍，会在大约 1¼ 秒内像波浪一样传过文字，而不是让每个字母一起跳。
  - **哪些设置轮流变化**（开启 Thorn 时）：Thorn 的所有滑块、Experimental **Seed**（所以 Crumple 的折痕和 Slipstream 的阵风也每次只在少数几个字母上变化）、Distortion 之前的每个 Geometry 设置（Curve flattening、Squaring、Anchors、Grid & angles 和 Random anchors），以及 Crumple、Ripple、Whorl 和 Slipstream 的滑块（下面两个除外）。
  - **哪些保持平滑**、让每个字母一起变化：Distortion 的滑块和它的种子，以及 Crumple 和 Ripple 的 **Amount**。这些设置变动时，刺留在原来的点上（见 Thorn 里的“**其他设置变动时，刺留在原处**”）。
  - 你自己移动的滑块（声音没有驱动的那些）仍然让每个字母一起变化。声音开始带动字母、你打开 Thorn、修改文字或换字体时，每个字母都一起从最新的设置开始。关闭 Thorn 时，什么都不轮流。
- **Live · N fps**（实时 · 每秒 N 帧）——显示在 Sound 标签页和底部状态栏里：程序每秒能跟上多少个新形状（fps 即每秒帧数）。上一个形状算好，程序就立刻画下一个，每秒最多 30 个，所以设置越重、文字越长，帧数越少。Motion contrast 和 Pitch reactive 会让程序为每个字母最多计算三个版本，所以也会让这个数字变小。它数的是新形状，而不是程序多久听一次声音（程序按屏幕自己的节奏听，而且只在标签页可见时听）。
- **不会闪烁：** 所有被带动的滑块和种子共用一个上限，加在一起每秒最多让字母闪烁 3 次。一次闪烁是一次大变化再加上变回去，所以相当于每秒大约 5 次大变化。大变化指的是：一个滑块往回摆动了轨道的十分之一或更多（几个滑块同时往回摆、加起来达到十分之一时，合起来也算），或者一次种子跳动（见上文的**种子**）。如果音乐会让变化更频繁（比如鼓点很快、**Release** 又很短），滑块会稍等片刻再往回摆，种子的跳动则会被跳过。这个上限看着屏幕上的每个字母：开启 Motion contrast 或 Pitch reactive 时，动得最远的那些字母也算在内，一个字母在“动得少”和“动得多”之间切换也算一次变化。一次分几步很快到达屏幕的变化（比如旋律换到一个新的音时）只算一次。一组字母轮到换刺（见“**刺轮流变化**”）时，如果刺变化很大，也算一次大变化；达到上限时，这次轮换会稍等片刻。
- 如果每秒低于大约 8 个，标签页会显示 “Too slow to follow the sound: try fewer effects or a shorter text.”（太慢，跟不上声音：试试少开几个效果或缩短文字）；开启 Motion contrast 或 Pitch reactive 时显示 “Too slow to follow the sound: try fewer effects, a shorter text, or less Motion contrast and Pitch reactive.”（还建议调低 Motion contrast 和 Pitch reactive）。关掉一些 Experimental 效果、换一段更短的文字、用更轻的设置，或者调低这两个滑块，都会有帮助。
- **Freeze**（冻结）——把字母此刻的样子复制到滑块和种子输入框里，并让声音暂停（文件暂停，或麦克风停止收音）。这一刻会作为普通设置留在屏幕上，你可以继续调整，也可以导出。按 **Play** 或 **Start listening** 继续。声音没有在带动字母时，以及正在录制视频时（“Freeze is off while recording.”，即录制期间 Freeze 不可用），Freeze 是灰色的。如果按下时共同值（滑块上的细线和实时种子）正好和滑块、种子一致（例如两次鼓点之间），它只会暂停声音。撤销（Mac 上是 ⌘Z，其他系统是 Ctrl+Z）可以让滑块和种子回到 Freeze 之前的样子（声音保持暂停）。
  - 开启 Motion contrast、Pitch reactive 或 Thorn 轮流变化时，Freeze 写入的是共同值（滑块上细线显示的那些值）。之后每个字母都使用这些值，所以原来比别的字母动得多或少的字母，以及刺还没轮到的字母，又和其他字母一样了。
- **SVG、PNG 和字体导出始终使用滑块和种子输入框**，从不使用正在移动的字母。想保存音乐中的某一刻，先按 **Freeze**，再点 **Export…**。声音正在移动字母时，导出对话框也会提醒这一点。想留住动态本身，就录一段视频：它会按字母移动的样子原样记录，每个字母都带着自己的幅度（见[录制视频](#录制视频)）。和导出一样，Typography 标签页里的 **Fit text** 和 **Free** 也按你的滑块设置下的字母来测量。

**Response**（响应）——声音如何测量，以及字母回应得有多强。一共六个滑块，每个旁边都有 **ⓘ** 说明。保持初始值时，字母完全按映射的设置移动。

- **Sensitivity**（灵敏度）——在测量前提高或降低输入，适合声音很小或很大的来源（−24 到 +24 dB，默认 0 dB）。房间很安静或麦克风离得远时调高，这也能帮 Beat 捕捉到轻微的鼓点；条形表总是满格时调低。
- **Strength**（强度）——所有映射让字母移动多远，从 0% 到 400%（默认 100%）。50% 时移动一半远，200% 时移动两倍远；滑块仍然会停在轨道的尽头。它也会按比例改变每个种子的 **Rate**（最多到 100%）。0% 时字母保持不动。移动越大，越常被“不会闪烁”的上限拦下（见上文的**不会闪烁**）。
- **Motion contrast**（动态对比）——让每个字母按自己的幅度反应（0–100%，默认 0%）。0% 时每个字母都一样动。高于 0% 时，大约每六个字母中有一个动得比其他字母少，大约每六个中有一个动得更多，其余的按共同幅度移动；数值越高，差别越大（在 100% 时，动得多的字母移动的距离是共同幅度的好几倍，动得少的只有它的一小部分）。哪些字母领头会慢慢变化，每隔几秒换一换。整体幅度仍由 **Strength** 决定。开启 Thorn 时，它不改变轮流变化的那些设置（见上文的“**刺轮流变化**”）。它可能会降低帧率。
- **Release**（释放）——声音过后读数回落得有多慢：短则跳动，长则平稳（20–1000 ms，默认 150 ms）。大多数读数都是立即上升；Beat 和 Melody 按这个速度回落；Swell 和 Pitch 有自己的速度。（旧版本里它叫 **Smoothing**。）
- **Pitch reactive**（音高响应）——让音高决定哪些字母动得最多（0–200%，默认 0%）：曲调里的低音让左边的字母动得更多，高音让右边的字母动得更多，所以无论唱得低还是高，一段曲调都会扫过整段文字。程序会从最近几秒的音里学到曲调的音域：一开始是围绕第一个清晰的音的一个八度；出现更高或更低的音时，几乎立刻（约 0.15 秒）扩展过去；之后在大约 8 秒里慢慢向最新的音收拢；超过 8 秒没有音，就重新开始。音域从不窄于一个八度，所以平稳的人声不会让字母左右乱跳；**Pitch** 电平表最底端和最顶端的音（距 55 Hz 或 1760 Hz 一个半音以内）会被忽略，因为和弦和鼓往往读在那里。因为音域会随每个新的音扩展，曲调第一次往上走时，每个新的最高音都落在最右边；程序听过整段曲调之后，每个音都有自己的位置。它需要清晰的单个音，比如人声或一件乐器。数值越高，差别越大；数值很高时，快速跳一个八度偶尔会被闪烁上限拦下（见上文的**不会闪烁**）。开启 Thorn 时，它和 Motion contrast 一样不改变轮流变化的那些设置。它可能会降低帧率。
- **Melody tracking**（旋律跟随）——每当曲调换到一个新的音，就增加一些移动，即使响度保持不变（0–200%，默认 0%）。它用 **Melody** 读数（见上文的 **Levels**）给每个滑块映射行加一把力：数值越高，力越大。作用在 **Pan** 或 **Melody** 本身上的行，以及种子，都不会被加力。想只让旋律来移动某个滑块，就把某一行的 **Feature** 设为 **Melody**。
- **Reset sound**（恢复声音设置）——把六个滑块全部恢复为初始值：0 dB、100%、0%、150 ms、0% 和 0%。已经是这些值时按钮会变灰。
- 这六个滑块会和你的作品一起保存，也可以像其他设置一样撤销（见[下次打开时](#下次打开时)）。载入预设不会改动它们。

#### 录制视频

Sound 标签页最下面的 **Record**（录制）组，会在声音移动字母时把画布实时录成视频，并把声音一起录进去。和其他导出不同，视频会留住动态：每个字母都按它移动的样子原样记录，包括按自己的幅度反应的字母和轮流变化的刺，文字也和画布上一样停在原处。它录的是画布上显示的内容，所以录制期间你做的改动也会出现在视频里。和 PNG 一样，它只包含画布：超出画布边缘的部分会被裁掉。（一次 **take**（录制）就是一段录像，从按下 **Record** 到它结束。）

1. 选好声音——**File** → **Choose file**，或者 **Microphone**——并像平常一样设置好字母和映射。
2. 设置下面的选项。
3. 按 **Record**。如果文件处于暂停，Record 会从当前的 **Position** 开始播放它；如果是麦克风，它会开始收音（第一次使用时浏览器会询问权限）。声音一开始，录制就开始。
4. 按 **Stop**，或者等选定的 **Length** 结束这次录制。视频会像其他导出一样保存到你的电脑上（通常在“下载”文件夹里）。如果文件或麦克风是 Record 启动的，结束后它会再次暂停文件或停止收音。

- **Record** / **Stop**（录制 / 停止）——旁边显示已录制的时间，选了固定长度时还会显示这次录制有多长（例如 “0:03 / 0:10”），声音带动字母时还会显示 **Live · N fps**。Record 无法开始时会变灰，并在下方说明原因：“Load a font to record.”（请先载入字体）、“Choose an audio file first.”（请先选择音频文件）、“Opening the sound…”（正在打开声音）或 “This browser cannot record video.”（这个浏览器无法录制视频）。
- **Format**（格式）——**MP4**（初始选项，几乎在哪里都能播放）或 **WebM**。不能写 MP4 的浏览器会改存为 WebM，并显示 “MP4 isn't supported in this browser: saved as WebM.”（这个浏览器不支持 MP4：已存为 WebM）。浏览器完全不能写的格式会变灰，并标着 “(not supported in this browser)”（这个浏览器不支持）。
- **Length**（长度）——一次录制持续多久：**Until stopped**（直到停止，初始选项）、**5 s**、**10 s**、**15 s**、**30 s**、**60 s** 或 **Whole file**（整个文件）。**Whole file** 会把音频文件从头播到尾，录制期间 **Loop** 关闭（如果原来是开着的，录完后会重新打开）。它需要选好的音频文件，所以使用麦克风时或选好文件之前是灰色的；如果之前已经选了它，会有一条提示 “Whole file needs an audio file: this take runs until stopped.”（Whole file 需要音频文件：这次录制会一直持续到停止）。每次录制最多 10 分钟（“Stopped at the 10-minute limit.”，即在 10 分钟上限处停止），因为视频在保存之前一直放在浏览器的内存里。
- **Include audio**（包含音频）——把声音录进视频，并和字母对齐（初始是勾选的）。使用麦克风时，它的声音会录进文件，但仍然从不通过扬声器播放。录制不会改变你听到的声音。
- **Use the preview look**（使用预览外观）——不勾选（初始）：画布按 **Color** 设置显示，和 PNG 导出一样。勾选：使用右下角小预览的外观，包括它的 **Blur**，以及开启 **Invert** 时互换的颜色。
- **尺寸说明**——选项下方的一行说明下一次录制会是什么样，例如 “1200 × 800 px · up to 30 fps · MP4”（1200 × 800 像素 · 每秒最多 30 帧 · MP4）。尺寸就是 PNG 的尺寸：画布的 **W** × **H** 乘以 1×–4× 倍数（见[画布尺寸](#画布尺寸)）。超过 4K 的视频（长边超过 3840 px，或像素数多于 3840 × 2160）会缩小到刚好放得下，这一行会加上 “(scaled down to the 4K limit)”（已缩小到 4K 上限）。视频不能透明：开启 **Transparent background** 时会画上背景色，并有一条提示 “Videos have no transparency: the background colour is painted.”（视频没有透明度：会画上背景色）。
- **帧：** 画布每显示一个新形状，视频就得到一个新帧，每秒最多 30 帧——和 **Live · N fps** 的数字一样。字母静止时，视频保持画面（每秒至少一帧，好让播放器计时准确）。程序跟不上时，这一组会显示 “Too slow for a smooth video: try fewer effects or a shorter text.”（太慢，视频不会流畅：试试少开几个效果或缩短文字）。
- 如果什么都不会动——**Drive letters** 关着、**Strength** 为 0%，或者没有一行有 Depth——会有一条提示 “Sound is not moving the letters: the video will be still.”（声音没有在移动字母：视频会是静止的）。你仍然可以录制。
- **页面顶部：** 录制期间，屏幕顶部先显示 “Starting to record…”（正在开始录制），然后是一个红灯和 “Recording 0:12”（正在录制 0:12），最后是 “Saving the video…”（正在保存视频），旁边有一个方形的停止按钮，无论工具区打开的是哪个标签页都能点到。录制结束后，顶部会说明结果，直到你点它的 **×** 关掉这条提示。
- **从导出对话框录制：** **Export…** → **Video — live sound**（视频——实时声音）显示同样的选项（在那里改，这里也跟着改）。它的 **Record** 按钮会关闭对话框并立刻开始录制；在页面顶部停止。录制期间再次打开对话框，里面也有自己的 **Stop**。见[保存为视频](#保存为视频)。
- **什么会结束一次录制**（已经录下的部分总会被保存）：
  - **Stop**——在这一组、页面顶部或导出对话框里；
  - 选定的 **Length** 到了，或者选 **Whole file** 时文件播完；
  - 声音停了——你按了 **Pause** 或 **Stop listening**、文件在 **Loop** 关闭时播完、麦克风停了，或者你在 **File** 和 **Microphone** 之间切换：“The sound stopped, so the recording ended.”（声音停了，录制随之结束）；
  - 标签页被隐藏——切换到另一个标签页或把窗口最小化：“Recording stopped because the tab was hidden.”（因为标签页被隐藏，录制已停止）（隐藏的页面不会绘制，视频会卡住不动）；
  - 改变画布尺寸或它的倍数：“Recording stopped because the canvas size changed.”（因为画布尺寸改变，录制已停止）；
  - 10 分钟上限。
  - 录制期间关闭页面时，浏览器会先询问你。
- **保存之后**，这一组和页面顶部会说明，例如 “Saved Roboto-Regular-video.mp4: 0:05, 1200 × 800 px.”（已保存 Roboto-Regular-video.mp4：0:05，1200 × 800 像素）。文件名由字体的族名和样式名加上 “video” 组成——勾选 **Use the preview look** 时是 “video-preview”——例如 `Roboto-Regular-video.mp4` 或 `Roboto-Regular-video-preview.webm`。
- **需要知道的：**
  - 有些播放器不显示 WebM 文件的总时长，或者要先完整播放一遍才能拖动进度。视频本身是完整的；网页浏览器和 VLC 这类播放器都能播放它。
  - 尺寸大、时间长的录制文件也大：在 4K 上限录 10 分钟，最多约 1 GB。
  - 这些选项保留到你关闭页面为止。它们不会随作品保存，也不能撤销。

录制出问题时，这一组和页面顶部会说明原因：

| 提示 | 含义 | 怎么办 |
|---|---|---|
| This browser cannot record video. | 你的浏览器无法把画布录成视频。 | 换用新版的 Chrome、Edge、Firefox 或 Safari。 |
| The sound did not start, so nothing was recorded. | 文件没有播放，或者麦克风没有打开。 | 查看来源下方的提示（见上表），然后再按 **Record**。 |
| The sound stopped before recording began, so nothing was recorded. | 声音开始了，但在录制开始之前又停了。 | 再按一次 **Record**。 |
| The video did not start, so nothing was recorded. | 声音在播放，但画布 30 秒内都没有给出画面。 | 让标签页保持可见，用轻一些的设置，然后再按 **Record**。 |
| The sound could not be recorded: the video is silent. | 视频保存了，但没有声音。 | 再录一次；如果一直这样，换一个浏览器，或者关掉 **Include audio**。 |
| Blur isn't available for video in this browser: recorded without it. | 勾选了带模糊的 **Use the preview look**，但这个浏览器无法给视频加模糊。 | 换一个浏览器来录带模糊的视频，或者用 **Export the preview look** 保存静态图片（PNG）。 |
| Recording failed: … | 浏览器的视频录制器出错停止了（后面是它自己的说明）。“Saved what was recorded: …” 表示出错之前的部分已经保存；“Nothing was recorded.” 表示什么都没有录下。 | 再试一次，或者换另一种 **Format**。 |

### Typography（排版）标签页——字号、间距和对齐

**Typography**、**Glyphs** 和 **Color** 三个标签页在左下。这些设置决定文字在画布上怎么排，不改变字母的形状，也不影响导出的字体文件。

- **Size**（字号）——以像素表示的字号（一个 em 在画布上有多高）。改变画布尺寸时字号保持不变。可以拖动滑块，也可以直接输入数字。
- **Fit text**——让文字尽量大，同时和画布边缘保持 25 像素的距离。刺不算在内：它们仍可能伸出边缘（见 Experimental 标签页里的 Thorn）。
- **Tracking**（字间距）——字母之间额外的距离，负值让字母靠得更近。
- **Line height**（行距）——行与行之间的距离。1 是字体本身的行距，2 是两倍。
- **Slant**（倾斜）——让字母倾斜，类似简单的斜体。正值向右倾，负值向左倾。
- **Align**（对齐）——三个画着横线的按钮，让各行文字靠左、居中或靠右对齐。
- **Position**（位置）——文字在画布上的位置。点九个圆点之一：四个角、四条边的中点或正中间。文字会移到那里，并和边缘保持 25 像素的距离，各行的对齐也会跟着变：左边一列靠左、中间一列居中、右边一列靠右。选中的圆点会发光。点 **Free**（自由）可以自己摆放：文字先回到起始位置，然后在大画布上直接拖动（随时再点 Free 就能回到起始位置）。文字到画布边缘就会停住，不会被拖出页面。在画布其他地方拖动仍然是移动视图。打开 Thorn 时，边距、边缘以及能抓住文字的地方，都只看去掉刺之后的字母：请拖字母，而不是刺。Sound 标签页让字母动起来时，文字停在你的滑块所决定的位置：声音从不移动它。
- **Reset typography** 把这些设置恢复成初始值。

### Color（颜色）标签页——文字和背景颜色

- **Presets**（预设）——十二组现成的配色，两个圆点分别是文字颜色和背景颜色。默认是 **Charcoal**（浅色纸上的深色文字）。
- **Random** 随机挑一组仍然好认的配色；**Swap** 交换文字和背景的颜色。
- **Text**（文字）和 **Background**（背景）——点颜色条可以挑任意颜色，也可以输入十六进制色值，比如 `#35f2b4`。
- **Transparent background**（透明背景）——导出时不含背景，方便把文字放到别的东西上。此时画布显示为棋盘格（用你的配色生成，所以文字依然好认）。
- 下方的 **Contrast**（对比度）表示这组颜色是否好认；低于 3 : 1 时会出现黄色提示，说明文字会很难看清。

画布、预览以及 SVG 和 PNG 导出都使用这些颜色。字体文件没有颜色。

## 9. 常用配方

**粗犷的折面字（类似“每条曲线 4 / 3 / 2 条线”）**
Curve flattening → **Fixed segments**，打开 **Merge joined curves**，**Break merged curves at** 选 Corners & extremes，**Segments per curve** 设为 4（含蓄）、3 或 2（强烈）。

**用 Adaptive 模式做折面字形**
Curve flattening → **Adaptive**，打开 **Merge joined curves**，**Tolerance** 设为 50（含蓄）、150 或 500（非常粗犷）。

**极端的低分辨率字形**
在上面任一配方的基础上，打开 **Merge through straight lines**，把 **Corner angle** 调到 45°–90°。想要最简化的形状，可以把 **Break merged curves at** 改成 Corners only。

**方形的 O 和其他圆形字母**
Squaring → **Square**，Applies to 选 **Round contours**，再到 Anchors → **Anchor reduction** 设为 2。输入 “OO oo 00” 检查效果。

**像素 / 网格风格**
Grid & angles → 打开 **Snap to grid**，**Grid size** 约为字体 Units/em 的 5%（例如 1000 单位的字体设为 50）。再打开 **Angle lock** 并选 **90°**，就只剩水平和垂直的边。

**石刻或风化的质感**
固定线段数 3 并开启合并，然后 Distortion → **Noise amplitude** 10–30、**Noise frequency** 8–15、**Normal bias** 70%。不断点 **Next variant**，直到找到喜欢的图案。

**随机的手工切割感**
Random anchors → 打开 **Use random anchors**，**Density** 3–5，**Randomness** 100%，打开 **Keep sharp corners**。不断点 **Shuffle** 直到满意，然后点 **Copy** 记下种子。

**揉皱的纸**
Experimental 标签页 → 打开 **Use crumple**，**Amount** 70–100%，**Facet size** 15–25%。想要粗犷、块状的折痕，可以搭配较大的 Curve flattening **Tolerance**（40 或以上）。不断点 **Next variant**，直到找到喜欢的折痕。

**多边形波纹**
Experimental 标签页 → 打开 **Use ripple**，**Amount** 50%，**Wavelength** 25–35%，**Sides** 6 或 8。想要硬朗的三角形冲击波，试试 **Sides** 3 并配合较大的 Curve flattening **Tolerance**；想让波纹从一角扫过来，把 **Center X** 和 **Center Y** 都设为 0%。

**多面花朵**
Experimental 标签页 → 打开 **Use ripple**，**Amount** 0–30%，**Petals** 40–60%，**Sides** 5（想要四叶的样子就用 4）。想要狂野的花朵，把 **Petals** 调到 100–200%，**Amount** 调到 200% 或以上。

**漩涡字母**
Experimental 标签页 → 打开 **Use whorl**，**Amount** 60–100%，想让字母内部拧转就勾选 **Pin top and bottom**（不勾选则整个字母旋转），**Rings** 4–6，**Sides** 8。把 **Amount** 推过 100%，可以得到翻折、撕碎的漩涡。

**被风吹走**
Experimental 标签页 → 打开 **Use slipstream**，**Strength** 30%，**Slip** 0，**Cuts** 0，**Trails** 2–4，**Gust size** 10–15%，**Gustiness** 60–100%。如果字母挤在一起，可以在 Typography 标签页调大 **Tracking**；点 **Next variant** 换一组阵风。

**切片字母**
Experimental 标签页 → 打开 **Use slipstream**，**Strength** 0%，**Slip** 20–40%，**Cuts** 2–4，**Trails** 0。字母碎成一片片彼此错开的切片，并顺着气流切出细缝。把 **Direction** 设为 90°，切片就改为上下错开。

**玻璃后面长刺的字母**
Experimental 标签页 → 打开 **Use thorn**，**Anchors** 2–3，**Reach** 3–10%，**Root** 50–80%，再把 **Refraction** 调到 50%，**Flute width** 8–15%。不断点 **Next variant**，直到刺落在你喜欢的位置。

**无法阅读的碎裂字母**
Experimental 标签页 → **Use crumple** 300–500%，或 **Use ripple** 200–400%，或 **Use slipstream** 配合 **Gustiness** 150–200%。几个一起开就是彻底的混乱；不断点 **Next variant**，直到形状让你意外。其中几个都接近最大值时，字母会被简化成粗糙的板块（见 Experimental 标签页的“设置太重时”）。所有效果都开到最大时导出一整套大型字体，可能超过文件的点数上限，这时改为只导出文本里用到的字符。

**随音乐跳动的字母**
Sound 标签页 → **File** → **Choose file** → **Play**。在 **Mappings** 下点 **Add mapping**（Level → Distortion · Noise amplitude，+50%）：响亮的段落让字母变粗糙，安静的段落让它们变平滑。想要更强的效果，可以调大 **Depth**，或者先把 Distortion 的 **Noise amplitude** 调高一点。在喜欢的时刻按 **Freeze**，然后导出。

**低音响起时张开的花瓣**
Experimental 标签页 → 打开 **Use ripple**，**Amount** 0–30%，**Petals** 0–20%，**Sides** 5。Sound 标签页 → 点 **Add mapping**，再把 **Feature** 设为 **Bass**，**Target** 设为 **Ripple · Petals**，**Depth** 设为 +10%。如果还想让镲片声带来一阵颤动，再添加 **Treble** → **Crumple · Amount**（这会替你打开 Crumple）。

**随节拍跳动的锚点**
Sound 标签页 → **File** → **Choose file** → **Play**。点 **Add mapping**，把 **Feature** 设为 **Beat**，**Target** 设为 **Distortion · Seed**（如果 **Noise amplitude** 原来是 0，会替你设为 40），**Rate** 设为 100%：粗糙的轮廓会在每个节拍上换成新的形状。想让点沿着字母本身移动，改选 **Random anchors · Seed**（这会打开随机锚点）。看到喜欢的形状时按 **Freeze**。

**回到原样**
把 Curve flattening 设为 **Adaptive** 并用较小的 **Tolerance**，再关闭 Squaring、Anchors、Grid & angles、Distortion 和实验效果（每组都有复位按钮）。或者直接在画布工具栏选 **Original** 查看未经改动的字体。

## 10. 保存作品（导出）

点右上角的 **Export…**。只有点下载按钮时才会下载（视频在一次录制结束时保存）。

SVG、PNG 和字体导出始终使用你的滑块设置和种子。如果 **Sound** 标签页正在移动字母，先按 **Freeze**，才能导出你看到的那一刻。视频则不同：它会录下随声音移动的字母（见[保存为视频](#保存为视频)）。

### 保存为图像（SVG 或 PNG）

两种格式都会保存画布：它的尺寸、和画布上一样排好的文字，以及你的配色。

1. 选择 **SVG — main view**（可以继续编辑的图形）或 **PNG — main view**（图片）。
2. 想要透明背景（只画字母），请先在 Color 标签页勾选 **Transparent background**。
3. 可选：勾选 **Export the preview look**，改为保存小预览里的样子——它的模糊，以及开启 **Invert** 时互换的颜色。请先在预览里调好 Blur 和 Invert。
4. **实心还是只有轮廓：** 图片跟随画布上的 **Fill** 按钮。Fill 开启时（通常如此），字母是实心的。Fill 关闭时，字母只画轮廓——在画布上 2 像素宽的线（所以 2× 的 PNG 里是 4 像素），用文字颜色，里面是空的。对话框会告诉你会得到哪一种；想改的话，关掉对话框，点画布上方的 **Fill**。
5. SVG 选 **Coordinate precision**（坐标精度），即文件里的数字保留几位小数，默认 2 即可。预览也按这个精度显示字母，程序会记住你的选择留到下次。PNG 的图片尺寸来自 **Canvas size**（宽 × 高 × 1×–4× 倍数）。
6. 点 **Download SVG** 或 **Download PNG**。如果按当前设置还有字母没准备好，对话框会显示 **Computing outlines…**（正在计算轮廓），等它们算好就会开始下载；点 **Cancel** 可以中止。

SVG 文件可以用 Illustrator、Figma、Inkscape 或浏览器打开，里面的形状全部由直线构成。带模糊的 SVG 使用模糊滤镜，浏览器和大多数设计软件都能显示；如果某个软件不支持，请改用 PNG。

### 保存为字体（OTF）

1. 选择 **Font file — OpenType (.otf)**。
2. **Glyphs to include**（包含哪些字形）：**Current glyph**（当前字形）、**Specimen characters**（只包含你输入文字里的字符）或 **All mapped characters**（字体里的所有字母）。
3. 填写 **Family name**（字体族名）和 **Style name**（样式名），请用英文字母。起一个新名字可以避免和原字体混淆。名字下方，对话框会估计这套字体大约有多少个轮廓点。如果超过一个字体文件能容纳的数量（1,000,000），或者按当前设置还有很多字母需要计算、生成可能要花几分钟，会出现黄色提示。
4. 点 **Build & verify**（生成并校验）。应用会在后台生成字体并做全面检查，同时显示进度（例如 “Processing outlines 120 / 300”，然后是写入和检查文件）。画布上已经画好的字母会直接拿来用，只有其余的需要计算。点 **Cancel** 会立刻中止生成。如果生成整整一分钟都没有进展，它会被中止，对话框显示 “The export stopped responding.”（导出没有响应）。
5. 显示 “Verified” 后点 **Download .otf**，然后像安装普通字体一样安装它。

需要了解：

- 生成之后如果又改了设置，需要重新生成再下载。
- 即使画布上的 **Fill** 关着，字体文件里的字母也始终是实心的；对话框会提醒你。
- 新字体会保留原字体的**字偶距**——像 “AV” 这类字母组合之间的细微间距——只要这两个字母都在新字体里，所以排出来的文字和画布上一样。连字、重音符号在字母上的定位、取决于前后字母或语言的字偶距，以及原字体的其他高级排版功能都不包含。对话框里的 **What the font file does not include**（字体文件不包含的内容）列出了全部。
- 字母会沿用原字体的字重、样式（例如斜体）、倾斜角、行距以及版权和授权信息，所以你做的 Regular 和 Bold 能像原字体一样同时安装。
- 行距和画布上一样，在 Mac 和 Windows 上都是如此。如果字母伸得远远高于或低于平常的高度（比如用了 Slipstream），少数较老的软件可能会把行距拉大一些。
- **伸得很远的字母会被修剪。** 字体文件把每个字母存放在一个 32,766 字体单位宽的正方形里——每 em 2048 单位的字体是 16 em，每 em 1000 单位的是 32.8 em——这个正方形围绕字母摆放。轮廓伸得更远的部分（比如很长的 Thorn 刺尖）会在正方形边缘被直线切掉，这样字母仍能保存。对话框会在 “Trimmed to fit”（已修剪以放下）下列出这些字母。这只影响字体文件：画布、SVG 和 PNG 里它们和原来一样。
- 极少数情况下，某个字母根本无法存进字体文件——比如它的形状有比一个字体单位还细的细节，或者它占的宽度（从它的起点到下一个字母开始的地方）超过 32,767 个字体单位。这时对话框会显示 “Left out of the font file:”（以下字形未收入字体文件），并列出每个这样的字母及原因。细节太细时，调小 **Distortion** 或 **Anchor spacing** 通常就能解决。
- 设置非常密时（Anchor spacing 接近 1，或很强的 Experimental 效果），整套字体的点数可能超出一个文件能容纳的上限。对话框会在生成之前提醒你，并建议调大 Anchor spacing、减弱 Experimental 效果，或只导出文字中用到的字符。
- 可变字体会按屏幕上看到的版本保存，它的字偶距会取整到整数字体单位。
- **版权提醒：**修改后的字体仍然基于别人的设计。分享前请查看原字体的授权——许多开源字体要求修改版使用新的名字。如果原字体保留了自己的名字，导出对话框会提醒你换一个字体族名。

### 保存为视频

1. 选择 **Video — live sound**（视频——实时声音）。它需要一个字体和一个声音：在 Sound 标签页里选好的音频文件，或者麦克风。
2. 设置 **Format**、**Length**、**Include audio** 和 **Use the preview look**。它们和 Sound 标签页 **Record** 组里的选项是同一套：在这里改，那里也跟着改。选项下方的一行显示视频的尺寸，例如 “1200 × 800 px · up to 30 fps · MP4”。
3. 点 **Record**。对话框关闭，录制立刻开始：暂停的文件开始播放，或者麦克风开始收音。屏幕顶部会显示例如 “Recording 0:02” 和一个方形的停止按钮。
4. 点停止按钮，或者等选定的 **Length** 结束。视频在录制结束时保存，页面顶部会说明保存了什么。

视频和图片一样跟随画布上的 **Fill** 按钮：Fill 关闭时只显示轮廓，对话框也会说明。

每个选项的作用、什么会结束一次录制、文件如何命名，见[录制视频](#录制视频)。

### 保存为配置文件（只含设置）

配置文件保存的是设置，不是字母本身：以后、在另一个浏览器或另一台电脑上载入它，程序就会恢复成当时的设置。它是一个很小的 `.json` 文件。

1. 选择 **Config — settings (.json)**（配置——设置）。还没载入字体时也可以用。
2. 对话框会写出这个文件要求哪个字体。点 **Download config**。文件以字体命名，例如 `none-curve-Roboto-config.json`。

它保存的内容和程序在两次访问之间保留的一样（见[下次打开时](#下次打开时)）：每项设置、画布尺寸、文字、画布视图按钮、预览的 Blur 和 Invert、**Coordinate precision**、Sound 标签页的映射和 **Response** 滑块、选中的字母，以及字体的名字。它从不包含字体文件本身、声音或视频选项。

**载入它：** 点 **Import** → **Config file**（配置文件）并选择文件，或者把它拖到画布上。

- 设置、文字、Sound 映射和 Response 滑块一次全部改变，撤销一次（Mac 上是 ⌘Z，其他系统是 Ctrl+Z）就能回到之前的样子。画布视图按钮、预览的 Blur 和 Invert、Coordinate precision 也会改变，但撤销不会改回它们（它们本来就不能撤销）。
- 文件里的 **Google 字体**会重新下载（已经打开时不重复下载）。**电脑上的字体**没法替你打开：菜单下方的提示会写出文件名——导入这个文件，字母就会按载入的设置出现。
- 不是配置文件的文件（其他 `.json`，或已经损坏的文件）会被拒绝：提示显示 “Config not imported”，什么都不改变。旧版本程序保存的文件会像已保存的作品一样被转换；新版本保存的文件只载入这个版本认识的部分，提示里会说明。
- 用提示上的 × 按钮关闭它；载入另一个字体时它也会消失。

## 11. 常见问题

**线段已经很少了，字母看起来还是很平滑。**
在 Fixed segments 模式下打开 **Merge joined curves**。不开启时，曲线的每一小段都会各自分到线段。

**调整 Corner angle 没有任何变化。**
打开 **Merge through straight lines**（在 Merge joined curves 下面）。不开启时，Corner angle 只影响两段曲线之间的连接点，而这些连接点几乎都已经是平滑的。

**我喜欢某个随机锚点的结果，怎么找回来？**
记下（或 **Copy**）它的种子。以后载入同一个字体，把 Random anchors 设成相同的设置，再把种子输入到 **Seed** 框里。同一次打开页面时，也可以直接在 **Previous** 里点它。如果这个结果是声音选出来的，先按 **Freeze**：它会把实时种子写进输入框。

**为什么看不到骨架点或绿色顶点？**
字母足够大时才会显示。放大画布即可。

**有些控件是灰色的，拖不动。**
它们此刻不会产生任何效果，上方的说明会解释原因——例如随机锚点开启时曲线展平整组变灰；Randomness 为 0% 时随机种子变灰。

**在 Glyphs 里点的字符插错了位置。**
字符会插到文字输入框里光标最后所在的位置。先在输入框里点一下想插入的位置，再点字符。

**黄色提示说有些轮廓“kept their previous shape”（保持了之前的形状）。**
那个设置会让字母的一部分塌陷、自己交叉，或者碰到字母的另一部分（比如中间的空洞），所以应用为那一部分保留了上一个正常的结果。试试温和一点的数值。

**某个字母显示成红色虚线框。**
字体里没有这个字符，或者（Google Fonts 的情况下）它在另一个字符子集里。换一个子集或字体。

**刷新页面后结果会变吗？**
不会。你的文字、设置、Sound 映射和 **Response** 滑块都保存在这个浏览器里，页面再次打开时会恢复，而且相同的设置和种子总会得到相同的结果。Google 字体会自动重新下载；来自你电脑的字体需要重新导入。见[下次打开时](#下次打开时)。想确保留住某个结果，请把它导出。

**我不小心改错了。**
撤销它：Mac 上按 ⌘Z，其他系统按 Ctrl+Z。见[撤销与重做](#撤销与重做)。

**怎样从头开始？**
点状态栏最右端画着回转箭头的按钮（**Reset all**）：它关闭字体，并把文字和每项设置恢复成程序刚打开时的样子。它不能撤销，所以想保留什么，请先导出或保存配置文件。只想让某一个设置组从头开始，就用那一组的重置按钮。见[认识屏幕](#3-认识屏幕)里的“一键从头开始”和[下次打开时](#下次打开时)。

**有个字母不见了，文字输入框下方说有字形 “failed to process”（处理失败）。**
一个字母计算超过 60 秒，程序就会放弃它。这个字母不会出现在画布和导出里；导出字体时会把它列出来，原因是 “Took longer than 60 s; try lighter settings”（耗时超过 60 秒，请用轻一些的设置）。调低最重的那些设置（通常是 Experimental 效果，或很小的 **Anchor spacing**）。

**画布上出现红色提示 “The geometry worker … Reload the page to try again.”**
字母是由程序里一个叫 geometry worker（几何计算器）的部分在后台算出来的。如果它启动不了，或者接连好几次失败或没有响应，字母就再也画不出来了：请刷新页面。如果是某个很重的设置引起的，刷新后把它调低。“The geometry worker could not open this font” 表示读取这个字体文件来绘制时失败了；换一份这款字体的文件试试。

**字母没有随音乐动起来。**
在 Sound 标签页里检查：已经载入字体；文件正在播放（或麦克风正在收音）；**Drive letters** 已打开；**Strength**（在 **Response** 里）高于 0%（为 0% 时 Drive letters 下方会显示 “Strength is 0%: the letters hold still.”）；至少有一个映射是勾选的，并且 **Depth**（或 **Rate**）不是 0%。如果某行下方有灰色提示，点它旁边的 **Enable**——例如 “Turn on Crumple to hear this.” 表示 Crumple 效果是关闭的。如果电平表一直是空的，说明声音太小：调高 **Sensitivity**。程序只在它的标签页可见时才听声音：切换到另一个标签页、把窗口最小化或被其他窗口挡住时，字母不再跟随声音，回来后会接着跟随。

**字母在动，滑块和种子却不动。**
这是有意的：滑块和种子输入框保留你的设置。每个被驱动的滑块上那条细竖线显示声音把它带到了哪里，被驱动的种子输入框旁边的小数字就是实时种子。声音停下后，字母会回到你的设置。按 **Freeze** 可以把当前的样子复制到滑块和种子输入框里。

**选了一个目标后，某个设置自己打开了。**
这个目标只有在那个设置打开时才起作用，所以程序替你打开了它，并在该行下方作了说明（例如 “Turned on Ripple.”）。更换这一行的目标或删除这一行时，它会保持打开；如果不想要，自己关掉即可。

**导出的结果和正在动的字母不一样。**
SVG、PNG 和字体导出使用的是滑块，而不是声音。在想要的时刻按 **Freeze**，然后再导出。开启 **Motion contrast**、**Pitch reactive** 或 Thorn 轮流变化时，Freeze 会让每个字母都使用共同值，所以冻结后的字母比移动时看起来更相像。想留住动态本身，就录一段视频：导出对话框里的 **Video — live sound**，或 Sound 标签页里的 **Record**（见[录制视频](#录制视频)）。

**视频一卡一卡的。**
视频每秒得到的帧数，就是声音移动字母时程序每秒能画出的数量——也就是 **Live · N fps** 的数字，最多 30。设置很重、文字很长、**Motion contrast** 和 **Pitch reactive** 都会让它变小；每秒低于大约 8 帧时，Record 组会显示 “Too slow for a smooth video: try fewer effects or a shorter text.”（太慢，视频不会流畅：试试少开几个效果或缩短文字）。关掉一些 Experimental 效果、换一段更短的文字，或者调低 Motion contrast 和 Pitch reactive，然后重新录制。字母静止时视频会保持画面：这不是故障。

**为什么得到的是 WebM 文件，而不是 MP4？**
不是每个浏览器都能写 MP4。你的浏览器不能写时，程序会改存为 WebM，并显示 “MP4 isn't supported in this browser: saved as WebM.”；这时 **Format** 列表里的 MP4 会标着 “(not supported in this browser)”。WebM 可以在网页浏览器和 VLC 这类播放器里播放。如果一定要 MP4，换一个浏览器录制（比如新版的 Chrome 或 Edge），或者用视频转换工具转换。有些播放器不显示 WebM 文件的总时长；视频本身是完整的。

**视频里的声音和画面有一点对不上。**
字母总是比声音慢一点点，因为每个新形状都需要时间来计算。程序会让视频里的声音延后同样的时间，这个时间在录制开始时测量；但仍可能差大约一帧，如果录制期间帧率变化很大，差得会更多。按 **Record** 之前先让声音带动字母几秒钟，好让程序测出延迟，并用轻一些的设置让帧率保持稳定。如果需要完全对齐，可以在视频编辑软件里移动声音。

**我切换标签页时录制停了。**
浏览器不会绘制看不见的页面，视频就会卡住不动。所以标签页被隐藏时——切换到另一个标签页或把窗口最小化——程序会结束这次录制，保存已经录下的部分，并显示 “Recording stopped because the tab was hidden.”（因为标签页被隐藏，录制已停止）。在录制结束之前，让程序的标签页保持打开并在屏幕上可见。

**改了字号或画布之后，刺变长（或变短）了。**
Thorn 的 **Reach** 按画布的比例计算，而不是按字母，所以刺在画布上所占的比例不变：文字越小或画布越大，刺相对字母就越长。调低或调高 **Reach** 就能得到想要的长度；它旁边的 **ⓘ** 会告诉你此时 100% 相当于多少个 em。

**我的刺在画布边缘被裁掉了。**
刺可以伸出画布。大画布上会完整显示它们，但预览以及 SVG 和 PNG 导出会在画布边缘把它们裁掉，和画布外的其他东西一样；刺伸出去不会出现红色提示。调低 **Reach**，或者多按几次 **Next variant**，直到刺指向画布里面。字体文件没有画布：在那里，只有很长的刺才会被修剪（见[保存为字体（OTF）](#保存为字体otf)）。

**音乐播放时，每次只有少数几个字母的刺在变。**
这是有意的。开启 Thorn 时，字母轮流变化，所以新的刺像波浪一样传过文字，而不是每个字母一起跳：每四分之一秒最多约五分之一的字母在变，每个字母最多大约每 1¼ 秒变一次（见 Sound 标签页里的“**刺轮流变化**”）。想让每个字母一下子都换上最新的刺，按 **Freeze**。

**音乐播放时，有个字母在画布边缘被裁掉了。**
声音带动字母时，文字停在按你的滑块算出的位置，所以从不晃动。这样一来，声音把某个字母扭得比你的滑块更远时，它可能伸出画布边缘：大画布上完整显示，但预览和视频会在那里把它裁掉。给文字周围多留些空间（调小 **Size**，或选一个离那条边远一些的 **Position**），或者调低对字母扭曲最多的那几行的 **Depth**。

**刺长的位置和我以前保存的作品不一样。**
这个版本的程序用一种更稳定的方式挑选刺的点，让它们在其他设置变动时留在原处（见 Thorn 里的“**其他设置变动时，刺留在原处**”）。因此，同一个 **Seed** 得到的刺和旧版程序不同。多按几次 **Next variant**，直到你再次满意为止。

**会上传什么东西吗？**
不会。本地字体和音频文件始终留在你的电脑上，麦克风的声音只在你的浏览器里被测量；视频在你的浏览器里生成，直接保存到你的电脑上；Google 字体从 Google 下载，不会发送到其他任何地方。

## 12. 术语表

| 术语 | 含义 |
|---|---|
| **Glyph 字形** | 字体中画出的一个图形——字母、数字或符号。 |
| **Contour 轮廓** | 一条闭合的外形线。“O” 有两条：外圈和中间的洞。 |
| **Counter 字腔** | 字母内部被包围的空白，如 “o”“a”“B” 中的洞。 |
| **Curve / segment 曲线 / 曲线段** | 两点之间的一段轮廓。字体用 Bézier 曲线来存储。 |
| **Anchor 锚点（曲线上的点）** | 位于轮廓线上的点。 |
| **Control point 控制点（曲线外的点）** | 牵引曲线、但本身不在曲线上的点。 |
| **Vertex 顶点** | 新的直线形状的拐角。 |
| **Polygon 多边形** | 只由直线组成的形状。 |
| **Crease 折痕** | 实验效果折叠轮廓时所沿的直线；只有在折痕上才会增加棱角。 |
| **Fold 翻折** | 实验效果超过 100% 时发生的事：字母的一部分叠到另一部分上。重叠处会合并成一个只有直边的形状。 |
| **Decibel 分贝（dB）** | 响度的单位。在 Sound 标签页里，0 dB 是录音能达到的最大响度，数字越低（负数）越安静。 |
| **Onset 起音** | 一个新声音开始的瞬间，比如一下鼓点；**Beat** 条形表会在这时跳到满格。 |
| **Mapping 映射** | Sound 标签页里，从一个声音读数（比如 **Level**）到一个滑块或种子的连接；连上后，它的数值就会随声音变化（滑块或种子输入框本身不动，滑块上的一条细线或种子输入框旁的一个小数字显示当前的数值）。 |
| **Depth 深度** | 读数最强时，一个映射让它的滑块移动多远，按滑块轨道的比例计算。 |
| **Rate 速率** | 一个映射让它的种子往下一个走得有多频繁，从 0 到 100%。 |
| **fps 每秒帧数** | 声音移动字母时，程序每秒能跟上多少个新形状。视频每秒得到同样多的帧。 |
| **Strength 强度** | Sound 标签页 **Response** 组里的设置：所有映射让字母移动多远，从 0%（字母不动）到 400%；100% 时完全按映射的设置移动。 |
| **Motion contrast 动态对比** | **Response** 组里的设置：让每个字母按自己的幅度反应，有些字母比滑块细线显示的共同幅度动得少，有些动得多。 |
| **Pitch reactive 音高响应** | **Response** 组里的设置：让音高决定哪些字母动得最多——近来曲调中的低音让左边的字母动得最多，高音让右边的字母动得最多，不管曲调在哪个音区。 |
| **刺轮流变化** | Sound 标签页里开启 Thorn 时：字母被分成五组，依次换上声音最新的刺设置，所以每次只有少数几个字母的刺在变。 |
| **Melody 旋律** | 一个声音读数，每当曲调换到一个新的音就跳起。Response 组里的 **Melody tracking** 用它给滑块映射加一把力。 |
| **Release 释放** | 声音过后各个读数回落得有多慢（旧版本里叫 Smoothing）。 |
| **Take 一次录制** | 一段视频录像，从按下 **Record** 到它结束。 |
| **MP4** | 一种几乎在哪里都能播放的视频文件格式。 |
| **WebM** | 一种开放的视频文件格式，网页浏览器和许多播放器都能播放；浏览器不能写 MP4 时就存成它。 |
| **Em / Units per em** | 字体看不见的设计方格，以及它的字体单位大小（常见 1000 或 2048）。 |
| **Font unit 字体单位（u）** | 字体内部的度量单位，控制项里的所有尺寸都用它。 |
| **Baseline 基线** | 字母坐落的那条线。 |
| **x-height / cap height** | 小写 “x” 的高度 / 大写字母的高度。 |
| **Ascender / descender 上伸 / 下伸** | 高出 x 高度的部分（h、d）/ 低于基线的部分（p、g）。 |
| **Advance width 字宽** | 排一个字母后文字向前推进的距离，包括它两侧的留白。 |
| **Kerning 字偶距** | 特定字母组合之间的细微间距调整，如 “AV”。 |
| **Variable font 可变字体** | 一个文件里包含一系列字重或宽度的字体。 |
| **Font collection 字体集合** | 一个装着好几款字体的文件（`.ttc` 或 `.otc`），通常是同一字体家族的各个样式。 |
| **SVG** | 矢量图像格式，任何尺寸下都保持清晰。 |
| **OTF（OpenType）** | 可以安装到电脑上的标准字体文件格式。 |
