# None-Curve 用户指南

[English](USER_GUIDE.md) · **中文**

本指南面向设计师和所有感兴趣的人，不需要任何编程知识。它会说明屏幕上每个区域的作用、每个控制项会带来什么变化，以及如何保存作品。

> 网页界面是英文的。本指南提到按钮和选项时，会写出界面上的英文名称，并在旁边附上中文解释，方便对照。

---

## 1. None-Curve 能做什么

字体里的字母是用平滑曲线画出来的。None-Curve 会把这些曲线**改用直线重建**，让字母变成多边形——效果可以从“几乎和原字一样”，一直调到“棱角分明的折面”“方形”“对齐网格”，或“粗糙、像刻出来的”。

你可以：

- 从电脑或 Google Fonts 载入字体。
- 输入任意文字，拖动滑块时实时看到它被重建。
- 放大查看单个字母，以及它原本的曲线控制点。
- 把一个字母或整段文字保存为 **SVG** 图像，或把改造后的字母生成新的**字体文件**（`.otf`）。

所有操作都在你的浏览器里完成，字体文件不会被上传到任何地方。

---

## 2. 你需要准备什么

- 电脑上的新版浏览器（Chrome、Edge、Firefox 或 Safari）。手机也能用，但大屏幕会舒服得多。
- 电脑里的字体文件（`.ttf`、`.otf`、`.woff` 或 `.woff2`），**或者**能上网，以便从 Google Fonts 载入字体。
- 网页地址，例如 `https://m1ingx1xx1.github.io/None-Curve/`，也可以向搭建项目的人索取。

## 3. 认识屏幕

屏幕分成上下两行、五个区域：

```text
┌────────────────────────╥─────────────────────────────────────────────────────┐
│ ① 功能区               ║ ② 结果画布                                          │
│   Import font 导入字体 ║   你输入的文字，实时重建                            │
│   字体信息             ║                                                     │
│   造型控制项           ║                                                     │
╞════════════════════════╩═╦══════════════════════════╦════════════════════════╡
│ ③ 排版、字形、颜色       ║ ④ Text 文字              ║ ⑤ Preview 预览         │
│   三个标签页             ║   在这里打字             ║   ② 的缩小版，         │
│                          ║                          ║   可模糊/反色          │
└──────────────────────────╨──────────────────────────╨────────────────────────┘
```

1. **功能区（左上）**——**Import font**（导入字体）按钮、已载入字体的信息，以及决定字母形状的控制项，分为 **Geometry**（几何）和 **Experimental**（实验）两个标签页。向下滚动可以看到全部控制项。
2. **结果画布（右上）**——最大的预览区，显示一张固定尺寸的画布（类似一页纸），上面是你输入的文字，并按当前设置重建。要导出的那一页放在中间，带着柔和的阴影，像是稍稍浮在背景上。页面周围的背景稍暗一些，铺着浅浅的网格，所以页面本身保持干净，和导出效果完全一样。拖动文字时，或放大到 200% 以上时，网格也会出现在页面上，方便对齐。改动设置后，字母会在后台陆续更新——这期间应用照常可用，画布角落的标签会显示 “Updating…”，直到全部更新完。底部的 **Canvas size** 栏可以打开画布尺寸设置。
3. **排版、字形与颜色（左下）**——三个标签页。**Typography**（排版）设置文字的字号、间距、倾斜、对齐和位置。**Glyphs**（字形）列出字体里的每个字母、数字和符号：点击一个就会把它打进文字输入框，适合输入 `©`、`→`、带重音的字母这类不好打的符号。**Color**（颜色）设置文字和背景的颜色。
4. **Text 文字输入**——输入想在画布上看到的文字。
5. **Preview 预览**——结果画布的缩小版，显示你输入的全部文字，并带有自己的 **Blur**（模糊）滑块和 **Invert**（反色）按钮。

页面最上方有 **Export…**（导出）按钮；最下方的状态栏会说明当前显示的内容和启用了哪些设置。

**亮色或暗色界面。** 状态栏最右端有两个小按钮——太阳和月亮——用来在亮色和暗色界面之间切换。每次打开时，程序都会跟随你电脑的亮色 / 暗色模式；你在这里的选择只在关闭页面前有效，不会被记住。画布不受影响：它的颜色来自 **Color** 标签页。

**调整各区域的大小。** 图中的双线就是各区域之间那些细细的灰线，可以拖动：

- **上下两行之间**——上下拖动，让画布或下面一行更高；
- **功能区和画布之间**——左右拖动；
- **排版 / 字形 / 颜色标签页和文字输入之间**——左右拖动；
- **文字输入和预览之间**——左右拖动。

一边变大多少，另一边就变小多少，所以整个界面始终正好放进窗口里，页面不需要滚动。每个区域都有最小尺寸。双击细线可以让它回到原来的位置。下次打开时程序会记住你的设置。

> 在手机上，这些区域会从上到下排列：功能区、画布、文字输入、预览、排版 / 字形 / 颜色标签页。造型控制项默认收起，点画布工具栏里的 **Parameters** 展开。

## 4. 五分钟快速上手

1. 点左上的 **Import font** → **Google Fonts** → 选择 **Inter** → **Load font**。
2. 在文字输入框里输入一个词，比如 `Hello`。
3. 在功能区找到 **Curve flattening**（曲线展平），选择 **Fixed segments**（固定线段数），把 **Segments per curve**（每条曲线的线段数）设为 `2`。
4. 打开 **Merge joined curves**（合并相连曲线），字母会出现明显的折面效果。
5. 点顶部的 **Export…** → **SVG — main view** → **Download SVG**。

这就是完整的流程。本指南接下来会逐步详细说明。

## 5. 载入字体

点功能区最上方的 **Import font**，会出现两个选项。

### 从电脑载入

- 选择 **Local file**（本地文件）并挑一个字体文件，**或者**直接把字体文件拖到大画布上。
- 支持 `.ttf`、`.otf`、`.woff`、`.woff2`。不支持字体集合（`.ttc`）。
- 文件始终留在你的电脑上，只由浏览器读取。

### 从 Google Fonts 载入

选择 **Google Fonts**。在 **Family**（字体名称）框里，你可以：

- **从列表中选**——列出了 15 款字体，按无衬线、衬线、粗衬线和等宽分组（例如 Google Sans、Inter、EB Garamond、Bodoni Moda、Arvo、JetBrains Mono）。
- **输入字体名称**——任何 Google 字体都可以，但拼写要和 fonts.google.com 上完全一致（大小写也要一致：写 `Open Sans`，不要写 `open sans`），然后点 **Use "…"**。
- **粘贴链接**——在 fonts.google.com 上复制某款字体页面的地址，例如 `https://fonts.google.com/specimen/Plaster`，粘贴进来即可。带有字重或斜体信息的链接（例如 `…css2?family=Roboto:ital,wght@1,700`）也能识别。

选定字体后再设置：

- **Weight**（字重）——字有多粗（400 为常规，700 为粗体）。所有字体都可以选，包括把所有字重放在一个文件里的“可变字体”。
- **Italic**（斜体）——如果这款字体有斜体。
- **Character subset**（字符子集）——Google 按语言拆分字体文件（如 `latin`、`latin-ext`、`cyrillic`）。一次只载入一个子集，所以其他语言的字符可能缺失。

点 **Load font**。下载完成后，字体名称会出现在功能区。

### 出问题时

功能区会显示发生了什么，并提供 **Retry**（重试）：

| 提示 | 含义 | 怎么办 |
|---|---|---|
| Empty file / Unsupported format | 文件不是字体，或者是空的。 | 换成 `.ttf`、`.otf`、`.woff` 或 `.woff2` 文件。 |
| Font parsing failed | 文件已损坏。 | 换一份这款字体的文件。 |
| Google Fonts API error | Google 不认识这个名字。 | 检查拼写和大小写。 |
| Network / CORS error | 没有网络，或浏览器插件拦截了请求。 | 检查网络或广告拦截插件，然后点 **Retry**。 |
| Only fonts.google.com … URLs are accepted | 粘贴的不是 Google Fonts 链接。 | 粘贴来自 fonts.google.com 的链接。 |

新字体载入失败时，屏幕上会继续保留之前的字体。

## 6. 输入文字

- 在 **Text** 输入框（右下）里打字，按回车换行。
- **Clear** 旁边的示例菜单提供现成的示例文字：**Lorem ipsum**（假字填充）、**Pangrams**（包含所有字母的句子）、**Spacing**（如 “Hamburgefontsiv” 这类经典字距测试词）和 **Alphabet**（全部大写、小写、数字和常用标点，每组一行）。程序启动时显示 Lorem ipsum。你改动文字后，菜单会显示上一个示例并标注 “(edited)”；再选一次它就能恢复原文。
- **Clear** 清空输入框。
- **Text** 标题右边的 **AA**（全大写）、**Aa**（每个单词首字母大写）和 **aa**（全小写）会改变字母在画布和导出中的样子，你输入的文字本身不会变。再点一次高亮的按钮即恢复原样。（鼠标悬停在按钮上可以看到它的名称。）
- 输入框下方会显示字符数，以及是否应用了字体自带的**字偶距**（像 “AV” 这类字母组合之间的细微间距调整）。
- 如果某个字符在字体里不存在，画布上会显示一个**红色虚线框**，并在输入框下方列出；这一行的其余部分照常显示。
- 最多显示 1000 个字符。
- 不好直接打出来的符号，可以在左下的 **Glyphs** 标签页里点一下。它会插入到输入框里光标所在的位置（如果你还没点过输入框，就加在末尾）；如果你选中了一段文字，符号会替换掉它。
- 把 Glyphs 列表拖窄时，它只显示字符本身、不显示编码，这样能放下更多字符；拖宽就会重新显示编码（鼠标停在字符上也能看到）。
- **Glyphs** 列表上方的**搜索框**可以按字符本身（`A`）、编码（`U+0041`）或名称的一部分（`arrow`、`dieresis`）查找字符。

## 7. 查看结果

### 画布工具栏

**轮廓视图**——画出哪种形状：

- **Original**（原始）——字体原本的样子，带曲线，用来对比。
- **Flattened**（展平后）——套用你全部设置后的结果（默认）。
- **Compare**（对比）——灰色的结果上叠加蓝色虚线表示的原始曲线。

**图层**——可以开关的附加信息（一开始只开着 **Fill**）：

- **Fill**（填充）——实心字母。关闭后只显示轮廓线。
- **Skeleton**（骨架）——决定原始曲线的点：蓝色方块在曲线上；空心橙色圆是牵引曲线的“控制点”；细线把它们连起来。
- **Vertices**（顶点）——新直线形状每个拐角处的绿色圆点。
- **Metrics**（度量线）——几条水平参考线：ascender（上伸线，“h” 这类高字母的顶部）、cap height（大写字母顶部）、x-height（“x” 的顶部）、baseline（基线，字母坐落的线）、descender（下伸线，“p”“g” 的底部）。

> 字母足够大时才会显示骨架点和顶点。如果画布提示 “Zoom in to see skeleton points and vertices”，请放大。

**缩放**——`−` 和 `+` 缩小、放大，**Fit** 重新显示全部文字。也可以在画布上滚动鼠标滚轮缩放，按住拖动来移动视图。

### 查看单个字母

- 点画布上的某个字母即可选中它（点在这个字母所占的位置里就行）。它在文字中出现的每一处都会换成高亮色。这个颜色根据你的文字颜色和背景颜色算出来，既醒目又容易看清——比如米色纸上的黑字会高亮成朱红色。鼠标指着某个字母时，它也会这样变色。从 Glyphs 列表插入字符时，也会选中该字符。
- 点画布上的空白处，或按 Esc，即可取消高亮。拖动画布不会取消高亮。
- 造型控制项里的统计数字（顶点数、曲线数等）针对的是当前选中的字母；取消高亮后，针对的是你最后选中的那个字母。每个标签页顶部的 **Statistics** 一行始终写明是哪个字母，例如 “Statistics: l U+006C”。
- 预览从不显示高亮，因为它显示的正是导出后的样子。
- 想看细节，就在画布上放大。

### 预览：模糊、反色和宽度

右下角的 **Preview** 按导出效果显示整张画布——画布以外的部分会被裁掉。它跟随画布的 Original / Flattened / Compare 和图层按钮，但不跟随画布的缩放。

- **Blur** 让预览变模糊，就像从远处看或眯着眼看。这样能抛开细节，只看字母整体的形状和节奏——可以快速检查粗糙或折面风格的文字是否仍然好认。
- **Invert**（反色）交换预览里文字和背景的颜色——浅底深字变成深底浅字，再点一次换回来。适合检查文字在两种配色下的效果，比如做招牌或深色海报时。
- Blur 和 Invert 只改变这个小视图。想把它们保存进文件，导出时勾选 **Export the preview look**。
- **想让预览更宽：** 拖动它左边的细线（见第 3 节“调整各区域的大小”）。

### 画布尺寸

文字排在一张固定像素尺寸的**画布**上，类似一页纸或一个画板。点大画布下方的 **Canvas size** 栏可以打开或收起它的设置：

- **W** 和 **H**——宽和高（像素）。拖动滑块或直接输入数字（按回车或点别处后生效）。
- **1:1、4:3、16:9、4:5、3:2、3:4**——常见画幅比例。宽度不变，高度随之调整。**Swap** 把横向画布变成竖向，或反过来。
- **1×、2×、3×、4×**——PNG 导出放大几倍。排版不变，倍数越高图片越大越清晰（下方会显示尺寸，例如 2400 × 1600 像素）。

如果文字太大放不进画布，大画布上会出现一条红色提示；预览和导出会在画布边缘把文字裁掉。用 **Typography → Fit text** 可以让文字刚好放下。

## 8. 造型控制项

这些控制项在左上的工具面板里，分为两个标签页。**Geometry** 标签页按固定顺序从上到下依次生效，后面的步骤处理的是前面步骤的结果；**Experimental** 标签页在它全部完成之后生效：

**Curve flattening 曲线展平 → Squaring 方形化 → Anchors 锚点 → Grid & angles 网格与角度 → Distortion 扰动 → Experimental 实验效果**

所有尺寸都以**字体单位**计算。字体是在一个看不见的正方形（称为 **em**）上设计的，通常宽 1000 或 2048 个单位（字体信息里的 “Units/em”）。所以在 1000 单位的字体里，“20 u” 相当于字高的 2%。缩放画布不会改变这些设置的效果。

名称不够直观的控制项都有简短说明。为了让面板保持清爽，说明默认是收起的：点控制项名称旁边的小 **ⓘ** 就能展开阅读，再点一次收起。想一次看到全部说明（第一次使用时很有用），勾选工具面板顶部、标签页下方的 **Show all explanations**（排版和颜色标签页里的说明也会一起展开）。黄色警告和统计数字始终显示。如果某个设置会破坏形状（例如让字母自己交叉，或者把 **A**、**B**、**e** 中间的空洞推到字母外面、显示成一块实心），程序会先为字母的那一部分尝试一个温和一些的版本——少一点方形化、稍微简化的轮廓、角度锁定改用阶梯、或者小一点的扰动——并用一条灰色提示说明。只有都行不通时，那一部分才会保持上一步的样子，并出现一条黄色提示说明原因。

### Curve flattening（曲线展平）——曲线如何变成直线

先选一种 **Mode**（模式）：

- **Adaptive**（自适应）——尽量贴近原形。**Tolerance**（容差）是直线允许偏离曲线的距离。数值小（0.1–2）时几乎和原字一样；数值大（20–500）时明显有棱角。单独使用 Adaptive 时，大约到 100 就不会再变粗犷了——打开 **Merge joined curves** 才能更进一步。
- **Fixed segments**（固定线段数）——每条曲线都换成同样数量的直线。**Segments per curve** 设置这个数量（1–32），线越少越粗犷、折面感越强。

**Merge joined curves**（合并相连曲线，两种模式都可用）——获得强烈折面效果的关键。你眼中的一条弧，在字体里通常由好几小段曲线拼成。不合并时，设置作用于每一小段，字母看起来仍然平滑；合并后，整条看得见的弧才算一条曲线：

- 在 **Fixed segments** 下，把 **Segments per curve** 依次设为 4、3、2，从含蓄过渡到强烈；
- 在 **Adaptive** 下，调大 **Tolerance**（试试 50、150、500）：每条弧会在容差允许的范围内尽量拉直，最多变成一条直线。

下面的合并设置两种模式共用，切换模式时会保留。

- **Break merged curves at**（在哪里断开合并的曲线）——一条合并曲线在哪里结束、下一条从哪里开始：
  - **Corners & extremes**（尖角和极值点，默认）——在尖角处，以及每个圆形最左、最右、最上、最下的点断开。圆形的 “O” 会分成四段四分之一弧，折面均衡对称。
  - **Corners only**（只在尖角）——只在尖角处断开。像 “O” 这样整圈平滑的形状会变成一条曲线，可能得到三角形或非常简化的形状。
- **Merge through straight lines**（穿过直线合并）——把平滑流进曲线的直线部分也一起合并，比如 n、m、u 的竖笔流进弧线的地方。它们会和曲线一起被重新塑形，得到粗犷得多的“低分辨率”效果。竖笔的端点可能被削掉，所以默认关闭。
- **Corner angle**（尖角阈值）——拐弯要多急才算尖角（默认 15°），比它平缓的拐弯会被合并。单独调它几乎看不到变化，因为字体内部的曲线几乎总是平滑相接的。**打开 Merge through straight lines 后它才真正起作用：** 把角度调大（试试 45° 和 90°），每个字母会有越来越多的部分合并成几笔大的折线。

### Squaring（方形化）——让圆形字母变方

把圆形推向矩形。设为 **100%**（“Square”）时，圆形的 **O** 和它中间的洞都会变成正方形，笔画粗细保持不变。

- **Amount**（强度）——0% 为关闭，**Soft** 为一半，**Square** 为完全方形；中间的值用滑块调。
- **Applies to**（作用范围）：
  - **Round contours**（只作用于圆形轮廓，推荐）——只改变接近圆或椭圆的形状，如 O、o、0，以及 b、d、g、p、q 的圆腔。A、E、S 这类直线或尖角形状保持原样。
  - **All contours**（所有轮廓）——每个形状都推向矩形。效果强得多，有些字母可能会显得奇怪。

小技巧：方形化之后，加一点 **Anchor reduction**（锚点简化，例如 2），直边会更干净。

### Anchors（锚点）——轮廓上有多少个点

- **Anchor spacing**（锚点间距）——在直线边上加点，使每段都不超过这个长度。形状不变，但后面的步骤（比如扰动）会有更多点可以处理。0 为关闭。
- **Anchor reduction**（锚点简化）——去掉对形状影响很小的点。数值越大去掉的点越多、字母越简化；数值过大可能抹掉小细节。0 为关闭。
- 两者同时开启会互相抵消（简化会删掉刚加上的点），界面会提示。
- **Reset anchors** 同时关闭两者。

### Grid & angles（网格与角度）——构成感、几何感的造型

- **Snap to grid**（网格吸附）+ **Grid size**（网格大小）——把每个点移到一张看不见的网格上，就像在方格纸上画字。网格越大，字母越像像素块。开启时，画布上会淡淡地画出网格。
- **Angle lock**（角度锁定）+ **Allowed directions**（允许的方向）——把每条边拉直到固定的几个方向：
  - **90°**——只有水平和垂直线。
  - **45°**——再加上对角线。
  - **30°** / **15°**——更细的角度间隔。
- 如果拉直会让字母的某部分移动太远，那一部分会改成小阶梯，字母不会跑出原来的位置。
- 两者同时开启时先吸附网格，所以角度锁定可能会让部分点稍微离开网格。
- **Reset grid & angles** 同时关闭两者。

### Distortion（扰动）——粗糙、手工或石刻般的边缘

以可控、可重复的方式移动轮廓上的点。

- **Noise amplitude**（噪声幅度）——点最多移动多远。0 为关闭。小数值（5–20）带来轻微的手工切割感；大数值像被磨损或侵蚀。
- **Noise frequency**（噪声频率）——边缘起伏的密度。低：缓慢、温和的波浪；高：急促、细碎的粗糙感。
- **Normal bias**（法线偏向）——点移动的方向。0% 让点沿着边滑动；100% 让边向内外凹凸。
- **Seed**（种子）——选择某一种随机图案的数字。同样的种子永远得到完全相同的结果，所以可以随时找回喜欢的版本。**Next variant** 换成下一种图案。
- **Reset distortion** 关闭扰动，但保留你的种子。

扰动可能会降低文字的可读性，请适度使用。

### Random anchors（随机锚点）——每次都不一样，但可以复现

位于 Geometry 标签页的最底部。平时程序会在曲线上按规则的间距放点（即 Curve flattening 曲线展平）。打开 **Use random anchors** 后，点改为放在字母原始轮廓上的随机位置——点始终落在真实的字母上，随机的只是“放在哪里”。后面的控制项（Squaring、Anchors、Grid & angles、Distortion）照常叠加。

随机锚点开启期间，**Curve flattening** 的控件会变灰并附上说明，因为随机锚点取代了它们——调了也不会有变化。关掉随机锚点即可恢复使用。

- **Density**（密度）——每 1000 字体单位轮廓大约放多少个点。数值小（2–6）字母会变得粗糙、块状；数值大则接近原字形。
- **Randomness**（随机程度）——0% 时点均匀分布；100% 时每个点可以在自己的一小段范围内随意移动。点与点之间不会互换位置，所以字母不会缠在一起。
- **Keep sharp corners**（保留尖角）——保留字母真正的尖角（例如竖笔末端和衬线），让它们保持干净利落。关掉后效果更松散。
- **Seed**（种子）——决定某一个随机结果的数字。
  - **Shuffle** 随机换一个新种子，并显示在输入框里。
  - **Copy** 复制种子，方便贴到你的笔记里。
  - **Previous** 列出你这次打开页面后试过的种子，点一下就能回到那个结果。
  - 想以后重现某个结果：载入同一个字体，使用相同的设置，把种子输入到框里即可。
  - **Randomness** 为 0% 时点是均匀分布的，种子不起作用，会变灰。
- **Reset random anchors** 关闭随机锚点并恢复其他设置，但保留你的种子。

种子也会显示在底部的状态栏和导出对话框里，所以导出时它会被一起记录下来。

### Experimental（实验）标签页——可以叠加的效果

在工具面板顶部、**Geometry** 标签页的旁边。这里的效果作用在 Geometry 标签页的最终结果上，可以同时打开任意多个。每个效果都沿**笔直的折痕**折叠字母：只会增加棱角，不会产生曲线；任何组合都不会让字母自己交叉，也不会把 **A**、**B**、**e** 中间的空洞推到字母外面。它们始终按同一顺序运行：先 **Noise**，再 **Ripple**，最后 **Wind**。

**Noise——揉皱的纸**

- **Use noise**——打开该效果。
- **Amount**（强度）——字母被揉皱的程度。数值小时像轻轻手折过；100% 时折痕锐利明显。
- **Facet size**（刻面大小）——折痕的大小，按 em（字体的设计正方形）的比例计算。刻面小，折痕多而细；刻面大，折痕少而大，能让整个笔画弯折。最小值也会让折痕之间保持足够距离，看起来仍是棱角。
- 统计数字显示轮廓最多移动了多远（**Max move**），以及折痕增加了多少个角（**Creases**）。

**Ripple——多边形波纹**

- **Use ripple**——打开该效果。
- **Amount**（强度）——波纹把轮廓推出、拉回的程度。50% 左右字母仍然好认；100% 时会被撕成尖锐、破碎的形状。
- **Wavelength**（波长）——相邻两道波之间的距离，按 em 的比例计算。波长短，锯齿多而细；波长长，整个笔画都会弯折。
- **Sides**（边数）——波纹圈的形状：3 是三角形，4 是正方形，8 是八边形，最多 12。波纹圈总是平放在一条边上。
- **Center X / Center Y**（中心 X / Y）——波纹从哪里开始，按每个字母的宽度和高度的比例计算（50% / 50% 是字母正中）。小于 0% 或大于 100% 时中心在字母外面，波纹会从一侧扫过字母。
- **Fade**（衰减）——离中心越远波纹减弱得越多。100% 时到字母最远的边缘就完全消失。

**Wind——被风拉扯的字母**

- **Use wind**——打开该效果。
- **Direction**（方向）——风吹向哪里：0° 向右，90° 向上，180° 向左，270° 向下。
- **Strength**（强度）——字母被拉长多少。迎风的一侧保持不动；字母的某一部分离迎风侧越远，就被拉得越远。100% 时，每一部分被拉出的距离等于它离迎风侧的距离，所以字母可能伸进相邻的字母。
- **Gust size**（阵风大小）——阵风拉动的条带宽度，按 em 的比例计算。风向水平（0° 或 180°）时，同一行的所有字母共用同样的条带，所以尾迹会笔直地贯穿整行文字。
- **Gustiness**（阵风度）——各条带之间的差别。0% 时每条带被拉得一样多，字母只是被拉长；100% 时有的条带几乎不动，有的被拖得很远，留下参差、直边的尾迹。

**Seed**（种子）——这个标签页上所有效果共用一个数字：它决定 Noise 的折痕和 Wind 的阵风（Ripple 没有随机性）。种子和设置相同，字母就相同；**Next variant** 换下一个。**Reset experimental** 关闭所有效果并恢复其设置，但保留你的种子。

同一个字母的每次出现折痕都一样，所以导出的字体与画布上看到的完全相同。

### Typography（排版）标签页——字号、间距和对齐

**Typography**、**Glyphs** 和 **Color** 三个标签页在左下。这些设置决定文字在画布上怎么排，不改变字母的形状，也不影响导出的字体文件。

- **Size**（字号）——以像素表示的字号（一个 em 在画布上有多高）。改变画布尺寸时字号保持不变。可以拖动滑块，也可以直接输入数字。
- **Fit text**——让文字尽量大，同时和画布边缘保持 25 像素的距离。
- **Tracking**（字间距）——字母之间额外的距离，负值让字母靠得更近。
- **Line height**（行距）——行与行之间的距离。1 是字体本身的行距，2 是两倍。
- **Slant**（倾斜）——让字母倾斜，类似简单的斜体。正值向右倾，负值向左倾。
- **Align**（对齐）——三个画着横线的按钮，让各行文字靠左、居中或靠右对齐。
- **Position**（位置）——文字在画布上的位置。点九个圆点之一：四个角、四条边的中点或正中间。文字会移到那里，并和边缘保持 25 像素的距离，各行的对齐也会跟着变：左边一列靠左、中间一列居中、右边一列靠右。选中的圆点会发光。点 **Free**（自由）可以自己摆放：文字先回到起始位置，然后在大画布上直接拖动（随时再点 Free 就能回到起始位置）。文字到画布边缘就会停住，不会被拖出页面。在画布其他地方拖动仍然是移动视图。
- **Reset typography** 把这些设置恢复成初始值。

### Color（颜色）标签页——文字和背景颜色

- **Presets**（预设）——十二组现成的配色，两个圆点分别是文字颜色和背景颜色。默认是 **Charcoal**（浅色纸上的深色文字）。
- **Random** 随机挑一组仍然好认的配色；**Swap** 交换文字和背景的颜色。
- **Text**（文字）和 **Background**（背景）——点颜色条可以挑任意颜色，也可以输入十六进制色值，比如 `#35f2b4`。
- **Transparent background**（透明背景）——导出时不含背景，方便把文字放到别的东西上。此时画布显示为棋盘格（用你的配色生成，所以文字依然好认）。
- 下方的 **Contrast**（对比度）表示这组颜色是否好认；低于 3 : 1 时会出现黄色提示，说明文字会很难看清。

画布、预览以及 SVG 和 PNG 导出都使用这些颜色。字体文件没有颜色。

## 9. 常用配方

**粗犷的折面字（类似“每条曲线 4 / 3 / 2 条线”）**
Curve flattening → **Fixed segments**，打开 **Merge joined curves**，**Break merged curves at** 选 Corners & extremes，**Segments per curve** 设为 4（含蓄）、3 或 2（强烈）。

**用 Adaptive 模式做折面字形**
Curve flattening → **Adaptive**，打开 **Merge joined curves**，**Tolerance** 设为 50（含蓄）、150 或 500（非常粗犷）。

**极端的低分辨率字形**
在上面任一配方的基础上，打开 **Merge through straight lines**，把 **Corner angle** 调到 45°–90°。想要最简化的形状，可以把 **Break merged curves at** 改成 Corners only。

**方形的 O 和其他圆形字母**
Squaring → **Square**，Applies to 选 **Round contours**，再到 Anchors → **Anchor reduction** 设为 2。输入 “OO oo 00” 检查效果。

**像素 / 网格风格**
Grid & angles → 打开 **Snap to grid**，**Grid size** 约为字体 Units/em 的 5%（例如 1000 单位的字体设为 50）。再打开 **Angle lock** 并选 **90°**，就只剩水平和垂直的边。

**石刻或风化的质感**
固定线段数 3 并开启合并，然后 Distortion → **Noise amplitude** 10–30、**Noise frequency** 8–15、**Normal bias** 70%。不断点 **Next variant**，直到找到喜欢的图案。

**随机的手工切割感**
Random anchors → 打开 **Use random anchors**，**Density** 3–5，**Randomness** 100%，打开 **Keep sharp corners**。不断点 **Shuffle** 直到满意，然后点 **Copy** 记下种子。

**揉皱的纸**
Experimental 标签页 → 打开 **Use noise**，**Amount** 70–100%，**Facet size** 15–25%。想要粗犷、块状的折痕，可以搭配较大的 Curve flattening **Tolerance**（40 或以上）。不断点 **Next variant**，直到找到喜欢的折痕。

**多边形波纹**
Experimental 标签页 → 打开 **Use ripple**，**Amount** 50%，**Wavelength** 25–35%，**Sides** 6 或 8。想要硬朗的三角形冲击波，试试 **Sides** 3 并配合较大的 Curve flattening **Tolerance**；想让波纹从一角扫过来，把 **Center X** 和 **Center Y** 都设为 0%。

**被风吹走**
Experimental 标签页 → 打开 **Use wind**，**Strength** 30%，**Gust size** 10–15%，**Gustiness** 60–100%。如果字母挤在一起，可以在 Typography 标签页调大 **Tracking**；点 **Next variant** 换一组阵风。

**回到原样**
把 Curve flattening 设为 **Adaptive** 并用较小的 **Tolerance**，再关闭 Squaring、Anchors、Grid & angles、Distortion 和实验效果（每组都有复位按钮）。或者直接在画布工具栏选 **Original** 查看未经改动的字体。

## 10. 保存作品（导出）

点右上角的 **Export…**。只有点下载按钮时才会下载。

### 保存为图像（SVG 或 PNG）

两种格式都会保存画布：它的尺寸、和画布上一样排好的文字，以及你的配色。

1. 选择 **SVG — main view**（可以继续编辑的图形）或 **PNG — main view**（图片）。
2. 想要透明背景（只画字母），请先在 Color 标签页勾选 **Transparent background**。
3. 可选：勾选 **Export the preview look**，改为保存小预览里的样子——它的模糊，以及开启 **Invert** 时互换的颜色。请先在预览里调好 Blur 和 Invert。
4. SVG 选 **Coordinate precision**（坐标精度），即文件里的数字保留几位小数，默认 2 即可；PNG 的图片尺寸来自 **Canvas size**（宽 × 高 × 1×–4× 倍数）。
5. 点 **Download SVG** 或 **Download PNG**。

SVG 文件可以用 Illustrator、Figma、Inkscape 或浏览器打开，里面的形状全部由直线构成。带模糊的 SVG 使用模糊滤镜，浏览器和大多数设计软件都能显示；如果某个软件不支持，请改用 PNG。

### 保存为字体（OTF）

1. 选择 **Font file — OpenType (.otf)**。
2. **Glyphs to include**（包含哪些字形）：**Current glyph**（当前字形）、**Specimen characters**（只包含你输入文字里的字符）或 **All mapped characters**（字体里的所有字母）。
3. 填写 **Family name**（字体族名）和 **Style name**（样式名），请用英文字母。起一个新名字可以避免和原字体混淆。
4. 点 **Build & verify**（生成并校验）。应用会生成字体并做全面检查；大字体可能需要几秒钟，点 **Cancel** 可以中止。
5. 显示 “Verified” 后点 **Download .otf**，然后像安装普通字体一样安装它。

需要了解：

- 生成之后如果又改了设置，需要重新生成再下载。
- 新字体**不包含字偶距**、连字或原字体的其他高级排版功能，只有改造后的字母和它们的宽度。
- 字母会沿用原字体的字重、样式（例如斜体）、倾斜角、行距以及版权和授权信息，所以你做的 Regular 和 Bold 能像原字体一样同时安装。
- 极少数情况下，如果某个字母的细节小到字体文件无法保存，它会被略去，应用会列出它们。调小 **Distortion** 或 **Anchor spacing** 通常就能解决。
- 设置非常密时（Anchor spacing 接近 1），整套字体的点数可能超出一个文件能容纳的上限；应用会停止，并建议调大 Anchor spacing 或只导出文字中用到的字符。
- 可变字体会按屏幕上看到的版本保存。
- **版权提醒：**修改后的字体仍然基于别人的设计。分享前请查看原字体的授权——许多开源字体要求修改版使用新的名字。如果原字体保留了自己的名字，导出对话框会提醒你换一个字体族名。

## 11. 常见问题

**线段已经很少了，字母看起来还是很平滑。**
在 Fixed segments 模式下打开 **Merge joined curves**。不开启时，曲线的每一小段都会各自分到线段。

**调整 Corner angle 没有任何变化。**
打开 **Merge through straight lines**（在 Merge joined curves 下面）。不开启时，Corner angle 只影响两段曲线之间的连接点，而这些连接点几乎都已经是平滑的。

**我喜欢某个随机锚点的结果，怎么找回来？**
记下（或 **Copy**）它的种子。以后载入同一个字体，把 Random anchors 设成相同的设置，再把种子输入到 **Seed** 框里。同一次打开页面时，也可以直接在 **Previous** 里点它。

**为什么看不到骨架点或绿色顶点？**
字母足够大时才会显示。放大画布即可。

**有些控件是灰色的，拖不动。**
它们此刻不会产生任何效果，上方的说明会解释原因——例如随机锚点开启时曲线展平整组变灰；Randomness 为 0% 时随机种子变灰。

**在 Glyphs 里点的字符插错了位置。**
字符会插到文字输入框里光标最后所在的位置。先在输入框里点一下想插入的位置，再点字符。

**黄色提示说有些轮廓“kept their previous shape”（保持了之前的形状）。**
那个设置会让字母的一部分塌陷、自己交叉，或者碰到字母的另一部分（比如中间的空洞），所以应用为那一部分保留了上一个正常的结果。试试温和一点的数值。

**某个字母显示成红色虚线框。**
字体里没有这个字符，或者（Google Fonts 的情况下）它在另一个字符子集里。换一个子集或字体。

**刷新页面后结果会变吗？**
设置不会在两次访问之间保存。在同一次使用中，相同的设置和种子总会得到相同的结果。想保留的作品请导出。

**会上传什么东西吗？**
不会。本地字体始终留在你的电脑上；Google 字体从 Google 下载，不会发送到其他任何地方。

## 12. 术语表

| 术语 | 含义 |
|---|---|
| **Glyph 字形** | 字体中画出的一个图形——字母、数字或符号。 |
| **Contour 轮廓** | 一条闭合的外形线。“O” 有两条：外圈和中间的洞。 |
| **Counter 字腔** | 字母内部被包围的空白，如 “o”“a”“B” 中的洞。 |
| **Curve / segment 曲线 / 曲线段** | 两点之间的一段轮廓。字体用 Bézier 曲线来存储。 |
| **Anchor 锚点（曲线上的点）** | 位于轮廓线上的点。 |
| **Control point 控制点（曲线外的点）** | 牵引曲线、但本身不在曲线上的点。 |
| **Vertex 顶点** | 新的直线形状的拐角。 |
| **Polygon 多边形** | 只由直线组成的形状。 |
| **Crease 折痕** | 实验效果折叠轮廓时所沿的直线；只有在折痕上才会增加棱角。 |
| **Em / Units per em** | 字体看不见的设计方格，以及它的字体单位大小（常见 1000 或 2048）。 |
| **Font unit 字体单位（u）** | 字体内部的度量单位，控制项里的所有尺寸都用它。 |
| **Baseline 基线** | 字母坐落的那条线。 |
| **x-height / cap height** | 小写 “x” 的高度 / 大写字母的高度。 |
| **Ascender / descender 上伸 / 下伸** | 高出 x 高度的部分（h、d）/ 低于基线的部分（p、g）。 |
| **Advance width 字宽** | 排一个字母后文字向前推进的距离，包括它两侧的留白。 |
| **Kerning 字偶距** | 特定字母组合之间的细微间距调整，如 “AV”。 |
| **Variable font 可变字体** | 一个文件里包含一系列字重或宽度的字体。 |
| **SVG** | 矢量图像格式，任何尺寸下都保持清晰。 |
| **OTF（OpenType）** | 可以安装到电脑上的标准字体文件格式。 |
