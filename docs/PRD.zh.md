# None-Curve 产品需求文档（PRD）

[English](PRD.md) · **中文**

**状态：** 草案（实现状态见第 12 节）  
**产品形态：** 浏览器端字体轮廓编辑工具  
**目标用户：** 字体与平面设计师、创意技术人员、前端开发者

## 1. 产品概述

None-Curve 是一款网页工具，帮助用户把字体原有的曲线轮廓转换为可控制的直线多边形。用户载入字体后，可以查看曲线的锚点和控制点，调整每段曲线转换成的直线数量，预览几何变化，并导出 SVG 或字体文件。

产品强调直接、可视的造型探索：用户应能清楚看见原始字形是如何构成的，以及每个参数如何改变最终轮廓。

## 2. 用户与需求

### 主要用户

- **字体与平面设计师：** 想将现有字体转化为多边形、折面或实验性字形，并需要在轮廓和排版样张中检查效果。
- **创意技术人员：** 想通过可重复的参数和处理流程生成、比较字体变体。
- **开发者：** 负责实现字体解析、几何处理、预览和文件导出。

### 用户要完成的事情

1. 载入本地字体并选择要检查的字形。
2. 看见原始曲线、锚点、控制点，以及转换后的多边形顶点。
3. 决定每段曲线如何变成直线段，直观比较不同细节密度。
4. 调整几何效果，并在单字形和文本样张中预览。
5. 导出可供后续设计或使用的 SVG，或导出字体文件。

## 3. 产品目标与非目标

### 目标

- 让非开发者也能理解曲线轮廓和多边形结果之间的关系。
- 提供明确、即时的轮廓控制，尤其是每段曲线生成多少条直线。
- 支持原始曲线结构与处理后结果的对照检查。
- 输出由直线轮廓组成的 SVG；逐步支持有效字体文件生成。
- 在浏览器中完成字体载入、编辑和导出。

### 产品优先级与比重

- **字体解构与编辑是主工具，约占产品整体重点的 70%。** 首页和默认工作区优先呈现字体载入、骨架查看、曲线线性化、锚点与几何编辑、字形预览和导出。
- **声音是次要工具，约占产品整体重点的 30%。** 实时声音驱动 Geometry 和 Experimental 中已有的参数（第 11 节）；关闭 Sound 时，核心字体工具仍须完整可用。
- 70 / 30 是产品规划中的功能与设计投入比重，用于确定界面层级、开发顺序和功能范围，不是屏幕像素或单次会话时长的硬性比例。
- 字体功能先于声音功能交付。声音模块不得削弱字体工具的可发现性、基础编辑能力或 SVG / 字体导出路径。

### 首阶段非目标

- 成为完整的字体绘制或字体排版软件。
- 提供 Bézier 曲线控制柄编辑器或完整字形手工绘制工具。
- 重新设计字体的字符集、语言覆盖或高级排版特性。
- 保证所有字体格式、字体表和排版特性都能无损转换。
- 手机和平板布局：本产品只面向桌面浏览器，不提供窄屏布局。

## 4. 核心工作流程

```text
载入字体 → 选择字形 → 查看原始骨架 → 调整曲线转直线方式
          → 预览多边形与样张 → 导出 SVG 或字体
```

1. 用户拖入或选择 `.ttf` / `.otf` 文件。
2. 应用在本地读取文件，立即显示默认字形及可用字形选择。
3. 左侧控制面板提供字形选择与编辑控件；右侧主画布持续显示当前字形的实时渲染结果。
4. 用户在画布中检查原始曲线骨架和当前多边形，选择自适应展平或设置每段曲线的直线段数量。
5. 用户调整锚点密度、简化、网格吸附、角度约束或顶点扰动；画布中的轮廓随参数变化实时更新。
6. 用户切换填充预览或样张文本，实时检查形状、字腔和间距。
7. 用户明确点击导出后，才生成并下载当前字形 SVG 或支持范围内的字体文件。载入字体本身不触发导出。

## 5. 功能需求

### P0：字体载入与字形预览

- 支持从本地拖放或文件选择器载入 `.ttf` / `.otf`。
- 字体文件只在浏览器中处理，不上传到服务器。
- 显示文件名称、解析状态和可用字形选择入口。
- 对无法读取或不支持的文件显示可理解的错误信息。
- 支持单字形轮廓视图及基本缩放、平移。
- 字体载入后立即显示可视化字形预览；载入操作只建立可编辑工作区，不自动生成或下载结果文件。

### P0：原始曲线骨架

- 显示字形原始轮廓，并标出曲线上锚点、曲线外控制点和控制柄。
- 骨架叠加层可开关。
- 原始锚点 / 控制点与处理后多边形顶点使用不同标记或颜色。
- 支持同时检查原始结构和多边形结果。
- 骨架来自字体轮廓数据；此功能用于查看，不代表支持直接编辑原始 Bézier 控制点。

### P0：曲线线性化

提供两种清楚区分的处理模式：

- **自适应近似：** 通过曲线近似容差控制最大偏差。容差越低，通常线段和顶点越多。
- **每段曲线线段数：** 用户为每段原始曲线指定生成的直线段数量。数量越大，曲线近似越细致。

在参数变化时更新预览。控件应显示当前值和简短效果提示。固定线段数模式下，对误差明显的近似结果提供提示或可视化反馈。

用户拖动或调整控件时，主画布持续显示当前参数对应的渲染结果；不得要求用户先导出文件才能查看造型效果。

### P0：SVG 导出

- 导出当前选中字形的 SVG。
- 路径仅由 `M`（移动）与 `L`（直线）命令构成，并正确闭合轮廓。
- 保留必要的轮廓方向与填充行为，以正确显示字腔。
- 提供合理的 viewBox 和精度设置。
- 下载前提示导出字形和格式信息。

### P1：锚点与几何控制

- **锚点间距：** 沿现有多边形边增加点，使锚点间距不超过目标值。
- **锚点精简：** 使用简化阈值减少冗余顶点，同时尽量保留轮廓特征。
- **网格吸附：** 将坐标对齐到指定网格，可开关并设置网格大小。
- **角度锁定：** 将边方向约束到指定角度集合。
- **顶点扰动：** 设置噪声幅度、频率、法线偏向和种子；相同种子与参数应产生相同结果。
  - **少数锚点**（few anchors，Distortion 的一个隐藏模式，只有 Sound 标签页的 Flicker 预设会设置它）：每个字母只有少数几个锚点移动，其余锚点完全不动，所以字形得以保持。
    - 锁定、从不移动的：拐角（轮廓转向超过 30° 的地方）、x 和 y 方向的极值点（整段笔直的顶边、底边或侧边都算），以及顶点少于 8 个的轮廓上的所有顶点。
    - 候选：其余顶点，以及任何有 3 个或更多顶点的轮廓上、长度至少为 em 的 10% 的每条直边的中点。被选中的中点成为一个新锚点，这条边的两端保持不动，所以只由拐角和极值点组成的字母（例如 I、l、H、T 或连字符）也会动。
    - 每个字母 1–5 个移动点（它的顶点数的 6%，四舍五入），一个轮廓上最多 2 个，沿轮廓相隔超过 4 个顶点，由种子和位置的哈希从候选中挑出。换一个种子就换一组。
    - 每个移动点都被明显地推开：至少移动幅度的 60%，只有在边保护或修复降低幅度的地方才会更少。
    - 打开时，Distortion 面板显示一条只读说明（“Only a few anchors move (set by the Flicker preset in the Sound tab). Reset distortion moves every anchor again.”）和 **Anchors moved**（移动的锚点数）统计。**Reset distortion** 会关闭它，载入另一个预设也会。
    - 它不是控件，也不是 Sound 的目标。
- 几何处理的顺序应固定并在界面或说明中公开。

### P1：填充与样张

- 在轮廓模式与实心填充模式之间切换。
- 支持编辑预览文本，检查重复字形、节奏、字腔与字距。
- 字体解析支持时保留字宽和字偶距；无法保留时清楚标示。
- 提供基线、大写字高等可用度量参考线的显示开关。

### P2：字体文件导出

- 支持选择要包含的字形范围，并填写基础字体命名信息。
- 输出字形使用多边形直线轮廓。
- 尽可能保留字宽、左右边距和字符映射。
- 导出前校验缺失字形、无效轮廓和不支持的字体特性。
- 将支持范围和无法保留的特性告知用户。

### P2：实验效果（可叠加）

创意效果统一放在 Geometry 旁边的 **Experimental** 标签页：**Crumple**（揉皱的纸）、**Ripple**（从一点扩散的波纹）、**Slipstream**（沿某个方向被拉扯），按这个顺序开发，之后是 **Whorl**（绕每个字母中心的漩涡）和 **Thorn**（几个锚点跳进画布）。详细计划见 [EXPERIMENTAL_PLAN.zh.md](EXPERIMENTAL_PLAN.zh.md)。

- **没有曲线，眼睛看也没有：** 每个效果都是对平面的分段线性变形。边在每个网格三角形内部保持笔直，只在折痕处转折，新顶点也只加在折痕上。任何效果都不沿轮廓采样平滑函数；网格有最小单元尺寸，保证刻面看得见。Thorn 是唯一不是变形的效果：它让几个锚点沿直线移动，所以它的边同样是直的。
- **可叠加：** 任意组合可以同时打开。它们在 Geometry 流程之后按固定顺序 Crumple → Ripple → Whorl → Slipstream → Thorn 运行，每个效果接收上一个的结果。
- **始终有效：** 在 100% 以内，每种变形都是一一映射（网格三角形不会翻转），所以任意组合都不会让轮廓交叉，字腔始终留在字形内。每个效果之后仍会检查轮廓，并报告减弱情况。
- **翻折，用于无法阅读的极端效果：** 超过 100%（Crumple 最高 500%，Ripple 最高 400%，Whorl 最高 ±400%，Slipstream 的 Gustiness 最高 200% 并出现反向阵风，Strength 最高 800%）时，字母可以折到自己身上。重叠部分会合并成非零规则所填充区域的干净、不交叉的轮廓，仍然只有直边，所以每个字形都还能导出。Thorn 在任何设置下都可能穿过字母，所以只要它打开，轮廓都会这样合并。
- **花瓣：** Ripple 可以把各圈弯成一朵花，每条边一片直边花瓣（0–300%）。任何深度下 Petals 都是一一映射，自己永远不会翻折；翻折仍然只来自超过 100% 的 Ripple Amount。
- **Whorl（漩涡）：** 一圈圈直边多边形各自整体绕字母中心旋转，可以固定上下（中间被拧转），也可以整体旋转（顶和底也被甩过去）。正反方向在 100% 以内都是一一映射；超过之后和其他效果一样翻折。
- **Thorn（刺）：** 每个字母外侧的几个锚点（字腔永远不会长刺）笔直跳进画布，它们的边变成又长又直的刺。Anchors 决定每个字母跳出几个（1–12），Reach 决定跳多远（最多 em 的 200%），Spread 决定向旁边偏多少（两侧各最多 90°），Width 决定每根刺离开字母处有多宽（从一根细针到一个宽楔形）。共用的种子决定哪些锚点跳出、跳向哪里，所以 Next variant 或由 Sound 驱动的种子会让它们换地方。
- **可重复：** 整个标签页共用一个种子；效果在字形自身坐标里计算，所以同一个字母的每次出现形状相同，也能导出字体。
- Random anchors 不再标为实验功能，仍留在 Geometry 标签页。

## 6. 信息架构与界面要求

```text
┌──────────────────────────────────────────────────────────────┐
│ 字体 / 文件状态                                  导入  导出  │
├──────────────────────┬───────────────────────────────────────┤
│ 左侧控制面板         │ 实时字形画布                          │
│ 字形选择             │ 原始骨架 / 当前多边形 / 填充预览      │
│ 解构                 │                                       │
│ 几何与网格           │ 参数变化后立即更新                   │
│ 扰动 / 声音          │                                       │
│ 导出选项             │                                       │
├──────────────────────┴───────────────────────────────────────┤
│ 样张 / 预览模式 / 缩放 / 处理状态                             │
└──────────────────────────────────────────────────────────────┘
```

画布是主要反馈区域，应在工作区中持续可见。载入字体与导出是两个独立动作：导入后进入实时编辑预览，只有用户主动执行导出时才生成文件。

### 控件分组

1. **解构：** 展平模式、曲线近似容差、每段曲线线段数、锚点间距、锚点精简。
2. **几何与网格：** 网格吸附、网格大小、角度锁定、固定锚点行为。
3. **扰动：** 噪声幅度、频率、法线偏向、随机种子（以及少数锚点模式，它没有控件：只有 Flicker 预设会设置它）。
4. **导出：** SVG 设置、字体覆盖范围和字体元数据。
5. **Experimental**（Geometry 旁边的独立标签页）：Crumple、Ripple、Whorl、Slipstream、Thorn，可叠加，共用一个种子。

### 工具层级

- 默认进入字体解构工作区；字体处理、骨架查看、轮廓编辑和导出构成主导航与主要画布。
- 控制面板固定在工作区左侧，实时字形画布位于右侧主区域。不能用导出结果替代实时预览。
- Sound 作为第三个标签页，位于 Geometry 和 Experimental 旁边；它不应替代基础字体编辑器，也不要求用户先载入音频才能编辑字体。
- Sound 实时运行时，滑块保留自己的值（用标记显示实时值）；关闭 Sound 后完全恢复原值，导出使用滑块值。

### 视觉与交互原则

- 使用深色、高对比度、简洁的视觉语言，服务于轮廓检查与造型操作。
- 优先使用设计师能理解的名称，例如“曲线近似度”“每段曲线线段数”“锚点间距”。
- 关键参数同时显示滑块和数值输入，便于探索和精确设置。
- 用图形或清楚的图例区分曲线骨架点与多边形顶点。
- 每个核心控件提供简短说明；复杂术语可通过提示解释。
- 覆盖未载入字体、处理等待、解析错误和导出完成等状态。
- 界面可通过键盘操作，焦点状态清晰可见。

### 形态变化视觉参考

`resources/reference/font_change_sample.png` 是字体形态变化的设计参考，展示平滑曲线字形逐步转为不同细节密度的多边形字形。用它指导实时预览中从原始轮廓到多边形结果的视觉表达，以及“每段曲线线段数 / 锚点密度”控制的效果梯度；不要求逐像素复刻，也不限定所有字体必须采用图中的字形或黑白配色。

## 7. 数据与处理规则

- 原始字体轮廓和字体度量作为只读输入保留。
- 原始曲线骨架与处理后的多边形数据分别存储。
- 派生几何由原始曲线和当前参数生成；参数改变不应累积修改原始数据。
- 随机扰动使用显式种子，保证预览结果可重复。
- SVG 输出必须通过检查，确保路径数据不含 `C` 或 `Q` 等曲线命令。
- 实验效果是分段线性变形，只在折痕处加顶点（Thorn 让几个锚点沿直线移动）；不得增加连续朝同一方向小幅转折、看起来像曲线的段落。
- 处理较大字体时避免阻塞界面；必要时在后台线程计算，并在计算期间维持控件响应。

## 8. 验收标准

- 用户可以载入有效 `.ttf` / `.otf` 文件并选择字形；无效文件会得到明确提示。
- 载入字体后，用户无需执行导出即可看见所选字形的实时画布预览。
- 编辑控件位于视口左侧；调整曲线线段数或其他几何参数后，画布显示对应的当前结果。
- 用户可以打开骨架视图并辨认原始锚点、控制点和控制柄。
- 用户可以调整每段曲线生成的直线段数量，并立即看到多边形变化。
- 用户可以切换自适应近似模式，理解其与固定线段数模式的区别。
- 原始曲线骨架和生成的多边形顶点在视觉上可区分。
- 导出的 SVG 只含直线轮廓命令，轮廓闭合且字腔显示正确。
- 同一组参数与随机种子可重复生成相同几何结果。
- 文件载入、预览和导出均在客户端完成。
- 载入文件不会自动创建下载文件；导出只在用户明确触发后发生。
- 若字体导出未覆盖某些字体特性，应用会在导出前明确说明。
- 实验效果可以同时打开；100% 以内的任意组合都得到有效轮廓（不交叉，字腔在字形内），也不增加像曲线的段落。超过 100% 或打开 Thorn 时，翻折或长出刺的字母会合并成不交叉、可以导出的轮廓。

## 9. 里程碑建议

| 里程碑 | 交付范围 |
|---|---|
| 1. 可视化原型 | 字体载入、字形选择、原始曲线骨架、曲线展平、填充 / 轮廓预览、SVG 导出 |
| 2. 锚点控制 | 固定每段曲线线段数、自适应容差、重采样、简化、参数实时预览 |
| 3. 造型工具 | 网格吸附、角度锁定、确定性扰动、文本样张 |
| 4. 字体生成 | 字体元数据、字形范围选择、OTF 生成与校验 |
| 5. 发布完善 | 交互细节、可访问性、错误状态、GitHub Pages 部署 |

## 11. 声音驱动几何（新增产品方向）

详细计划见 [SOUND_PLAN.zh.md](SOUND_PLAN.zh.md)。本节取代之前的“声音驱动石刻字形”方向（新的石刻操作、时间轴、把音频分布到一段文字的各个字母上，以及配方导出），那个方向不再做。

- **概念：** 在 Geometry 和 Experimental 旁边新增 **Sound** 标签页。实时声音（本地音频文件，或用户明确开始后的麦克风）驱动两个标签页里已有的参数，让字母随音乐而动：锚点踩着节拍跳动，声音变响时轮廓被揉皱，低音响起时花瓣张开。
- **不新增几何：** 声音只改变参数值，而且只在每个滑块自己的范围内改变（种子：在其输入框范围内的整数）。每一帧都是手动拖滑块、填种子输入框也能得到的结果，所以只有直边，像其他结果一样经过检查，并且可以导出。帧与帧之间不做补间。
- **特征：** 共 20 个，分六组；电平表和映射的 Feature 列表按同样方式排列：
  - **Loudness（响度）：** Level（短时 RMS）和 Swell（缓慢跟随的 Level：约 300 ms 升起，约 2 s 回落）。
  - **Bands（频带）：** Low / Mid / High 频带能量（20–250 Hz、250–2000 Hz、2000 Hz 到奈奎斯特频率）。
  - **Narrow bands（窄频带）：** Sub（20–60 Hz）、Bass（60–250 Hz）、Low mid（250–500 Hz）、High mid（2–4 kHz）、Presence（4–6 kHz）和 Air（6–20 kHz）。和 Low / Mid / High 一样，每个频带都与自己最近最响的时刻相比。
  - **Tone（音色）：** Brightness（频谱质心）；Noisiness（频谱平坦度，只量到声音实际的带宽，所以有损压缩的文件也读得准：乐音接近 0，嘶声和鼓声高）；Pitch（正在演奏或演唱的音高，55 Hz 到 1760 Hz，对数刻度；两个音之间保持上一个音，静音时为 0）。
  - **Rhythm（节奏）：** Beat 和 Kick（起音），作为脉冲：每次起音跳到 1，再按 Smoothing 的时间回落；Change（频谱变化的多少：持续的声音接近 0，噪声也一样，起音时高）；Pace（最近 2 s 内每秒的 Beat 起音数；每秒 8 次读作 1）。
  - **Stereo（立体声）：** Balance（左 −1 到右 +1，唯一的双向特征）和 Width（单声道为 0，很宽的立体声约为 1）。实际上只对文件有效：单声道麦克风读作居中、没有宽度。
  - 大多数特征以快速的起音和可调的释放（Smoothing）跟随声音，并经过静音门限；Swell 和 Pitch 有自己固定的时间。
- **映射：** 最多 8 行，每行把一个特征连接到一个目标。
  - **连续：** 滑块位置（沿滑块的绘制方向，0–1）+ Depth × 特征，截断到滑块两端，再取整到滑块的档位；同一目标上的多个作用先相加再截断。普通滑块相当于 滑块值 + Depth × 特征 × 滑块的范围，而对数刻度的滑块（如 Tolerance）沿滑道均匀移动。
  - **事件**（Beat、Kick），分三种：
    - **Jump：** 种子前进一个，让锚点、翻折、阵风或刺跳到新位置。三个种子都是目标，新的种子让每个锚点落到新的地方。在种子上，这一行的滑块显示为 **Rate**（0–100%）：配 Beat 或 Kick 时，每次起音种子前进一个（Rate 50% 是每隔一次起音，25% 是每四次）；配其他特征时，每秒最多跳 4.8 次 × Rate × 特征值。种子始终是字段范围内（0–999 999）的整数，超过最大值后回到 0。
    - **Step：** 换到几个可选值中的下一个，例如 Allowed directions（角度步长）。
    - **Kick：** 跃起后再回落。Beat 或 Kick 用在任意滑块上就是这样，靠的是它们的脉冲。
  - **Geometry 标签页中的目标：** Distortion 的 Seed、Noise amplitude、Noise frequency 和 Normal bias；Random anchors 的 Seed、Randomness 和 Density；Curve flattening 的 Tolerance、Segments per curve 和 Corner angle；Squaring 的 Amount；Anchor spacing 和 Anchor reduction；Grid size；Allowed directions（角度步长）。Allowed directions 随 Step 映射一起加入。
  - **Experimental 标签页中的目标：** 其中的滑块和共用的种子。
  - 开关从不作为目标，Distortion 的少数锚点模式也不是。
  - **目标会自己打开所需的设置：** 选中一个设置处于关闭状态的目标时，会打开该设置，并在这一行下面说明（例如 "Turned on Ripple."、"Set Noise amplitude to 40." 或 "Turned off Random anchors. Set Mode to Adaptive."）。把这一行换到别的目标，或删除这一行，都不会关闭任何东西。如果用户之后又把设置关掉，这一行会说明原因并提供 **Enable**。用键盘在 Target 列表中浏览时，只有按 Enter 或焦点离开列表时才应用目标；用鼠标选择则立即应用。**Add mapping** 优先选已经起作用的目标。
    - Curve flattening 的目标会关闭 Random anchors，并设置各自需要的：Tolerance 需要 Adaptive 模式，Segments per curve 需要 Fixed segments 模式，Corner angle 需要 Merge joined curves（两种模式下都可以）。
    - Grid size 打开 Snap to grid。
    - Distortion 的 Noise frequency、Normal bias 和 Seed 在 Noise amplitude 为 0 时把它设为 40。
    - Random anchors 的目标打开 Random anchors；Seed 还会在 Randomness 为 0% 时把它设为 100%。
    - Experimental 的效果滑块打开各自的效果。Crumple、Slipstream 和 Thorn 都没打开时，Experimental 的 Seed 会打开 Crumple（Ripple 和 Whorl 没有随机性）。
  - **预设：** Flicker、Scatter、Pixel、Low poly、Block、Jitter、Facet、Bloom、Flare、Gale。每个预设除了映射，还会设好几个起始值。大多数只用 Geometry 标签页，所以安静时字母仍然清楚可读；每个最多一个 Experimental 效果（Bloom 用 Ripple，Flare 用 Thorn，Gale 用 Slipstream）。Flicker 会打开 Distortion 的少数锚点模式（P1）。一个 ⓘ 列出每个预设，各一行说明。
    - 在 **Preset** 列表中选择只是选中。
    - **Load** 把 Geometry 和 Experimental 的每个设置恢复为默认值，保留三个种子；设好预设的起始值；用预设的映射替换当前映射；并在 Preset 一行下方显示提示，例如 “Loaded Bloom. Turned off Crumple. Other Geometry and Experimental settings back to defaults (seeds kept).”。所以无论之前设了什么，每个预设都从同样的字母开始。
    - 手动选择目标仍然只会打开它所需的设置，不会恢复任何默认值。
- **保留滑块值和种子：**
  - 滑块保留自己的值，并用标记显示实时值。种子字段保留自己的种子，被驱动的种子旁边用一个小数字显示实时种子；Distortion 和 Random anchors 的统计信息也显示实时种子。
  - 关闭 Sound、关闭映射或 Depth 为 0 时，完全恢复滑块值。暂停、停止或关闭 Drive letters 时，种子完全回到字段中的值，再次播放时从这些值开始。
  - **Freeze** 把实时值写入滑块、把实时种子写入种子字段，并让声音暂停。
  - 导出始终使用滑块值，从不使用实时音频。
- **性能：**
  - 流程不变，同一时间最多只有一个请求在处理；实时请求带有标记，结果会分开保存。帧率随计算量自动调整，上限 30 fps，并显示在标签页中。
  - 实时值取整到滑块档位，以复用缓存结果；实时帧使用单独的缓存。
  - 在 48 kHz 下，测量 20 个特征每帧约需 90 µs。种子跳一次会重新计算每个字形，约 2–3.5 ms（Arial，24 个不同字形）。
- **安全：**
  - 为防闪烁，被驱动的滑块每秒最多来回摆动 3 次（每次摆动至少是滑道的 10%）；再多的摆动会让滑块停在上一个值，直到 1.25 s 的窗口过去。种子跳变也受同样的限制，计数方式相同：任意 1.25 s 内最多 6 个跳变帧，即每秒 3 次闪烁（同一帧中一起跳的种子只算一次）；超出的跳变直接跳过。暂停后再播放不会重置这个计数。
  - 开启减少动态效果时，Drive letters（驱动字母）默认关闭（访问期间才开启减少动态效果时也会自动关闭），Sound 标签页会说明原因。
  - 麦克风只在用户明确点击后启用，并显示指示标记。
  - 音频不会离开浏览器。
- **交付顺序：**
  1. 音频引擎、特征和电平表。
  2. 连续映射、实时调度和 Freeze。
  3. 事件映射、频率限制和预设。
  4. Pitch 和 Balance。

  视频录制以后再做。
