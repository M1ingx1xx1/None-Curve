# None-Curve 产品需求文档（PRD）

[English](PRD.md) · **中文**

**状态：** 草案（实现状态见第 12 节）  
**产品形态：** 浏览器端字体轮廓编辑工具  
**目标用户：** 字体与平面设计师、创意技术人员、前端开发者

## 1. 产品概述

None-Curve 是一款网页工具，帮助用户把字体原有的曲线轮廓转换为可控制的直线多边形。用户载入字体后，可以查看曲线的锚点和控制点，调整每段曲线转换成的直线数量，预览几何变化，并导出 SVG 或字体文件。

产品强调直接、可视的造型探索：用户应能清楚看见原始字形是如何构成的，以及每个参数如何改变最终轮廓。

## 2. 用户与需求

### 主要用户

- **字体与平面设计师：** 想将现有字体转化为多边形、折面或实验性字形，并需要在轮廓和排版样张中检查效果。
- **创意技术人员：** 想通过可重复的参数和处理流程生成、比较字体变体。
- **开发者：** 负责实现字体解析、几何处理、预览和文件导出。

### 用户要完成的事情

1. 载入本地字体并选择要检查的字形。
2. 看见原始曲线、锚点、控制点，以及转换后的多边形顶点。
3. 决定每段曲线如何变成直线段，直观比较不同细节密度。
4. 调整几何效果，并在单字形和文本样张中预览。
5. 导出可供后续设计或使用的 SVG，或导出字体文件。

## 3. 产品目标与非目标

### 目标

- 让非开发者也能理解曲线轮廓和多边形结果之间的关系。
- 提供明确、即时的轮廓控制，尤其是每段曲线生成多少条直线。
- 支持原始曲线结构与处理后结果的对照检查。
- 输出由直线轮廓组成的 SVG；逐步支持有效字体文件生成。
- 在浏览器中完成字体载入、编辑和导出。

### 产品优先级与比重

- **字体解构与编辑是主工具，约占产品整体重点的 70%。** 首页和默认工作区优先呈现字体载入、骨架查看、曲线线性化、锚点与几何编辑、字形预览和导出。
- **声音驱动石刻是次要工具，约占产品整体重点的 30%。** 它扩展字体多边形编辑流程，为字形提供声音分析、参数映射和石刻效果；关闭声音模块时，核心字体工具仍须完整可用。
- 70 / 30 是产品规划中的功能与设计投入比重，用于确定界面层级、开发顺序和功能范围，不是屏幕像素或单次会话时长的硬性比例。
- 字体功能先于声音功能交付。声音模块不得削弱字体工具的可发现性、基础编辑能力或 SVG / 字体导出路径。

### 首阶段非目标

- 成为完整的字体绘制或字体排版软件。
- 提供 Bézier 曲线控制柄编辑器或完整字形手工绘制工具。
- 重新设计字体的字符集、语言覆盖或高级排版特性。
- 保证所有字体格式、字体表和排版特性都能无损转换。

## 4. 核心工作流程

```text
载入字体 → 选择字形 → 查看原始骨架 → 调整曲线转直线方式
          → 预览多边形与样张 → 导出 SVG 或字体
```

1. 用户拖入或选择 `.ttf` / `.otf` 文件。
2. 应用在本地读取文件，立即显示默认字形及可用字形选择。
3. 左侧控制面板提供字形选择与编辑控件；右侧主画布持续显示当前字形的实时渲染结果。
4. 用户在画布中检查原始曲线骨架和当前多边形，选择自适应展平或设置每段曲线的直线段数量。
5. 用户调整锚点密度、简化、网格吸附、角度约束或顶点扰动；画布中的轮廓随参数变化实时更新。
6. 用户切换填充预览或样张文本，实时检查形状、字腔和间距。
7. 用户明确点击导出后，才生成并下载当前字形 SVG 或支持范围内的字体文件。载入字体本身不触发导出。

## 5. 功能需求

### P0：字体载入与字形预览

- 支持从本地拖放或文件选择器载入 `.ttf` / `.otf`。
- 字体文件只在浏览器中处理，不上传到服务器。
- 显示文件名称、解析状态和可用字形选择入口。
- 对无法读取或不支持的文件显示可理解的错误信息。
- 支持单字形轮廓视图及基本缩放、平移。
- 字体载入后立即显示可视化字形预览；载入操作只建立可编辑工作区，不自动生成或下载结果文件。

### P0：原始曲线骨架

- 显示字形原始轮廓，并标出曲线上锚点、曲线外控制点和控制柄。
- 骨架叠加层可开关。
- 原始锚点 / 控制点与处理后多边形顶点使用不同标记或颜色。
- 支持同时检查原始结构和多边形结果。
- 骨架来自字体轮廓数据；此功能用于查看，不代表支持直接编辑原始 Bézier 控制点。

### P0：曲线线性化

提供两种清楚区分的处理模式：

- **自适应近似：** 通过曲线近似容差控制最大偏差。容差越低，通常线段和顶点越多。
- **每段曲线线段数：** 用户为每段原始曲线指定生成的直线段数量。数量越大，曲线近似越细致。

在参数变化时更新预览。控件应显示当前值和简短效果提示。固定线段数模式下，对误差明显的近似结果提供提示或可视化反馈。

用户拖动或调整控件时，主画布持续显示当前参数对应的渲染结果；不得要求用户先导出文件才能查看造型效果。

### P0：SVG 导出

- 导出当前选中字形的 SVG。
- 路径仅由 `M`（移动）与 `L`（直线）命令构成，并正确闭合轮廓。
- 保留必要的轮廓方向与填充行为，以正确显示字腔。
- 提供合理的 viewBox 和精度设置。
- 下载前提示导出字形和格式信息。

### P1：锚点与几何控制

- **锚点间距：** 沿现有多边形边增加点，使锚点间距不超过目标值。
- **锚点精简：** 使用简化阈值减少冗余顶点，同时尽量保留轮廓特征。
- **网格吸附：** 将坐标对齐到指定网格，可开关并设置网格大小。
- **角度锁定：** 将边方向约束到指定角度集合。
- **顶点扰动：** 设置噪声幅度、频率、法线偏向和种子；相同种子与参数应产生相同结果。
- 几何处理的顺序应固定并在界面或说明中公开。

### P1：填充与样张

- 在轮廓模式与实心填充模式之间切换。
- 支持编辑预览文本，检查重复字形、节奏、字腔与字距。
- 字体解析支持时保留字宽和字偶距；无法保留时清楚标示。
- 提供基线、大写字高等可用度量参考线的显示开关。

### P2：字体文件导出

- 支持选择要包含的字形范围，并填写基础字体命名信息。
- 输出字形使用多边形直线轮廓。
- 尽可能保留字宽、左右边距和字符映射。
- 导出前校验缺失字形、无效轮廓和不支持的字体特性。
- 将支持范围和无法保留的特性告知用户。

### P2：实验效果（可叠加）

创意效果统一放在 Geometry 旁边的 **Experimental** 标签页：**Noise**（揉皱的纸）、**Ripple**（从一点扩散的波纹）、**Wind**（沿某个方向被拉扯），按这个顺序开发。详细计划见 [EXPERIMENTAL_PLAN.zh.md](EXPERIMENTAL_PLAN.zh.md)。

- **没有曲线，眼睛看也没有：** 每个效果都是对平面的分段线性变形。边在每个网格三角形内部保持笔直，只在折痕处转折，新顶点也只加在折痕上。任何效果都不沿轮廓采样平滑函数；网格有最小单元尺寸，保证刻面看得见。
- **可叠加：** 任意组合可以同时打开。它们在 Geometry 流程之后按固定顺序 Noise → Ripple → Wind 运行，每个效果接收上一个的结果。
- **始终有效：** 每种变形都是一一映射（网格三角形不会翻转），所以任意组合都不会让轮廓交叉，字腔始终留在字形内。每个效果之后仍会检查轮廓，并报告减弱情况。
- **可重复：** 整个标签页共用一个种子；效果在字形自身坐标里计算，所以同一个字母的每次出现形状相同，也能导出字体。
- Random anchors 不再标为实验功能，仍留在 Geometry 标签页。

## 6. 信息架构与界面要求

```text
┌──────────────────────────────────────────────────────────────┐
│ 字体 / 文件状态                                  导入  导出  │
├──────────────────────┬───────────────────────────────────────┤
│ 左侧控制面板         │ 实时字形画布                          │
│ 字形选择             │ 原始骨架 / 当前多边形 / 填充预览      │
│ 解构                 │                                       │
│ 几何与网格           │ 参数变化后立即更新                   │
│ 扰动 / 声音石刻      │                                       │
│ 导出选项             │                                       │
├──────────────────────┴───────────────────────────────────────┤
│ 样张 / 预览模式 / 缩放 / 处理状态                             │
└──────────────────────────────────────────────────────────────┘
```

画布是主要反馈区域，应在工作区中持续可见。载入字体与导出是两个独立动作：导入后进入实时编辑预览，只有用户主动执行导出时才生成文件。

### 控件分组

1. **解构：** 展平模式、曲线近似容差、每段曲线线段数、锚点间距、锚点精简。
2. **几何与网格：** 网格吸附、网格大小、角度锁定、固定锚点行为。
3. **扰动：** 噪声幅度、频率、法线偏向、随机种子。
4. **导出：** SVG 设置、字体覆盖范围和字体元数据。
5. **Experimental**（Geometry 旁边的独立标签页）：Noise、Ripple、Wind，可叠加，共用一个种子。

### 工具层级

- 默认进入字体解构工作区；字体处理、骨架查看、轮廓编辑和导出构成主导航与主要画布。
- 控制面板固定在工作区左侧，实时字形画布位于右侧主区域；窄屏时可折叠左侧面板，但不能用导出结果替代实时预览。
- 声音石刻作为可选工具或工作区模式接入当前字形，不应替代基础字体编辑器，也不要求用户先载入音频才能编辑字体。
- 使用声音时，界面仍提供原始字形、基础多边形和声音驱动结果的对照入口。

### 视觉与交互原则

- 使用深色、高对比度、简洁的视觉语言，服务于轮廓检查与造型操作。
- 优先使用设计师能理解的名称，例如“曲线近似度”“每段曲线线段数”“锚点间距”。
- 关键参数同时显示滑块和数值输入，便于探索和精确设置。
- 用图形或清楚的图例区分曲线骨架点与多边形顶点。
- 每个核心控件提供简短说明；复杂术语可通过提示解释。
- 覆盖未载入字体、处理等待、解析错误和导出完成等状态。
- 界面可通过键盘操作，焦点状态清晰可见。

### 形态变化视觉参考

`resources/reference/font_change_sample.png` 是字体形态变化的设计参考，展示平滑曲线字形逐步转为不同细节密度的多边形字形。用它指导实时预览中从原始轮廓到多边形结果的视觉表达，以及“每段曲线线段数 / 锚点密度”控制的效果梯度；不要求逐像素复刻，也不限定所有字体必须采用图中的字形或黑白配色。

## 7. 数据与处理规则

- 原始字体轮廓和字体度量作为只读输入保留。
- 原始曲线骨架与处理后的多边形数据分别存储。
- 派生几何由原始曲线和当前参数生成；参数改变不应累积修改原始数据。
- 随机扰动使用显式种子，保证预览结果可重复。
- SVG 输出必须通过检查，确保路径数据不含 `C` 或 `Q` 等曲线命令。
- 实验效果是分段线性变形，只在折痕处加顶点；不得增加连续朝同一方向小幅转折、看起来像曲线的段落。
- 处理较大字体时避免阻塞界面；必要时在后台线程计算，并在计算期间维持控件响应。

## 8. 验收标准

- 用户可以载入有效 `.ttf` / `.otf` 文件并选择字形；无效文件会得到明确提示。
- 载入字体后，用户无需执行导出即可看见所选字形的实时画布预览。
- 编辑控件位于视口左侧；调整曲线线段数或其他几何参数后，画布显示对应的当前结果。
- 用户可以打开骨架视图并辨认原始锚点、控制点和控制柄。
- 用户可以调整每段曲线生成的直线段数量，并立即看到多边形变化。
- 用户可以切换自适应近似模式，理解其与固定线段数模式的区别。
- 原始曲线骨架和生成的多边形顶点在视觉上可区分。
- 导出的 SVG 只含直线轮廓命令，轮廓闭合且字腔显示正确。
- 同一组参数与随机种子可重复生成相同几何结果。
- 文件载入、预览和导出均在客户端完成。
- 载入文件不会自动创建下载文件；导出只在用户明确触发后发生。
- 若字体导出未覆盖某些字体特性，应用会在导出前明确说明。
- 实验效果可以同时打开；任意组合、任意强度都得到有效轮廓（不交叉，字腔在字形内），也不增加像曲线的段落。

## 11. 声音驱动石刻字形（新增产品方向）

### 11.1 概念与范围

核心链路为 **Sound → Carving Logic → Letterform（声音 → 石刻逻辑 → 字形）**。声音先转成可解释的特征，再转成刻痕参数，最后作用到字形的多边形轮廓。不能仅以波形替代字形或叠加一张纹理图片；用户应能追溯每个形变的声音来源。此模块作为基础多边形编辑流程的扩展，关闭时仍可使用原有功能。

“石刻”是造型模型，不是物理雕刻仿真。Depth 是归一化的刻痕深度，用于控制轮廓扩张和刻口幅度；二维 SVG / 字体不携带真实三维深度。光照、阴影和材质预览必须与可导出的轮廓变化区分。

### 11.2 声音输入与特征定义

- 首版支持本地音频文件、播放、暂停、时间轴和区间选择；至少支持 WAV，以及浏览器可解码的 MP3。麦克风输入为后续扩展，必须由用户主动开启。
- 音频在浏览器内解码和分析，不上传；解码失败、空文件、静音和未检测到稳定音高均须有明确状态。
- **Volume / 音量：** 短时 RMS 能量，表示相对强弱，不宣称测量真实声压或录音设备的物理音量。
- **Pitch / 音高：** 有声片段的基频估计，以 Hz 显示，并保存置信度。静音或低置信度片段不作为高音处理。
- **Rhythm / 节奏：** 起音事件、事件间隔与每秒事件数；有足够稳定节拍时才显示估计 BPM。
- **Duration / 时长：** 选区长度及连续声音事件的持续时间，以秒表示；须与音量积分区分。
- **Frequency / 频率分布：** 低、中、高频频带的相对能量，而非与 Pitch 重复的单一频率值。默认分带边界先采用 20–250 Hz、250–2000 Hz、2000 Hz–Nyquist，并在低采样率时裁剪到有效范围。
- **Texture / 质感：** 以频谱平坦度、噪声比例代理值及瞬态变化描述粗糙程度；界面应说明这是声学估计，不是对音源材质的识别。
- 分析结果同时保留原始值、单位、归一化值、时间戳和有效性标记。归一化范围、静音阈值、分析窗口和步长须可追溯；避免除零，并对异常峰值限幅。

### 11.3 默认映射要求

| 声音输入 | 石刻参数 | 字形作用与方向 |
|---|---|---|
| Volume 增大 | Depth、Pressure 增大 | 刻口更深、轮廓扩张更强、字重更粗 |
| Pitch 升高且可信 | Chisel Angle 更尖、Stroke Width 减小 | 端部更尖锐、局部笔画更窄 |
| 低频相对能量增大 | Pressure、Stroke Width 增大 | 字形更厚重、横向更宽 |
| 起音更密集 / Rhythm 更快 | 刻口密度增大 | 切口更密集、局部笔画更碎，但不默认断开整个笔画 |
| 声音事件 Duration 更长 | 刻划延伸长度增大 | 指定端部或局部方向上的笔画延长 |
| Texture 噪声估计增大 | Edge Roughness、Erosion 增大 | 边缘更粗糙、局部缺损更明显 |
| 高频相对能量增大 | 细小刻口密度与锐度增大 | 更细密的边缘细节；独立于基频音高映射 |
| 瞬态冲击更强 | 局部 Pressure 峰值增大 | 在事件对应位置生成较明显的凿痕 |

六个主要石刻参数须独立定义：Depth 控制刻口幅度；Pressure 控制局部扩张与受力范围；Stroke Width 控制笔画厚度；Edge Roughness 控制边缘扰动；Erosion 控制减去的缺损区域；Chisel Angle 控制凿口夹角与方向。避免六个滑块最终都只是同一种随机顶点位移。

这些对应关系是可编辑的设计默认值，不是声学定律。用户可以开关、反向、调整强度并重置每条映射；允许多个特征共同作用，但需要显示每项贡献。

### 11.4 映射与时间分配控制

- 每条映射提供输入特征、目标参数、输入范围、输出上下限、强度、正向 / 反向、响应曲线和启用开关；提供线性、缓入和缓出曲线。
- 合成规则固定为“基础值 + 各映射贡献 → 输出范围限幅 → 几何约束”。零强度应恢复基础参数，关闭模块应恢复原有几何流程。
- 默认使用选区聚合特征生成静态字形。扩展模式支持将选区按时间顺序分配到文本中的字符，或按轮廓弧长分配到局部刻口；界面必须明确当前模式。
- 轮廓局部模式按稳定的轮廓顺序、起点和弧长映射，不依赖随机顶点索引；文本模式需定义空格、标点、重复字符和音频短于文本时的分配规则。
- 文本模式中重复字符可获得不同实例轮廓；字体文件中同一字符默认仍只有一个字形。实例变体通过样张 SVG 导出，字体导出使用明确选定的静态快照。
- 时间平滑用于抑制抖动，起音事件单独保留。用户可锁定参数、固定时间点或选区，并比较原字形、基础多边形和声音驱动结果。
- 音频、选区、分析配置、映射配置、基础几何参数、随机种子和算法版本相同，应产生相同静态结果。播放与重新绘制不得重新随机生成轮廓。

### 11.5 字形质量与交互要求

- 提供“保留可读性”默认模式，限制最小笔画厚度、最小字腔间隙、最大延伸和缺损比例；阈值以 em / 字体单位定义，不能随视口缩放变化。
- 生成后检查闭合、方向、字腔、退化边和自交。无效结果应回退至最近有效几何或降低效果，并说明具体限制；无法修复时阻止该结果导出。
- Erosion 必须实际改变轮廓；增加的缺损轮廓也须保持有效填充关系。仅渲染的阴影不能作为雕刻深度已改变字形的证据。
- 默认保留字宽与基线；超出边距时提示。允许显式开启字宽自适应，且样张与导出使用相同度量。
- 时间轴显示波形、选区、起音标记及所选特征曲线；控制面板按“声音 / 石刻 / 字形”分组，并显示有效输入、映射贡献及受限状态。
- 提供撤销 / 重做、模块重置、映射预设保存与导入；预设保存分析和映射配置，不默认嵌入原始音频。
- 首版静态生成优先于实时录音；分析与几何生成显示进度，取消或更换输入后不得让旧计算覆盖新结果。

### 11.6 导出与验收

- 支持导出当前有效字形 SVG、声音分配后的文本样张 SVG，以及包含映射配置、选区、种子和算法版本的 JSON 配方。配方需重新关联音频，并以内容指纹检查输入是否一致。
- SVG / 字体继续遵守直线轮廓、闭合和字腔规则；配方中的 Depth 为造型参数，不能宣称 SVG 或字体为三维模型。
- 用静音、稳定高低音、强弱振幅、密疏起音、长短事件和噪声片段分别验收。其余输入与参数固定时，目标效果应符合表中方向；Pitch 无效时不触发尖锐化。
- 只改变低频能量时，应能独立影响厚重感；只改变基频时，应能独立影响尖锐度，证明两者没有被混用。
- 映射归零、单条关闭、反向与限幅均可验证；相同配方重复生成及预览 / 导出结果一致。
- 在含字腔字形、细笔画、中文复杂字形及重复字符样张上验证可读性约束和导出有效性。
- 交付顺序：本地音频与分析 → 静态聚合映射 → 石刻几何与质量约束 → 时间局部 / 文本分配 → 配方与样张导出；麦克风实时模式后续评估。
